# 模拟回放记录网页导入与逐条一致性核验

状态：用户已确认并要求启动执行；Issue 标记 ready-for-agent。

## Problem Statement

用户需要把指定本地“模拟交易复盘”目录中的全部模拟回放 CSV，通过 TradeReview 网页导入系统，并验证保存的数据与外部原始记录一致。现有 TradingView 导入已有上海证券支持，但证券识别、解析和核对对话框将市场固定为上海，无法正确表示目录中的深圳证券。已有本地样本测试只覆盖其中两份文件，也没有证明本批文件经过真实网页确认、持久化及刷新后仍逐条一致。

## Solution

沿用“导入 TradingView 模拟交易”入口，逐份完成全部四份 CSV 的证券核对、解析、预览、确认保存与刷新恢复。补齐本批文件所必需的沪深市场支持及发现的最小缺陷。以独立读取的原始 CSV 为外部对照，建立每条源记录与系统成交的对应关系，提供本地逐条核验报告、汇总和未解决差异。

本规格将“外部数据”解释为用户目录中的原始 CSV；外部行情仅验证证券归属、来源和实际覆盖情况，不作为模拟成交价格或源报告绩效的真值。验收不能以直接写库或调用导入接口代替网页操作。

## User Stories

1. As a 复盘用户, I want 从已有网页入口选择目录中的四份 CSV, so that 全部练习记录都能进入系统。
2. As a 复盘用户, I want 上海和深圳证券被正确识别, so that 股票不会关联到错误市场。
3. As a 复盘用户, I want 导入前核对市场和六位代码, so that 无证券列的文件也能明确归属。
4. As a 复盘用户, I want 文件重命名后仍能核对证券, so that 导入不依赖固定文件名。
5. As a 复盘用户, I want 名称补全失败时看到明确状态, so that 不把缺名称误判为成交丢失。
6. As a 复盘用户, I want 始终看到 TradingView 和模拟盘标识, so that 模拟记录不混入实盘统计。
7. As a 复盘用户, I want 交易日期来自内容而非文件名, so that 历史区间准确。
8. As a 复盘用户, I want 日期精度和来源时区明确展示, so that 不把排序锚点误认为真实成交时刻。
9. As a 复盘用户, I want 核对原始行、配对、成交和交易回合的数量, so that 不混淆不同统计单位。
10. As a 复盘用户, I want 每行都有文件指纹、行号和交易编号对应关系, so that 差异可以追溯。
11. As a 复盘用户, I want 多空进出场转换正确, so that 买卖方向与仓位一致。
12. As a 复盘用户, I want 加仓和分批平仓份额保留, so that 合法的相似成交不会被去重。
13. As a 复盘用户, I want 核对每笔价格和数量, so that 汇总正确也不会掩盖逐笔错误。
14. As a 复盘用户, I want 配对重复列出的费用只计一次, so that 净盈亏正确。
15. As a 复盘用户, I want 源报告指标与系统计算分别展示和核对, so that 口径差异不会被隐藏。
16. As a 复盘用户, I want 所有原始列都有核验结论, so that 未保存字段不会被当作已验证一致。
17. As a 复盘用户, I want 源累计损益和配对净损益合计的差异保留, so that 系统不会篡改数据凑平。
18. As a 复盘用户, I want 预览明确列出重复、排除和错误, so that 全部源行都有去向。
19. As a 复盘用户, I want 确认后刷新仍能查看成交和模拟运行, so that 保存成功可验证。
20. As a 复盘用户, I want 重导同一文件和改名重导不增加成交, so that 可以安全重试。
21. As a 复盘用户, I want 不同运行及已有实盘互不合并, so that 历史记录和笔记不受影响。
22. As a 复盘用户, I want 取消预览不写入成交, so that 可以放心检查。
23. As a 复盘用户, I want 行情缺失有说明且已导入成交保留, so that 外部源故障不导致数据丢失。
24. As a 复盘用户, I want 在复盘中验证成交标记和持仓变化, so that 导入记录能实际使用。
25. As a 复盘用户, I want 未揭示的成交和最终绩效继续隐藏, so that 保持回放练习效果。
26. As a 复盘用户, I want 收到逐条对照和差异清单, so that 能判断本批导入是否完整完成。

## Implementation Decisions

- 执行前识别目标网页及对应存储环境，记录既有成交、模拟运行与导入历史基线。不得清空数据库；对既有重复记录核对复用，对无关记录验证未改变。
- 复用 TradingView 解析器、证券核对对话框、导入预览、对账、SQLite 和复盘工作区。将市场上下文贯穿文件名识别、手动核对、标准化成交、运行身份和元数据查询；SSE 对应上海，SZSE 对应深圳，不硬编码成上海证券。
- 按内容识别中文 CNY CSV，保留 BOM、引号和换行处理。文件名仅提供证券候选，导出日期不参与成交日期计算。
- 复用现有模拟运行、配对角色、来源行号和日期精度语义。配对编号不同于交易回合编号；同价同日的不同配对份额不能被误删。不同内容文件仍按独立模拟运行处理。
- 以独立 CSV 读取和十进制计算建立外部基线，不用生产解析器的输出生成自身期望值。源到系统无遗漏、系统新增到源无多余，重复记录也必须有实际系统对象可匹配。
- 字段逐项核对：交易编号、类型、日期、信号、价格、数量、大小（价值）、净损益、回报、手续费、有利/不利波动及其百分比、累计损益及其百分比、持续 K 线数。区分原样保留、规范化转换、配对级保存、派生计算、未表示和冲突；派生字段不要求与不同语义的源列强行相等。
- 大小（价值）可能为入场价值，不代替出场价格乘数量。配对级手续费在出场计入一次；源指标不能两行重复累加。系统重算和源报告分别记录，累计值差异明确报告。
- 报告记录每行来源定位、系统成交/运行/回合标识、外部值、系统值、比较规则、结果和差异原因。可作为本地文件交付，不要求新增通用对账页面或证据数据库。
- 核心字段和费用用十进制精确比较；仅对明确按源显示精度舍入的派生指标应用注明的舍入规则，不使用宽泛误差容忍。无法重算的回报或波动指标只验证源值保真，不能宣称计算一致。
- 缺配对、歧义和不支持记录明确阻塞完整验收，不能静默排除后宣布全部完成。已知源内部差异单独列示，区分源本身差异与导入错误。
- 原始 CSV 保持浏览器本地解析，不上传原文、不纳入仓库或公开 Issue。仅必要结构化记录按现有 API 保存；详细对账报告留在本地。

## Testing Decisions

- 拟定唯一主要验收边界：真实网页选择文件→真实解析→证券核对及预览→确认→SQLite 保存→刷新→交易库/复盘核验。测试断言外部可观察结果，不断言内部调用次数或实现结构。此边界已获用户确认。
- 复用工作区导入流程、TradingView 解析、本地样本、交易回合、回放账本和 SQLite API 测试先例。工作区验收必须使用真实解析链；确定性自动测试可冻结证券和行情响应。真实网页验收另外记录实际行情覆盖和失败状态。
- 本轮已独立读取四份 CSV：600330 为 34 行/17 配对，2021-02-19 至 2023-03-23，费用 0，配对净损益 20580；600737 为 12 行/6 配对，2021-03-16 至 2021-10-22，费用 0，配对净损益 -690；600869 为 24 行/12 配对，2021-02-19 至 2023-10-16，费用 9.60，配对净损益 21290.40；300857 为 12 行/6 配对，2021-03-01 至 2021-11-12，费用 0，配对净损益 -10500。金额单位 CNY。
- 合计 82 源数据行、41 配对，费用 9.60，配对净损益 30680.40。全部有效配对应表示为 82 条带份额成交，但实际新增数须扣除经核实已存在的同运行记录；不能把 41 配对当成 41 回合。
- 600869 的末项源累计损益 21290.38 与配对净损益合计相差 0.02：必须在报告中保留并解释为源内差异，不修改成交凑平，也不把两者称为完全相等。
- 验证沪深市场、源行覆盖、方向、多次入场、部分平仓、费用不重复、日期精度、源报告保存与读取，以及四份真实文件的字段级一致性。回合数量按独立持仓归零计算验证，不使用生产回合函数自证。
- 验证重导和改名重导、运行隔离、实盘共存、取消、保存失败无部分成交、刷新恢复、行情失败保留成交、未来信息遮蔽和既有笔记不变。对发现的必要修复运行相关回归及项目规定检查。
- 完成标准：全部 82 行有可追溯结论；核心成交及配对保存无未解决差异；未表示字段和源内差异透明记录；网页保存与重载有证据。只有计数或解析测试通过不算完成。

## Out of Scope

- 规格编制与执行分阶段进行；用户已要求启动本 Issue 执行。
- 自动扫描用户文件系统、必须新增多文件批量上传、通用自动对账平台、TradingView 账号同步或模拟撮合。
- 任意语言/币种/资产格式、跨文件拼接模拟运行、推断精确盘中成交时刻或未提供的资金参数。
- 新增行情供应商、保证历史分钟覆盖，或要求模拟成交价等于真实市场某个成交价。
