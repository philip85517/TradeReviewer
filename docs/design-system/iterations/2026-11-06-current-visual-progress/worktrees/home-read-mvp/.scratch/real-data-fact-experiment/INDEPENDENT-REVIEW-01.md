# 第一轮独立验收：真实副本的非财务读取实验

验收人：独立 Luna 6 Max；复核范围仅为隔离实验，不是首页或交易库产品验收。原始结果见 [run-01.json](results/run-01.json)，实验边界见 [README](README.md)。

## 结论

隔离与冻结数据上的事实、筛选和分页一致性 **PASS**。裁剪路线 B 的计时公平性 **FAIL**：投影时已对全部事实排序，随后筛选分页又排序一次；因此不能用该数字做公平的 A/B 比较。预备窄结果路线 C 相对于完整路线 A 的快速读取有方向性证据，不能外推到浏览器完整页面或实际数据更新。

在 1,866 条活动事实、8 个已知账户及 236 个标的的样本上，实验记录了完整事实与独立 SQL 一致；全部 234 页无重复，逐账户、逐市场、组合、空集合、日期边界及不同页大小下的结果得到核对。独立复核证实跨账户范围包含两账户，历史搜索锚点处于全部记录的第 1,866 位，位于产品第一页 1,000 条之后。真实副本无空账户和已撤销事实，相应分支不可算真实数据覆盖。

同一轮每种工作负载各 7 次，全部范围完整读取 A 的 p50 约 9,497 ms、完整响应 34,315,599 字节；预备窄结果 C 的 p50 约 0.789 ms、响应 3,250 字节。首次准备约 8,157 ms；新进程打开、读取并退出约 857 ms。单轮 p95 即最大样本，不代表线上分位数。这是本地实验代码的测量，非 HTTP 和浏览器首屏耗时。

## 证据与限制

- 独立只读复核了本轮私有源及预备库，完整性检查通过，源副本读取前后 SHA 未变，实际路径无符号链接；没有打开业务库或冻结种子。3 项纯内存核心测试通过。
- 脚本的路径边界检查仅为词法前缀，不能推广为未来所有路径的安全证明。应在复测前增加真实路径/符号链接检查。
- 首轮版本拒绝只改变规则版本，未分别证明源 SHA、账本版本或代码摘要变化。没有验证产品的动态缓存失效或每次读取检测缓存数据篡改。
- 严格日期及分页游标越界应使用合成反例检验。真实范围与缺失值、规则结果应分开记录。
- 首次准备时间不满足数据变化后立即完成首屏的目标；导入/修订后的真实更新、财务结果、Bars、行情、完整页面、线上接口及完整控件均未验证。
