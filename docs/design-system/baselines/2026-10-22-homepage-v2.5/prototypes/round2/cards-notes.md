# 第二轮卡片与贡献控件说明

## 来源核对

- 胜率原稿来自 `../winrate-current.svg`，其上游是冻结 `source/images/home-1440.svg` 的嵌套历史区域（`x=96,y=1130`），卡片为 `x=666,y=82,width=321,height=88`，主值 `60.0%`，分母 `6 / 10 盈利回合`。
- 贡献原稿来自 `../contribution-labels-current.svg`，其上游是冻结首页贡献区域（`x=96,y=1712.0`）。完整文字核对为：分类 `做多 / 做空 / 打新`；排序 `盈利最高 ↓ / 亏损最大 ↑`；独立过滤条件 `仅看未平仓持仓`；全局市场只读值 `全部市场`。源图中的过滤文字按语义拆为独立复选框，避免把布尔过滤误列为互斥排序项。
- 原稿以 SVG 图片直接显示，候选是 HTML/CSS 对照，避免把重画内容冒充基线。所有箭头均为独立 SVG；基线文件中的文字箭头只在源图中保留。

## 候选差异

### D10

- 候选 A 把分母移到主值右侧并右对齐，形成同一基线的平衡并列；主值、分母、颜色和字号不变。
- 候选 B 把右侧拆成两行“盈利回合 / 6 / 10”并右对齐，与左侧主值形成明确分组；不新增指标或装饰数据。
- 278px 压力例使用明确合成的 `100.0%` 与 `1,000 / 1,000 盈利回合`；窄宽卡片增高到104px，候选 A 将完整分母移到第二行，候选 B 保持右侧两行分组，不拆分、不缩小字号。

### D11

- 候选 A 只减弱边框并合并分段间隙，保留 36px 高度和 14px 文字。
- 候选 B 使用纯文本选中态、轻底色和下划线，保留同样的点击区。
- 排序是可操作的原生 `select`，选项保留原方向语义 `盈利最高 ↓ / 亏损最大 ↑`；`仅看未平仓`是独立复选框，可以与排序同时保留；分类按钮仅切换示意状态，不连接业务数据；`全部市场`保持只读上下文，与原 SVG 一致。两种候选只比较视觉呈现，不宣称业务行为等价。

## 操作清单

1. 在 D10 两个候选之间比较主值与分母的阅读顺序，并在 390px 宽度查看压力例。
2. 在 D11 点击分类按钮，确认仅有选中态切换；分别操作两个排序 `select` 与独立的 `仅看未平仓` 复选框，确认排序和过滤可以并存。
3. 对照每个区域上方的原 SVG 裁切，候选通过后由 root 集成并做独立浏览器验收。
