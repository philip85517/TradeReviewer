# 交易库视觉设计方案 V1.0

本方案把冻结的首页交易库业务与分镜独立成可直接交付的页面规范。它覆盖从首页日期、交易库入口到交易列表、练习回合、统计分布、详情复盘和返回来源的完整链路；首页 V2.5 只保留进入交易库的入口与返回恢复帧。原始权威来源为[冻结 V2.4.2 视觉规范 HP06](../../2026-10-22-homepage-v2.4.2/visual-spec.html#chapter-HP06)、[冻结 V2.4.2 交易库补充规范 HP07](../../2026-10-22-homepage-v2.4.2/visual-spec.html#chapter-HP07)及其公共控件手册。既有分镜沿用原 SVG；本次统一入口补充 `journeys-library-entry.svg`，并以 `library-return.svg` 表达普通交易库来源返回。

交易库复用 V2.5 的公共契约：[共享规范 HP08](../../2026-10-22-homepage-v2.5/visual-spec.html#chapter-HP08)、[视觉基础 HP11](../../2026-10-22-homepage-v2.5/visual-spec.html#chapter-HP11)、[全站原则](../../2026-10-22-homepage-v2.5/visual-spec.html#sitewide-principles)和[控件手册](../../2026-10-22-homepage-v2.5/source/component-manual.html)。跨页传参与恢复字段见[首页入口状态约定](../../2026-10-22-homepage-v2.5/visual-spec.html#entry-contract)。本页只补充交易库的页面层级、业务条件、列表与回合关系、统计口径、返回上下文和交易库专属边界。

## 一、目标与取舍 {#chapter-BT01}

交易库把首页上的结果阅读接到可核对、可复盘的具体交易。日期检索和普通交易库入口把首页结果接到具体交易；待复盘只作为交易库内部的显式筛选，再从筛选结果进入复盘任务。入口提供的来源日期、标的、市场和账户条件到达后立即生效，未提供的条件保持交易库自身范围；用户无需再次点击应用。条件摘要是只读说明，与按钮分开呈现，不画成待确认的操作。

页面保持“列表 → 标的或练习 → 回合集 → 回合复盘”的短链路。实盘与模拟盘是互斥视角，复用列表和统计组件，但各自保存条件和导航上下文。模拟盘以一次练习承载一个标的的多个交易回合，同一标的同一天的反复练习仍是独立练习；因此不增加无业务依据的中间页，也不把实盘账户当作模拟盘练习身份。

统计和列表使用各自明确的日期口径：实盘列表按每笔成交日期筛选，统计按回合平仓日期归属；未平仓成交仍可在列表查看，却不进入已平仓回合统计。模拟盘按导入文件保存的练习日期归属，不以行情日期代替。页面内搜索只过滤交易库表，不调用全局标的搜索遮罩。

## 二、布局与公共视觉基础 {#chapter-BT02}

交易库沿用 V2.5 公共表面、颜色、字体、间距、焦点和状态规则。顶栏先显示视角、来源条件和返回来源动作；内容区由条件工具区、列表或统计主体、分页与状态反馈组成。打开详情或回合集时沿用已确认的详情容器，不新增没有合同依据的双栏容器。返回动作在来源语境中恢复原位置与焦点。

公共尺寸和对齐以 HP08、HP11 与控件手册为准：按钮、分段标签、日期快捷项和应用动作在命中盒内水平垂直居中；输入文本左对齐，金额表头和金额数据右对齐，名称、说明与错误文案左对齐；共享图标视觉尺寸为16px，页头搜索与筛选图标为18px，外层图标和动作按钮保持36px命中盒。价格保留两位小数；金额按绝对值达到1万显示“万”、达到1亿显示“亿”，均保留两位小数，不增加“万亿”，完整值在详情、提示、悬停/聚焦、复制和导出中可查。表格列沿用公共列定义与右对齐规则。

交易库工具区保持搜索220px、刷新36px、间隔28px和独立条件摘要；表头与结果区不重叠。日期筛选使用日历图标，年份选择使用下拉箭头，静态日期不添加图标。筛选浮层沿用320px宽、字段高36px的公共规格；交易库内搜索保持页面内 inline filter，不能打开全局全屏搜索遮罩。

## 三、范围、日期与搜索 {#chapter-BT03}

首页入口默认进入“实盘”。来源日期、市场、账户、标的和返回上下文随入口传入，条件到达后立即生效。交易库内修改条件不回写首页；返回首页时恢复原期间、滚动位置和触发焦点。

日期支持单日、区间、全部以及“本周／本月／本年”快捷范围。业务时区为上海时区：自然本周从周一开始，自然本月从每月1日开始，自然本年从1月1日开始，均截至今天并包含起止日；提交后实际起止日期必须可见。日期或筛选参数不合法时使用明确的默认值并提示，不能静默显示另一个范围。

交易库分为互斥的“实盘 / 模拟盘”视角。两个视角分别记忆日期、市场、账户条件、搜索、排序、页码、滚动位置和焦点；列表和统计共享当前视角的日期、市场与账户条件。切换视角不得覆盖另一视角已保存的账户选择，也不得把实盘账户作为模拟盘练习身份。此处只约定条件的保存与恢复，不新增模拟盘账户控件或账户业务模型。

搜索是局部 inline filter，只过滤交易库表。清空、无匹配和失败均保留工具区几何，不能以全局搜索遮罩替代。来源范围、日期、市场和账户的只读条件摘要与搜索并列；刷新保留当前条件。搜索无匹配与没有交易是两种不同空态，缺失数据也不能以零代替。

## 四、列表、练习与回合 {#chapter-BT04}

### 实盘列表

实盘列表按每笔成交日期筛选，并保留未平仓成交。打开某个标的的交易后，进入已确认的详情容器查看该标的的回合集，不增加中间页面。关闭或返回时恢复来源列表的标的、筛选、排序、页码、滚动位置和触发焦点。

### 模拟盘练习列表

模拟盘以一次练习为列表入口。一次练习包含一个标的的多个交易回合，同一标的同一天的反复练习保持独立身份。列表分别显示练习记录数与已平仓回合数；点击练习直接进入该练习的回合集，操作与实盘进入某个标的的回合集一致，不增加中间页面。进入回合复盘后返回，恢复原练习、筛选、排序、页码、滚动位置和焦点；同一标的的其他练习不混入当前回合集。

中途加减仓按最近开仓优先配对：先买100、再买50、卖80时，先配对50，再配对30。配对不跨练习，每个有效配对算一回合；此例为两回合，余70仍未平仓并排除在已平仓回合统计之外。不要求练习另有开始或结束状态。扣费后收益大于0为盈利、小于0为亏损、等于0为持平；胜率分母包含持平回合，平均盈利和平均亏损不含持平回合。

## 五、统计与分布 {#chapter-BT05}

统计页复用趋势与盈亏分布组件，但遵循交易库日期和回合口径。日期跨度不超过31天按日展示，超过31天且不超过两年按月展示，超过两年按年展示。分布默认使用回合收益率，也可切换金额。每个区间显示回合数与占比，占比保留2位小数；窄栏把占比放到回合数下一行。

占比分母固定为当前范围内全部有效回合。展开区间明细只展示该区间回合，不改变分母、不改变顶部条件，也不重算原分布。点击回合进入复盘，返回后恢复原区间与列表位置。极端金额、负值、集中分布和缺失计算输入分别保持可读刻度、正确正负、稳定布局和明确不可计算状态。

模拟盘统计按练习保存日期归属；一次练习可有多个回合，但同标的同日的再次练习仍保持独立身份。实盘统计按回合平仓日期归属；未完成回合不混入已平仓统计。缺失值显示破折号并明确不可计算，不把缺失混入完整分布。

## 六、详情、复盘与返回完整分镜 {#chapter-BT06}

从首页日期点或普通交易库入口进入时，交易库立即显示入口提供的来源日期、标的、市场和账户；列表按成交日筛选，统计另按回合平仓日期归属。普通入口不预设 `queue=pending-review`；待复盘列表仅由交易库内的显式筛选到达，筛选结果的来源条件仍保持不变。完成复盘后应能在交易库内核对筛选结果变化。

从实盘列表打开某标的的交易，进入已有详情容器中的回合集；从模拟盘列表打开一次练习，直接进入这次练习的回合集；从回合集选择一个回合，进入携带该回合及必要开仓上下文的复盘。范围外的开仓上下文可以用于理解该回合，但不改变列表和统计归属。

返回必须逐层恢复来源：回合复盘返回原回合集；回合集返回原标的或原练习；交易库返回首页时恢复原期间、贡献模式、表格状态、滚动位置和触发焦点。首页贡献下钻进入交易库时，还应恢复原市场、证券、日期、账户、筛选、排序、页码、滚动位置和触发焦点；若刷新导致原标的消失，焦点回到来源容器标题并保留仍有效的条件。不能从泛化“进入贡献”按钮直接跳到固定证券详情。

入口帧和到达帧的职责必须分开：入口帧的导航按钮负责进入普通交易库；到达帧显示已生效条件和交易列表，不再要求重复点击“进入交易库”。待复盘分镜只表达交易库内的显式筛选，不代表首页入口或默认队列。首页 V2.5 只展示普通入口帧，交易库 V1.0 展示完整到达、列表、回合、复盘和返回链路。

## 七、异常状态 {#chapter-BT07}

首次加载使用标题、工具区、表头和行槽的最终尺寸占位，等待不会造成布局跳动。已有数据后台更新时保留上一组完整有效数据；更新失败或超时保留旧范围和有效值，并说明新范围未应用。没有交易、搜索无匹配、没有已平仓回合、数据缺失和计算输入缺失分别表达，不能将它们合并为零。

读取失败提供可恢复错误和重试，重试保留原筛选条件。请求连续切换时只应用最后一次仍有效的选择；迟到的旧请求不能覆盖新选择。缺失金额显示“—”或“不可计算”，不伪造零值。范围、账户、市场和日期参数非法时使用明确的默认值并提示。

## 九、实现验收 {#chapter-BT09}

本方案是设计合同，静态分镜只说明预期，不证明实现已经完成。实现验收分别检查功能、状态链、持久化和视觉：从首页日期点、普通交易库入口、交易库内待复盘筛选、实盘标的、模拟盘练习、统计区间进入；完成一次回合复盘后返回、刷新、重新打开，确认真实条件、列表、练习、回合、区间、滚动和焦点仍一致。写入验收使用隔离数据库，保留原始交易数据不变。

视觉对照使用批准视口、相同导航和相同状态，检查条件工具区、搜索220px、刷新36px、间隔28px、公共表格列对齐、金额精度、占比两位小数、窄栏换行、空态/错误态和返回焦点。功能、数据持久化、真实页面行为与同状态视觉比较分别记录结果；未验证项不能写成通过。
