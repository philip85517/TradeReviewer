# 首轮策略观察者原型实现记录

日期：2026-09-29
范围：`?prototype=strategy&variant=A|B` 的开发环境原型；对应 `strategy-visual-03`。

## 已实现

- 在 `app/page.tsx` 增加 Next 兼容的异步 `searchParams` 读取。只有开发环境且 `prototype=strategy`、`variant=A|B` 时挂载原型，正常首页分支保持原样。
- A（分步向导）按“历史设置 → 策略包 → 组合预览 → 自动运行 → 结果对比”逐屏推进，每一步有明确主动作和进度回看。
- B（连续工作台）在同一屏保留左侧实验配置、中间逐日净值图、右侧事件时间线；配置、推进、点选历史事件和结果入口在同一工作区内完成。
- 两个变体使用同一份固定合成故事：起点、两套策略、初始目标仓位、7 日曲线、第五日自动调仓解释、期末比较、返回/重新打开内存实验。
- 图形使用内联 SVG；未来数据不绘制，逐日推进会增加已揭示点和日期。页面明确标注合成演示、无业务数据库访问、刷新重置。
- 底部固定方案切换条支持按钮与左右方向键；输入/选择控件聚焦时不拦截键盘。切换 URL 可复制、刷新保持；生产环境不会挂载。
- CSS 覆盖深色应用视觉、桌面三栏/向导密度和约 390px 窄屏纵向布局；底部切换器保留安全间距。
- 独立复核后修正：曲线只使用已揭示游标并按当前可见数据缩放；没有未来虚线/未来极值；日期均明确为演示日。期限选项明确显示“固定 7 日合成样本”，选择结果会进入预览摘要。
- 两个变体都经过预览后才能启动；运行后策略与配置锁定。工作台显示净值、现金、持仓状态与调仓前后目标仓位。事件时间线只展示已揭示事件，点选历史事件进入独立回看视图，不回退运行游标。
- 返回实验列表和重新打开保留内存游标；刷新仍会重置。方案切换左右键在 A/B 间环绕。
- 复核收尾：B 播放时当前视野跟随运行游标，历史点选仅改变查看日；A 运行后不能回到策略选择步骤。第二策略仅作为结果对照，不冒充已执行的第二条曲线；调仓原因展开不会改写运行状态。结果页只保留“返回实验列表”，列表卡片负责重新打开。
- 原型 CSS 已将通用类选择器限定在 `.strategy-prototype` 下，正常首页不会继承原型按钮、文字或状态样式。持仓摘要和内存实验卡补充了桌面/窄屏布局样式。

## 验证

- 未运行服务、未访问 API、未写入数据库；浏览器视觉与动线验收由主协调者在现有 127.0.0.1:3047 预览中执行。

## 限制与后续决策

- 所有数据、曲线、调仓解释均为固定演示脚本，不代表真实市场、策略引擎或回测结果。
- “返回实验列表/重新打开”只恢复当前内存演示状态，刷新会重置；没有真实保存、持久化、权限或数据质量检查。
- 当前原型保留两套方案供用户选择；未将任一方案提升为生产页面，也未对后续详细指标、真实图表、完整期限和执行口径做承诺。
