# 交易收益分布与来源拆解设计规格

日期：2026-09-20
状态：ready-for-agent

## Problem Statement

用户已经有一批历史交易和基础收益统计，但现在仍无法从“总收益”回答几个最重要的问题：

- 盈亏是由很多笔小亏/小赚组成，还是被少数几笔大亏/大赚主导。
- 胜率和赔率是否匹配；较低胜率是否由较大的平均盈利补偿，较高胜率是否只是大量小赚而被少数大亏抵消。
- 当前收益中有多少来自新股申购/配售，普通二级市场交易的真实表现如何。
- 美股、港股、沪市、深市等市场之间的交易质量是否有明显差异。
- 这些差异是稳定的可复用模式，还是仅仅是样本少、数据不完整或个别异常交易造成的。

当前页面已有基础的已平仓指标和“模式洞察”入口，但缺少一套围绕单笔结果分布组织的图表、口径说明、来源拆分和初步诊断。若直接展示合计收益，跨币种、不同仓位规模、新股成本链和少数尾部交易会互相混淆，用户容易把相关性误读为因果，也无法定位需要回看的具体回合。

## Solution

在现有“模式洞察”页面增加“收益结构”首屏区域。该区域从现有的已平仓 `InsightEpisodeFact` 生成一个可解释的收益分析报告，并提供四层视图：

1. **结果分布**：用费用后单回合收益率展示小亏、大亏、小赚、大赚和持平的分布，同时保留直方图/散点明细，避免四个桶掩盖尾部。
2. **胜率—赔率关系**：同时展示胜率、平均/中位盈利、平均/中位亏损、赔率、利润因子和每笔期望收益；明确区分“含持平的总胜率”和赔率图使用的“非持平胜率”。
3. **初步结构诊断**：依据亏损/盈利的广度与尾部集中度，给出“亏损较普遍”“少数大亏拉动”“多笔小赚”“少数大赚拉动”等中性描述，并列出证据回合和反例回合。
4. **来源与市场拆分**：将可确认的新股 IPO 回合、可确认的非新股回合和无法判定回合分开；再按标准化市场字段提供美股、港股、沪市、深市等分组比较。

所有图表都使用相同的范围筛选和样本排除规则，支持从任意柱、点、诊断或市场/新股分组打开对应交易回合。缺失、未知或不可比的值显示为“不可用/无法判定”，不得用零代替。结论只描述样本相关性和分布形状，不生成买卖建议，不把统计相关性表述为因果关系。

## User Stories

1. As a 交易复盘用户, I want to 在统一统计范围内看到已平仓交易的总样本数, so that 我知道当前图表到底基于多少笔交易。
2. As a 交易复盘用户, I want to 同时看到盈利、亏损和持平的笔数, so that 我能区分胜率、亏损率和持平占比。
3. As a 交易复盘用户, I want to 看到费用后单回合收益率的分布, so that 不同金额和不同币种的交易也能在同一尺度上比较。
4. As a 交易复盘用户, I want to 看到收益率直方图并标出零收益线, so that 我能判断结果集中在零点附近还是存在明显尾部。
5. As a 交易复盘用户, I want to 看到小亏、大亏、小赚、大赚四类交易的数量、占比和代表性收益率, so that 我能快速理解交易结果的形状。
6. As a 交易复盘用户, I want to 知道“大/小”的分界值和分界方法, so that 我不会把数据驱动的分类误认为固定的行业标准。
7. As a 交易复盘用户, I want to 在样本过少时看到“无法可靠划分大小”的提示, so that 少量交易不会制造虚假的四象限结论。
8. As a 交易复盘用户, I want to 点击某个分布桶查看其中的交易回合, so that 我可以回看具体的大亏或大赚是如何发生的。
9. As a 交易复盘用户, I want to 看到最大亏损、最大盈利及其相对收益率, so that 我能识别是否存在改变总体印象的异常交易。
10. As a 交易复盘用户, I want to 看到平均盈利和平均亏损, so that 我能直接比较每次赢和每次输的典型幅度。
11. As a 交易复盘用户, I want to 看到中位盈利和中位亏损, so that 少数极端值不会完全代表大多数交易。
12. As a 交易复盘用户, I want to 看到赔率为平均盈利除以平均亏损绝对值, so that 我能判断胜率之外的收益补偿能力。
13. As a 交易复盘用户, I want to 看到利润因子和每笔期望收益, so that 我能判断收益是否靠少数盈利交易覆盖全部亏损。
14. As a 交易复盘用户, I want to 看到含持平的总胜率和不含持平的赔率图胜率, so that 持平交易不会让赔率关系的口径产生歧义。
15. As a 交易复盘用户, I want to 在胜率—赔率图上看到每个分组相对于盈亏平衡关系的位置, so that 我能理解两项指标的联动，而不是只盯着单项排名。
16. As a 交易复盘用户, I want to 看到一个“亏损广度”指标, so that 我能区分亏损是多数交易都发生，还是少数交易造成。
17. As a 交易复盘用户, I want to 看到亏损尾部集中度, so that 我能判断最差的一小部分交易占全部亏损幅度的比例。
18. As a 交易复盘用户, I want to 看到盈利尾部集中度, so that 我能判断整体盈利是靠少数大赚，还是由很多小赚分散贡献。
19. As a 交易复盘用户, I want to 看到“个别大亏”“普遍亏损”“少数大赚”“普遍小赚”等初步诊断, so that 我能决定下一步优先回看哪类交易。
20. As a 交易复盘用户, I want to 看到每条诊断的计算依据、阈值和样本数, so that 我能审查结论而不是被黑箱标签引导。
21. As a 交易复盘用户, I want to 点击诊断中的证据交易和反例交易, so that 我能验证诊断是否符合实际交易情境。
22. As a 交易复盘用户, I want to 将新股 IPO 交易与普通非新股交易分开统计, so that 申购/配售收益不会掩盖二级市场交易能力。
23. As a 交易复盘用户, I want to 看到新股组、非新股组和无法判定组的样本覆盖, so that 我知道有多少交易未被强行归类。
24. As a 交易复盘用户, I want to 看到新股和非新股的胜率、赔率、平均/中位结果和收益分布, so that 我能比较两类交易的收益质量。
25. As a 交易复盘用户, I want to 看到新股分类使用了哪条申购/配售证据, so that 新股标签可以回溯到账单事件而不是靠股票名称猜测。
26. As a 交易复盘用户, I want to 将“新上市但通过二级市场买入”的交易保持为非新股或无法判定, so that 系统不会把上市日期误当成 IPO 获配证据。
27. As a 交易复盘用户, I want to 按市场查看结果分布和收益质量, so that 我能发现某个市场是否更容易产生大亏或小赚。
28. As a 交易复盘用户, I want to 看到市场分组的样本数和数据完整性, so that 小样本市场不会被误排成最佳或最差市场。
29. As a 交易复盘用户, I want to 同时看到市场和新股拆分的结果, so that 我能区分市场效应与新股交易结构的干扰。
30. As a 交易复盘用户, I want to 切换实盘、模拟盘及具体模拟运行而不混合结果, so that 模拟实验不会改变实盘历史统计。
31. As a 交易复盘用户, I want to 按既有日期范围和市场筛选更新所有图表, so that 图表之间可以互相验证。
32. As a 交易复盘用户, I want to 在缺少费用、成本证据、收益率或历史库存证据时看到排除原因, so that 我能区分真实结果和不可核验结果。
33. As a 交易复盘用户, I want to 在跨币种场景下仍能查看收益率分布, so that 缺少汇率不会阻断尺度无关的分析。
34. As a 交易复盘用户, I want to 只在汇率和成本口径完整时看到合计金额, so that 系统不会伪造跨币种净收益。
35. As a 交易复盘用户, I want to 从任意图表回到对应的交易回合详情, so that 统计洞察能够落到可执行的复盘对象。
36. As a 交易复盘用户, I want to 看到明确的“这是描述统计，不代表因果或交易建议”说明, so that 我不会把历史相关性当成未来保证。
37. As a 交易复盘用户, I want to 在交易数量不足时仍看到原始描述统计但不看到正式诊断, so that 少量数据仍有参考价值且不会被过度解读。
38. As a 交易复盘用户, I want to 看到计算版本和统计口径, so that 后续规则升级后我能解释历史图表为何变化。

## Implementation Decisions

- **复用现有数据链路。** 洞察输入继续来自已平仓 `TradeEpisode` 派生的 `InsightEpisodeFact`。不重新读取原始账单，不在页面组件中重算成本、费用或持仓回合。现有交易范围中的实盘/模拟盘、模拟运行、日期范围和市场字段继续作为上游筛选。

- **最高 seam。** 新能力的核心 seam 是“洞察报告生成器”：给定已经完成可靠性筛选的事实集合，生成一个包含分布、胜率/赔率、诊断、新股拆分和市场拆分的纯报告；页面只渲染报告、显示口径、发起筛选和打开回合。优先扩展现有 `InsightEpisodeFact` / `buildPatternInsightReport` 体系，而不是新增 API 或让 UI 直接访问交易数据。

- **统计样本。** 正式分析只使用已平仓、净收益可核验、开仓敞口为正且费用后收益率可计算的回合。开放回合、未知费用、历史覆盖缺口、成本链不完整、币种冲突、收益不可用和无效敞口必须进入排除列表并显示首个适用原因。缺少完整路径行情不会阻断收益分布，但会使路径类指标保持为空。

- **主分析口径。** 图表和单笔分布以费用后收益率 `净盈亏 / 开仓敞口 × 100` 为主，因为它能跨仓位规模和币种比较。总净盈亏仍沿用现有原币/CNY 汇率快照规则，仅在可比较时展示。R 倍数作为计划风险覆盖足够时的辅助口径，不替代收益率分布，也不能从最终走势反推计划风险。

- **盈亏符号。** 收益率大于 0 为盈利，小于 0 为亏损，等于 0 为持平。总胜率沿用现有统计习惯，为盈利笔数除以所有合格回合数，持平计入分母且单独显示。赔率平面另显示非持平胜率，即盈利笔数除以盈利与亏损笔数之和；这样标准的平均盈利/平均亏损关系不会被持平样本混淆。

- **小/大分类。** 对盈利和亏损分别计算该方向收益绝对值的中位数作为分界：不超过同侧中位数为“小”，超过同侧中位数为“大”。同侧少于 3 个样本时不强行生成“大/小”类别，只展示原始分布和描述统计；平局单独为“持平”。图例始终显示分界值、样本数和“仅用于当前样本描述”的说明。分类不使用绝对货币金额，也不把新股或某个市场的结果与其他组混用分界值。

- **分布图表。** 首屏包含：

  - 收益率直方图/密度式柱形图：横轴为收益率区间，零线明显，正负区间使用不同语义色；每个区间显示数量，点击后打开该区间的回合列表。
  - 四类结果条形图：小亏、大亏、小赚、大赚、持平五类显示数量、占比、中位收益率和回合入口。
  - 极值摘要：最大亏损、最大盈利、亏损和盈利的中位数/平均值；极值只作为事实呈现，不自动标记为错误。
  - 赔率散点图：横轴为非持平胜率，纵轴为平均盈利/平均亏损绝对值；每个点代表总体、新股/非新股组或市场组，点旁显示样本数。盈亏平衡线根据 `胜率 × 平均盈利 - 亏损率 × 平均亏损 = 0` 生成；有持平样本时在说明中显示持平占比，不把该线解释为预测线。

- **诊断规则。** 诊断报告只输出中性、可解释的描述，不输出“应该怎么交易”。至少 5 个盈利或亏损样本时才生成尾部诊断；不足时显示“样本不足”。

  - 亏损广度 = 亏损笔数 / 合格回合数。
  - 亏损尾部集中度 = 按绝对收益率从大到小排列的最差 20% 亏损交易，占全部亏损绝对收益率之和的比例；按至少 1 笔计算，向上取整。
  - 盈利尾部集中度同理，用于判断盈利是否靠少数大赚。
  - “少数大亏拉动”信号：亏损样本达到 5，亏损广度低于 50%，且亏损尾部集中度至少 50%，或最大亏损绝对值至少为中位亏损绝对值的 2.5 倍。
  - “亏损较普遍”信号：亏损样本达到 5，亏损广度至少 50%，且亏损尾部集中度低于 50%。
  - “少数大赚拉动”信号：盈利样本达到 5，盈利尾部集中度至少 50%。
  - “多笔小赚”信号：盈利样本达到 5，盈利尾部集中度低于 50%，且盈利广度至少 50%。
  - 同时满足多个信号时按“少数大亏/少数大赚”尾部信号优先展示，其余作为辅助标签；不满足时只展示指标，不制造诊断。

- **诊断证据。** 每条诊断保留参与计算的交易 ID、最能支持诊断的尾部交易、代表性反例、时间范围、样本数、分界方法和计算版本。点击证据或反例进入既有交易库/复盘回合，不复制或修改原始交易。

- **新股判定。** 新股不是根据证券名称、上市日期或用户猜测判定。回合被标为 `新股/IPO` 的必要证据是同一账户、同一标准化证券和同一市场范围内存在可归属的正数量 `ipo` 配售/获配事件，或现有执行背书的 IPO 分配证据。与之相反，明确为普通成交且没有库存缺口的回合标为 `非新股`；存在初始持仓、历史缺口、库存事件冲突或无法确定来源时标为 `无法判定`。同一 IPO 事件在成交和账单资产表中重复出现时只计一次。

- **新股分组。** 整体报告保留无法判定组的数量和排除原因；新股与非新股的横向比较只使用两类已判定样本，不能把无法判定样本偷偷归入非新股。每组显示样本数、胜/负/平、总胜率、非持平胜率、平均/中位盈利与亏损、赔率、利润因子、收益率中位数、分布桶和诊断状态。IPO 成本证据不完整时，该回合不能进入正式收益比较，但仍可在“无法判定/排除”详情中定位。

- **市场分组。** 按现有标准化 `Instrument.market` 分组，首期支持美股、港股、沪市、深市，并保留未知市场。每个市场显示与总体相同的核心指标和结果桶；市场样本小于 3 时只显示描述统计，不参与正式诊断或排名。市场分组不合并不同交易性质或模拟运行，金额统计遵循现有币种和 FX 规则。

- **模式洞察衔接。** 收益结构放在现有模式洞察页面的正式标签洞察之前，作为所有已确认标签分析的基础层。现有条件/图形/执行心理洞察继续复用原规则和可信度分层；收益分布诊断不自动创建标签，不改变已确认标签，不替换现有的早期线索/正式洞察分类。

- **范围和交互。** 新增的分组选择至少包括总体、新股/非新股、市场；所有选择沿用当前交易室的实盘/模拟盘、模拟运行、日期和市场范围。切换分组只重新计算本地报告，不请求外部行情。图表的可访问名称、表格替代信息和窄屏折叠布局必须与视觉图表同时提供。

- **结果持久化。** 本期不新增用户可编辑事实，不把诊断写回成交或复盘记录。若沿用现有洞察快照机制，只保存可重建报告和计算版本，不保存重复的原始交易字段；报告必须能在规则版本升级后重建。

- **隐私与安全。** 所有统计在本地完成，外部行情接口不会收到账户、成交、复盘笔记或诊断内容。日志、测试夹具和页面错误不输出完整账单或敏感账户信息。

## Testing Decisions

- 好的测试应只验证用户可观察的统计结果、分类、口径、筛选和回合跳转，不锁定组件内部函数拆分、CSS 类名或 SVG 坐标。核心计算采用纯输入/输出测试，页面用可访问角色、可见标签和回合回调做行为测试。

- 报告生成器需要覆盖：

  - 正收益、负收益、精确持平、缺失收益率和不可用收益的样本计数。
  - 同侧收益中位数分界的边界值、少于 3 个同侧样本时不分类、五类桶占比总和和稳定排序。
  - 平均盈利、平均亏损、赔率、利润因子、含持平胜率、非持平胜率和每笔期望收益的公式。
  - 极端值改变平均值但不改变中位数的情形，以及单笔极端交易对尾部集中度的影响。
  - 亏损广度、盈利广度、尾部集中度和四种初步诊断的触发/不触发边界；样本不足时不得输出正式诊断。
  - 新股正数量 IPO 事件、执行背书事件、重复 IPO 证据、普通二级市场买入、初始库存和历史缺口的三态分类。
  - 各市场分组、未知市场、相同证券跨多个账户/交易性质、模拟运行隔离和稳定的证据交易 ID。
  - 跨币种时收益率仍可计算，原币金额不被错误相加；缺少 FX 时显示未知而不是零。
  - 现有排除原因继续透传到报告，并确保新报告不会把排除样本重新纳入总数。

- `InsightEpisodeFact` 构建相关测试需要验证新股证据和分类所需事实来自既有 `TradeEpisode`/`positionEvents`，不从证券名称或上市日期猜测；IPO 重复事件不重复增加敞口或样本。

- `PatternInsights` 组件测试需要验证：首屏图表标题和口径说明可访问；切换总体/新股/非新股/市场组后核心指标同步变化；小样本和无法判定提示可见；点击柱、点、诊断证据和反例调用已有打开回合回调；缺失指标显示破折号而不是 0；窄屏布局仍能读取表格化替代信息。

- 页面级验收需要在真实浏览器中使用隔离数据库验证完整路径：进入模式洞察、切换实盘/模拟范围、选择新股和市场分组、打开一笔大亏/大赚证据回合，并确认浏览器控制台没有阻断性错误。验收数据必须来自数据库一致性备份，且前后核对原始交易数量和内容摘要未改变。

- 既有测试先例优先复用：模式洞察报告的纯函数测试、事实构建测试、`PatternInsights` 的渲染与回调测试、交易库绩效汇总的币种/排除测试、交易回合 IPO 成本与重复证据测试，以及现有交易库和统计总览的浏览器验收。

## Out of Scope

- 不做实时行情、盘中监控、自动交易、选股、收益预测或风险承诺。
- 不把“新股交易”扩展为根据上市日期识别所有新上市股票；没有 IPO/申购/配售证据时不强行判定。
- 不重新解析原始 PDF、修改成交、重建交易回合算法或更改现有费用/成本口径。
- 不在本期引入 AI 自然语言解释、心理状态推断、自动确认标签或从图表推断交易规则。
- 不把不同账户、实盘、模拟运行或不同币种在缺少明确范围/汇率时合并成一个金额结论。
- 不对市场、IPO、分布桶进行交易建议、择时建议或因果排名。
- 不做用户可配置的任意分箱算法、任意阈值编辑器、导出图片或报告分享。
- 不要求完整行情才能显示收益分布；但路径类指标缺失时不以零填充。
- 不新增云端存储、多设备同步或远程 issue/消息发布。

## Further Notes

- 这项设计沿用项目中“持仓回合”“标准化证券”“已确认标签”“实盘/模拟运行”“费用后净盈亏”“计划风险 R”和“行情覆盖完整性”等术语。交易性质与模拟运行必须继续隔离，不能因新增图表而跨运行合并。
- 图表默认先显示跨币种仍可比较的收益率和比例指标；金额指标按现有原币/CNY 可用性展示。金额不可用不应阻断收益结构分析。
- “小/大”四桶是帮助用户阅读分布的当前样本分层，不是风险等级。所有桶和诊断旁边都要显示实际分界值、样本数和可点击的交易明细。
- 正式洞察仍遵守现有至少 3 个可比较样本、5 个样本才可用、10 个样本才可标记高可信度的分层；本规格新增的结构诊断另有最低 5 个正向/负向样本门槛，二者不互相替代。
- 新股分类需要保持“证据优先、缺失即未知”的原则。尤其要保护现有 IPO 成本链、执行背书和重复资产表证据的语义，不能为了让分组看起来完整而放宽判定。
- 本规格按无访谈要求直接采用最高 seam 的实现假设：统计报告生成器负责口径和证据，`PatternInsights` 负责展示与跳转。若实现阶段发现现有报告输入无法承载 IPO 三态证据，应先扩展事实模型和测试夹具，再接入页面，不把判定逻辑下沉到组件。
