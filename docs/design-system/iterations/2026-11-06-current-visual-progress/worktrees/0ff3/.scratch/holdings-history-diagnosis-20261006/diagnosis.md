# 今年持仓市值与盈亏空图：根因与验证

日期：2026-10-06；版本：63690a4；预览：[本地 review](http://127.0.0.1:3031/)。

## 结论

空图由历史持仓证据不足与全组合完整性门槛共同造成。历史计算已完成，有 279 个今年日期点，其中 271 天有已知市值/盈亏小计，但完整市值点与完整盈亏点均为 0。顶部当前市值与浮盈亏另受过期报价影响；它们不是同一个计算口径，也不能只用“行情还在加载”解释。

### 1. 今年历史图：旧仓证据持续阻断完整性

历史回放纳入全部已发生交易，不只当前未平仓回合。7 个美股标的 UVXY、QID、NVDA、ROKU、SQ、ABNB、AFRM 的台账含 `ambiguous-opening`；513010 则有未核验负仓方向。这 8 个标的在今年 279 天都无法给出可信数量。历史引擎只在数量已核验且为零时退出持仓，因此未知数量不会被当作零清除。依据是 [历史数量与清仓判定](../../app/lib/reviews/trading-room-history.ts:678) 和 [首次卖出产生 ambiguous-opening](../../app/lib/replay/position-ledger.ts:346)。这是保护不完整交易证据的规则；不能为了画图把未知仓位擅自归零。

每个日期的总市值可用条件是 `holdings.every(h => h.marketValueAvailable)`；浮盈亏另要求所有仓位成本可用。只要一个历史仓位失败，该日全组合指标就不完整。见 [点级完整性](../../app/lib/reviews/trading-room-history.ts:849)。图表的 [seriesValue](../../app/components/dashboard/room-holdings-history.tsx:104) 随即对不完整点返回 `null`，包括原币模式的 CNY/USD/HKD 曲线。因此，即使某币种有已知小计，该日曲线也没有值。

浏览器选 2026-09-14：15 个历史仓位仅 6 个市值可用，仍能看到 CNY 194,501.40、USD 1,551.99 的市值小计；未实现盈亏小计 CNY -4,078.52、USD +188.99。真实模型与这些值逐项一致。另有 516780 在 2026-05-22 红股公司行动之后被历史路径按未支持公司行动处理，使 138 天的数量/成本不可用；当前投影能恢复该标的数量与成本，两条路径的规则存在差异。

### 2. 当前市值/盈亏：报价存在，但全部过期

原业务库和隔离副本均有 153,425 根日线，全库最晚日期为 2026-09-28。当前 8 个持仓报价全为 `stale`：518880、512480、159813 止于 09-28；603087、516780、588080、SNDK 止于 09-15；513010 止于 2024-04-02。当前 7 个仓位数量/成本可信，成本小计与截图一致，但所有市值/盈亏均不可用；513010 还存在数量/方向证据问题。

当前 [quoteFreshness](../../app/lib/reviews/trading-room-holdings.ts:233) 以自然日差判断过期，默认阈值 3 天，并非按交易日历扣除休市。历史报价则按 [markFor](../../app/lib/reviews/trading-room-history.ts:450) 检查应有交易日；例如项目日历中沪深要求 09-30，但最新 09-28 的标的仍缺 09-29、09-30，不能跨缺失交易日沿用。

### 3. 缓存不会因开页或历史计算自动变新

workspace 启动 [hydration](../../app/components/trade-review-workspace.tsx:2854) 读取本地 SQLite 日线与 coverage，更新 React 中的行情状态；没有调用 [行情 provider 同步入口](../../app/components/trade-review-workspace.tsx:3374)。`持仓历史正在更新` 表示重算历史模型，不表示正在下载行情。提示消失后仍为空，是计算结果不完整。原库与副本日线数量和截止日期相同，排除了预览备份漏拷行情的解释。

## 可重复反馈与单变量对照

脚本只通过 `DatabaseSync(..., {readOnly:true})` 读取隔离 DB，直接加载产品计算函数，无迁移、外部行情请求、产品代码更改或 DB 写入。

```sh
node .scratch/holdings-history-diagnosis-20261006/diagnose.mjs
node .scratch/holdings-history-diagnosis-20261006/diagnose.mjs --expect-readable
```
