# 03 — 新股、非新股与无法判定拆分

**Parent:** `trade-outcome-distribution-insights` 父规格

**What to build:** 用户可以把收益结构切换为新股 IPO、非新股和无法判定三类，查看每类的样本覆盖、收益分布、胜率与赔率，并追溯到具体的申购/配售证据。

**Blocked by:** 01 — 收益结构基础：分布、胜率与赔率

**Status:** completed

- [ ] 基于同账户、同标准化证券、同市场的正数量 IPO 配售/获配事件或执行背书，生成新股分类
- [ ] 明确普通成交且不存在库存缺口的回合分类为非新股；初始持仓、历史缺口、事件冲突等分类为无法判定
- [ ] 去重成交与资产表中的重复 IPO 证据，不重复计入样本、敞口或成本
- [ ] 新股、非新股、无法判定组显示样本数、胜/负/平、总胜率、非持平胜率、平均/中位结果、赔率和分布桶
- [ ] 无法判定组保留在覆盖提示与详情中，不偷偷归入非新股；不完整 IPO 成本链不得进入正式收益比较
- [ ] 展示 IPO 证据来源和无法判定原因，并支持打开对应回合
- [ ] 补充 IPO 分类、重复证据、普通二级市场交易和历史缺口测试
