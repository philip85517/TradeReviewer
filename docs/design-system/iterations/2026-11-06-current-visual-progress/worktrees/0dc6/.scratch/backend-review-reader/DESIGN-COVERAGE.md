# 内容与交互覆盖契约

用户本轮原话为内容规范；视觉与评论参考：docs/design-system/baselines/2026-10-22-homepage-v2.5/visual-spec.html、review-client.js、review-client.css；协议依据 tools/document_review/API.md。原稿副本 before/ 是改写的事实边界。

|ID|需求与参考|owner|旅程与证据|
|---|---|---|---|
|R01|现状／目标分开，独立文档及评论身份|阅读器/root|切换文档，评论不串；刷新返回|
|R02|非技术正文：每章结论、业务影响、分层论据|文字/root|前言→术语→功能→链路→模块；独立内容审查|
|R03|技术详情可展开，保留源码和证据|文字/阅读器|展开与折叠；源对象与诊断引用可查|
|R04|集中术语说明，中文为主，英文名仅技术定位|文字/root|专业词均有定义，主结论可独立阅读|
|R05|目录定位、当前章节、深链接|阅读器/root|全部章节目录；点击、键盘、刷新定位|
|R06|选文字评论、保存、重开／刷新、导出|阅读器/root|真实选区→保存→磁盘→另一文档→返回→刷新；隔离评论目录测试|
|R07|候选／事实／待决定区分，六项决策仍开放|文字/root|源文逐项对照，不能自动关闭决策|
|R08|桌面和窄屏可读，正文不挤满术语表|阅读器/root|1440×900、1280×800、720断点两侧、390×844；视觉独立看图|

布局采用参考稿深色、左侧目录和右侧正文；桌面正文约900–1032px、正文17px/1.8，段落结论突出。技术详情默认折叠，打开后正常向下展开，不能遮住正文或评论。允许因内容类型省去图稿演示；不复制首页产品布局。无业务数据、无交易写入；评论持久化仅写专用 JSON 目录。

评论流程复用参考稿既有客户端，保持其角色和错误恢复。全页登记含目录、双文档入口、详情、评论面板与条件动作；实际覆盖和未验证项另记，不因复用宣称全部通过。

本轮结果：R01–R08均有对应证据，详见[最终验收的控件与旅程覆盖表](FINAL-ACCEPTANCE.md#版本绑定的控件与旅程覆盖)。正文内容第2/3轮通过，阅读器第1/3轮通过。未来版本映射、后续实施复核等条件流程未启用，未以本轮结果宣称这些流程已完成验收。
