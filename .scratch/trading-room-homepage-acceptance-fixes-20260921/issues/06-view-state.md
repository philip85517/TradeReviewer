# 06 — 修复期间切换造成的视图重置

**What to build:** 切换范围时保留趋势或日历视图，日历下钻与主动编辑日期互不干扰。

**Blocked by:** 无 — 可立即开始

**Status:** completed

- [x] 日历中切换快捷期间、市场或筛选后仍为日历；过期的点/日期选择清理。
- [x] 日历下钻同步范围与摘要，但不主动打开自定义日期编辑器。
- [x] 只有更多期间主动展开编辑；应用/取消收起，快捷期间切换收起并清理草稿错误。
- [x] 日期无效不改变已生效范围；默认实盘及模拟运行隔离不回归。
