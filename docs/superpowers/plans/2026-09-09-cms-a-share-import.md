# A股招商银行导入实施方案

目标：将本批招商证券 PDF 接入现有导入流程，仅接受境内 A 股与 ETF；用户可见格式名为“A股招商银行”，保留 china-merchants 来源标识与旧数据兼容。

设计：声明式表头 schema 驱动通用 PDF 表格读取，招商适配器负责章节、账户与业务语义，导入范围独立控制。保留已有合并文本布局适配，新增独立列布局；不依赖文件名、真实账户、年份或页面绝对位置。缺列、未知业务、无账户必须有诊断。只有日期，不伪装成交时刻。

- [x] 通用表格模块通过标签定位，按列对齐读取，支持跨页与拆分文本；招商适配器与旧版布局分离。
