## 执行顺序与职责

1. **依据与范围对齐**：本次完成；原型确认和传播验收拆开记录。
2. **表格与持仓一致性**、**历史到单一贡献区完整动线**、**交易库与共享规则一致性**：三组已分别派发给 Luna 5.6 MAX 独立推进。需要改共享正文时由 root 串行整合，避免覆盖。
3. **累计整合与独立验收**：依赖以上三组证据。统一正文、共享手册、关联图稿和评论映射后再宣称整个修订完成。

root 负责全篇视觉一致性、评论与阅读链路；每组任务正式派发时按项目流程由 Luna 承担有界修订，独立复核不得由该组实施者代替。当前正在修订文档与图稿，未启动产品开发；各组报告不替代 root 验收。
