## 任务提案

### 01 — 交易室统一分类与统计范围

**What to build:** 打开交易室默认看到实盘、全部分类、本月；能切换A股股票/美股股票/港股股票/ETF，筛选与指标采用统一范围。
**Blocked by:** None — can start immediately.

- [ ] 开始实现前核查ETF元数据来源和覆盖，形成可审阅分类证据；四类互斥，ETF只计一次，未知类型不伪装股票，不修改证券原身份。
- [ ] 冻结统一范围与金额展示输入契约，明确无汇率/部分缺失/完整汇率快照状态；后续日历、指标只消费该契约，不自行拉取汇率。
- [ ] 默认实盘、全部、本月；未知来源不混入；模拟盘先选运行且运行隔离。
- [ ] 自然月/近3个月/今年至今/自定义边界、来源交易日明确；高级筛选折叠。
- [ ] 可信净盈亏、回合数、排除样本一致；尚无汇率时分币种展示，不伪造跨币种总数。
- [ ] 空数据、无当期交易及跨年有可观察测试。

### 02 — 数据管理入口与首页导航

**What to build:** 四项一级导航可用，导入、行情更新及明细集中到数据管理，交易室不被运维控件挤占。
**Blocked by:** None — can start immediately.

- [ ] 我的交易室/交易库/模式洞察/数据管理可访问。
- [ ] 导入、更新、取消、失败重试和未完成恢复沿用原功能，移动入口不改写交易逻辑。
- [ ] 从复盘返回保留交易室状态；桌面与390px入口可用。
- [ ] 与现有导入及刷新流程回归，禁止以隐藏入口代替迁移。

### 03 — 最新汇率与人民币总体估算

**What to build:** 全部分类显示四类去重合并的人民币估算，数据管理可查看汇率来源、更新时间并手动刷新。
**Blocked by:** 01 — 交易室统一分类与统计范围；02 — 数据管理入口与首页导航。

- [ ] 核实中国银行真实来源、字段、每百单位与时点；不能将受控测试结果当真实接入成功。
- [ ] 最新汇率持久保存；每日首次打开自动尝试一次、手动可刷新，无历史汇率库。
- [ ] 失败沿用注明日期的旧值，无可用汇率保留原币并提示不能完整汇总。
- [ ] 同屏各金额使用同一快照，来源刷新有界、并发去重、不会污染原交易。
- [ ] 展示原币和估算标识；验证两次成功刷新、失败、缺币种及同日重复打开。

### 04 — 盈亏趋势与三级日历

**What to build:** 在同一业绩范围下切换趋势和日历，月/年/全部年份可下钻，顶部与摘要同步。
**Blocked by:** 01 — 交易室统一分类与统计范围；03 — 最新汇率与人民币总体估算。

- [ ] 趋势累计末值与同范围摘要、日/月/年汇总一致；无汇率按币种保留真实语义。
- [ ] 月看每日、年看12个月、全部年份看历年；切层与翻月同步全局期间。
- [ ] 近3个月切日历保留期间并显示3个月汇总，点月后下钻。
- [ ] 自定义期间保持实际覆盖日，点日格只展开详情；未来日不显示零收益。
- [ ] 分类/性质/运行切换清除失效详情，零盈亏、无样本与不可计算区分。

### 05 — 当前持仓与准确复盘入口

**What to build:** 首页展示当前持仓，按市场分组及最近成交排序，点击进入准确持仓回合并返回原状态。
**Blocked by:** 01 — 交易室统一分类与统计范围。

- [ ] 业绩日期不会隐藏早期开仓但仍未平仓的持仓。
- [ ] 分类/性质/账户过滤有效，ETF保留真实市场；同证券不同账户不混仓。
- [ ] 实现前核查估值来源与时效字段，记录证据；数量、可用成本、报价时间、估值缺失/过期状态清楚，不伪造当前价。
- [ ] 已导入数据截止可见；复盘进入确切回合并返回正确范围。

### 06 — 交易成本收益率与自然月胜率趋势

**What to build:** 未填本金也能查看交易成本收益率，收益质量区域展示按自然月的胜率变化及样本数。
**Blocked by:** 01 — 交易室统一分类与统计范围；03 — 最新汇率与人民币总体估算。

- [ ] 实现前核查买入成本及费用口径并记录证据；成本收益率的分子分母使用同一批完整回合，买入早于期间仍纳入该回合完整成本。
- [ ] 缺成本、非正成本、暂不适用做空同时排除分子分母；不累加百分比。申购/期初持仓/拆股等不能只用买入成交简单相加，缺乏可验证成本证据时排除并解释。
- [ ] 自然月胜率显示分子/分母；持平计分母，无样本为缺口，部分月份注明覆盖日。
- [ ] 全局比率用合计分子/分母；跨币种无完整汇率时不伪造总体比率，汇率可用后按同快照换算。
- [ ] 不输出账户收益率或跑赢大盘结论。

### 07 — 四类本金保存与参考收益率

**What to build:** 独立录入四类本金与币种，重新打开仍保留，并按完整范围显示本金参考收益率及总体汇总。
**Blocked by:** 03 — 最新汇率与人民币总体估算；06 — 交易成本收益率与自然月胜率趋势。

- [ ] A股/美股/港股股票及跨市场ETF四类互斥，币种可选，默认CNY/USD/HKD/CNY。
- [ ] 金额必须为正；持久化使用独立设置契约，不覆盖图表设置或原交易；实模拟/运行配置隔离。
- [ ] 总体包含已配置但当期无交易的本金；相关有交易分类缺填时提示并回退成本收益率。
- [ ] 市场、账户、标的等细筛使本金范围不匹配时回退成本收益率；仅切日期可沿用本金。
- [ ] 1万元两回合各赚100元：成本收益率1%，本金参考收益率2%；两类本金各10万仅一类交易时总体分母20万。
- [ ] 保存失败不可假成功；币种切换不静默宣称等值换算；刷新后配置仍一致。

### 08 — 数据质量摘要与可执行问题明细

**What to build:** 首页简洁说明哪些结果可用、哪些受影响，点击进入数据管理定位原因及下一步操作。
**Blocked by:** 01 — 交易室统一分类与统计范围；02 — 数据管理入口与首页导航；03 — 最新汇率与人民币总体估算；05 — 当前持仓与准确复盘入口；06 — 交易成本收益率与自然月胜率趋势。

- [ ] 交易可信度、持仓行情、历史K线、汇率分别说明，不用请求失败数代替统计质量。
- [ ] 历史K线缺失不误报已平仓盈亏无效；交易费用缺失不可被完整行情掩盖。
- [ ] 影响范围、样本、原因、时间与可重试/需补数据/源不支持动作对应。
- [ ] 互斥状态分类与独立重试队列清楚，部分可用不统称失败。

### 09 — 独立Luna QA与集成交付

**What to build:** 对最终界面逐项执行spec验收、记录缺陷并复验，交付协调者独立确认的可用预览。
**Blocked by:** 01–08全部完成。

- [ ] QA为独立gpt-5.6-luna / max，不参与产品实现，按spec独立构造反例。
- [ ] SQLite一致性备份/独立测试库及端口；正式交易哈希前后核对不变。
- [ ] 桌面与390px真实浏览器验证默认态、筛选、所有日历层级、本金保存、汇率失败、持仓复盘返回、数据管理入口。
- [ ] 固定样本核对四类去重、分子分母、全局汇总、实模拟隔离、未知数据及交易日边界。
- [ ] 开发者完成各自定向测试；协调者集中运行全量单元、类型、构建与必要运行时回归，保留失败记录。
- [ ] 缺陷交还原负责人修复，QA复验；协调者亲自验收关键路径，不只引用代理报告。
- [ ] 最终真实浏览器检查的可点击预览、仍运行服务、启动说明和已知限制在当前聊天交付。
