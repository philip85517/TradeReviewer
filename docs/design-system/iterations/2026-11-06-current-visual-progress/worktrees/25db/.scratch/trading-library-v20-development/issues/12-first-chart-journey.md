## Scope / What to build

一条实盘主动回合和一条模拟内部配对→遮住未来→下一根/播放/下一决策→Text→回看早期→保存/关闭/reload重开。

- 接入已有真实图表和复盘容器，不建第二套系统；以批准的human-action识别契约构造回合，配对不跨练习，原始成交数量与配对部分分列。
- 100+50买入→卖80形成1主动回合、2分配、余70；再卖70形成第2回合、累计3分配；同一动作技术拆单不加回合/重复费用。
- 完整执行REPLAY-STATE-CONTRACT各动作与双截止、Text归属、暴露来源、视野/轴边界及保存失败恢复；原始历史结果不能在早期状态出现。
- 协调者亲自操作真实图表看到推进目标bar/trade、跨初始视野仍可见；独立非实现者同态看图。首道门槛未接受，不扩展依赖图表/状态/布局契约的切片。

本票是独立开发任务，不是wayfinder决策子票。ready-for-agent表示范围已描述；所有依赖accepted且closed、具体接口/待决交互冻结后才能领取，禁止实现者填补业务政策。局部接受不代表功能整体接受。

本票由INTEGRATOR把新身份接到现有真实回合入口与票10最小练习读取容器，直接选择准确round/pair并返回；不等待票13/14的最终E布局，也不能借mock入口证明保存链。
