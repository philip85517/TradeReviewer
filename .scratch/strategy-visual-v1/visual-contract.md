# 策略台视觉方案 V1.0 · 设计产物契约

范围：用户要求扫描历史原型/聊天/文档并结合当前公共控件完成视觉设计。仅设计文档与可浏览 SVG 画板，不修改 app、数据库、真实回测逻辑。新视觉为待评审方案，不改写历史审批。

主参考：docs/design-system/baselines/2026-10-22-strategy-workbench-v1.0/source/history/H03、H04、H06–H10；全站 docs/design-system/baselines/2026-10-22-homepage-v2.5/source/visual-design.candidate.md 与 component-manual.html。参考冲突：H06 完整观察/外层滚动优先于 H05 旧单屏预算；V2.5 全站 tokens 优先旧颜色字号，但首页专属导航72/顶栏64不强加策略台。

协调者：root，负责全页一致性、信息架构与状态/持久化设计。画板制作：Luna。独立视觉审查：未制作画板的 root 直接看图；文档集成再由独立代理检查。无产品接线工作。

视口：主画板1440×1000（完整内容，首屏900另核对），紧凑桌面1280×900，窄屏390×1100；图为设计画布，非历史运行截图。历史H09是1440×900，H10是390×844，缩放/DPR以H06历史记录为准，本轮不重新宣称历史环境。新稿浏览器100%、DPR1或工具实际值记录。

几何：全局导航折叠54/展开200沿用融合契约；主画板用折叠54，顶栏48，主内容边距24、最大1240，页外滚动，不能固定100vh裁内容。工作台身份→组合→四项摘要→日期/阶段→图表+320检查区→回放固定槽；图区净绘图区360（1280最低320），不删状态内容凑屏。四项摘要采用88高的连续分隔带（本次明确视觉适配），常规数据字28/34。观察/结果/比较复用身份/日期基线。窄屏全局导航改顶端菜单，图区先、检查区后，KPI2列，44触控命中，图280，重要文字折行。

颜色：背景#0B1019，面板#111A26，抬高#162233，描边#283448，主文#E6EDF7，次文#A8B6CB，弱文#71829B，动作#6CA8FF，聚焦#A9C8FF，正#53D7A0，负#FF8592，警告#FFC66D。系列身份蓝/紫/青/橙，收益红绿不能当策略身份。字24/32标题、18/24区块、14/20正文按钮/数字、12/16辅助；间距4/8/12/16/24/32，圆角6/8。表头40行48，按钮36，命中不随字号缩小。不要渐变发光装饰。

内容：中文用户语言；画板数据标注为虚构示意，不新增产品演示工具。保留策略库与我的实验、3类包、锁定版本、4步向导、T0未建仓、推进显露新K线/成交、回看已看后续警示、结果截止/共同区间、错误保留旧进度。库不放“用于新实验”。回放是观察策略自动执行，不放手动下单。完整说明在正文，画板不夹工程术语M_i等。

设计验收：画板与文字状态一致；参考阅读记录/逐元素映射齐全；所有图片浏览器可读，无遮挡关键价格/说明；目录、图放大、分镜、返回和评论入口可用。产品功能/真实图表/数据库/物理触摸不在本次设计交付范围，后续产品验收仍NOT VERIFIED。
