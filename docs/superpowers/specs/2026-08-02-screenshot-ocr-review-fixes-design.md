# 截图交易校对视觉与 OCR 修复设计

日期：2026-08-02  
状态：已确认

## 目标

修复截图交易校对页的两个问题：长 OCR 文本穿透表格列造成视觉重叠，以及部分长图/低对比度截图无法识别。

## 根因

- 截图成交表采用固定布局和不换行文本，但单元格没有截断溢出；时间字段一旦包含多段 OCR 文本，就会覆盖来源图片和重复/冲突列。
- `anchorTradeRows` 使用图片高度的 4% 作为行内关联窗口。对长截图而言，该窗口远大于一行，会把多笔成交聚合到一个 draft，时间列因此串联多组日期和时间。
- OCR 处理只有灰度/反相这一条路径。某些截图在该路径下没有有效检测结果时，整张图片直接进入失败状态，没有原始颜色备用识别。

## 设计

### 表格显示

字段值使用可收缩容器和值节点，值单行省略，待确认标识保持固定宽度；所有数据单元格限制溢出。右侧证据抽屉继续展示完整 OCR 原文，不丢失校对信息。

### 行重建

行内候选关联窗口改为根据 OCR 文本框高度计算，并限制最大值，避免随整张图片高度放大。时间字段只保留当前行中最合理的日期/时间组合，避免把跨行内容串成一个字段。

### OCR 恢复

每个切片先执行现有深色界面增强路径；若结果为空，再对同一切片用原始颜色重新识别并合并结果。每个切片识别结束后立即清空 canvas。原图预览在失败状态仍可使用，便于手工补录或重试。

## 验证

- 测试长图行关联窗口不会把相邻成交聚合。
- 测试时间字段不会串联多行时间。
- 测试增强 OCR 无结果时会触发原始颜色备用识别，并正确合并坐标。
- 测试交易表包含防溢出结构和可访问的完整值标签。
- 运行相关 Vitest、类型检查和 lint。
