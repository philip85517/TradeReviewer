# 经用户确认的问题修复契约

依据：用户“确认，并进行迭代修复，并按照验收标准进行验收，直到通过”；上一轮README及11问题票建议规则均获本轮实施授权。这是现有控件有界迭代，不重构框架。docs/design-system/drawing-selection-feedback.md中默认1:1、200ms短确认、颜色、阶段/截止、原文、只读和持久化原则保留。下列针对已确认问题的变化覆盖旧“不改创建流程”的局部范围冻结。

1. Escape依次退出当前编辑/取点、拖动、未完成创建、闲置选中；不得改已保存数据。取消拖动恢复原图和此前选择，无历史命令。空白取消不提交空草稿，切工具清除未完成创建；有内容草稿保护不丢失。
2. 双点类工具支持第一点→动态预览→第二点确定，同时保留按住拖动→释放的快捷流程；小于3px的单击只确定第一点，不提交零长度对象。通道先基线两点，再确定平行宽度；每步有预览/简短状态，Esc和切工具清理。preview不持久化，释放/第二点只提交一次。
3. Text默认价格批注：先图上定锚点→连接线与标签随指针预览→第二点固定标签并编辑→完成；可按住拖放完成位置步骤。自由文字从明确模式切换进入；已有水平“价格标注”仍保留原语义，避免迁移旧数据。价格批注展示精确锚点价格与bar时间，不泄露截止外信息。框移动不改锚点；锚点移动不改框与正文。完成新文字后回选择；已有调用方若无切工具callback需接入真实workspace，不能仅mock。
4. 正文仅一套布局：普通/选中不改变换行、完整原文、宽度和行高；编辑时隐藏底层正文避免重复。保留已存300/180宽，编辑器可以是独立浮层；主操作常驻、样式入口可见，窄屏内可达，不以隐藏全文或缩字号塞下。正文14px/1.5沿用；展开/收起为紧凑chevron，细指针点击范围至少24px、粗指针44px，视觉保持小。
5. 选中柄视觉8px保留，Text移动柄细指针命中24px作为本轮可用性校准，粗指针44px；邻近目标有明确优先级。二维锚点move/grabbing，单轴价格ns-resize、时间/宽度ew-resize；拖动整个期间与释放/取消后光标一致。无虚假缩放柄。
6. 更多工具浮层脱离overflow裁切，视口内定位；七项鼠标可达，选后收起，外点/Esc关闭并返回焦点，不穿透画布。整体工具栏宽度/位置保持。
7. 箭头按向量绘制真实箭头，圆形选择柄不能替代方向；小尺寸风险/回撤线标签用有背景的紧凑分组，保留全部重要价格与比例，不改真实价差/坐标。选中/拖动不盖住操作柄，边界内可读。
8. 所有图形动作保持phase、market/execution cutoff、可见bar、计划与盈亏色不变；只更新所选工作图。创建/移动一次一个命令；选择/hover/动画/preview不持久化。隔离留存→返回→重进→刷新验证。

验收按DCA01–11原票逐项反例，工具T01–12，共享C01–18保留已有NV分母并补测受影响项。真实浏览器按住中间帧与系统光标，允许使用用户已明确授权的Playwright辅助浏览器验收（不把程序合成事件等同实体触控）。测试自动化不替代看图。
