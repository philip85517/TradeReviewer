## 验收标准与反例
- [ ] 防止业务数据库误访问，固定并验证源身份，私有复制，源与副本前后验证；计时不隐藏展示验证。
- [ ] 明确方案边界和完整内容，提供多次可复核对照；实际浏览器首屏、导入接线和一秒目标不冒充通过。

## 验收证据
第 1 轮测量工具自测 16/16 通过，但协调者与 Luna 独立审查发现计时和证据保存不满足设计，**未验收**，没有执行真实样本。问题及进入第 2 轮的修正范围：

1. 历史补录通常落在后续页面，而候选只计到第一页；目标记录实际读到及核对的时间被排除。
2. 重启时原连接仍打开，且“关闭期间更改展示信息、拒绝旧缓存并刷新”未实测。
3. F/C 在同一连接与文件上先后运行，第二次会受到第一次缓存预热的影响；与独立副本对照设计不符。
4. 样本全部运行结束才写结果；中途失败会丢失已完成样本的回执，无法完整复核。
5. 总耗时在最终报告写入前结束；重启子进程未验证完整冻结代码；进程环境注入检查发生在 Node 预加载之后，不能证明启动环境已受保护。

第 1 轮 [独立审查报告](../reviews/measurement-01/REPORT.md) 另指出部分筛选组合及真实数据见证缺失，已并入第 2 轮。第 2 轮在新候选目录保留历史证据，统一补测试、修正后重新独立验收；最多 3 轮。财务、Bars、重复导入保持暂停。
