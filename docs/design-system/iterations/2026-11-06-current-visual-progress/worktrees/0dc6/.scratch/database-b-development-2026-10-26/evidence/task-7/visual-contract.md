# 数据库 B：桌面导入与读取接线的视觉和交互契约

**本票改变保存协议，并补齐必须由用户明确选择的状态；保留现有导入界面的阅读顺序和空间安排。** 没有新增整页视觉改版授权。最终功能、持久化闭环和视觉需分别验收；本文件是实施前约束，不是通过证据。

## 依据和责任

- 规格：`docs/backend-design/database-module-design.candidate.md` 第5.3、6、8、9节；现有 `app/components/import/import-confirm-dialog.tsx` 和 `app/globals.css` 的对应状态与尺寸。
- 工作区：现有隔离 worktree；基线源码位于本功能 `evidence/baseline/`。最终截图必须绑定最终内容 manifest。实施前两组桌面截图及源码绑定见 before-desktop-observations.md / before-manifest.json；新协议最终渲染仍待对照。
- 整页视觉一致性及集成负责人：root；跨客户端/API/持久化闭环负责人：Task7 Sol。独立视觉审查：Task7 专属 Luna（不得参与实现）。
- 触发：本票影响导入控件、保存和刷新状态接线。检查范围为导入入口、确认框及条件选择、修订入口、交易库返回与重载、首页事实读取；不宣称整个前端100%。
- 范围：财务及 Bars 实现保持暂停，完整首屏一秒仍未验证。鼠标、键盘属于本次桌面验收；物理触屏和真机软件键盘不属于桌面操作承诺，不能用窄屏冒充。

## 信息顺序与空间

**审核顺序是“本次文件和范围 → 服务器计划的实际影响 → 必须选择的冲突与缺行 → 保存结果”。** 页面不得显示浏览器自己合并的全库作为服务器计划。

|区域|现有依据|保持的约束|允许的变化|
|---|---|---|---|
|确认框|globals.css `.import-dialog` / `.import-confirm-dialog`|宽 min(720px,100%)；最大高 min(820px,100vh−48px)；桌面遮罩24px；标题/底部固定，正文内部滚动|按真实计划增加冲突/缺行区域；不能把确认和取消推出可达范围|
|标题和文件|`.modal-header`、`.import-file-summary`|标题18px；文件、范围可辨认；关闭键明确可用/禁用|增加计划准备/过期的简明反馈，不暴露内部JSON或SQL|
|摘要和候选|`.import-stat-grid`、分类区|文件、有效成交、标的、重复与未识别各自清楚；重复不等于删除|摘要改为服务器权威影响；未知保留未知|
|冲突与缺行|设计5.3、6.1|每组明确已有/本次；缺失每笔保留/撤回；撤回理由必填；未选择不得保存|增加可访问的选择、理由及依赖说明；不得默认自动撤回|
|保存/错误|设计6.2、9.1；现有`.import-warning`/footer|保存中阻止重复操作；失败保留输入；错误可见且可恢复；确认与取消不同|版本冲突重新准备；断线用原请求ID查证，显式显示状态未确认|
|返回/重载|设计6.3|权威刷新至少包含提交凭据版本；不把本地候选当已保存|刷新失败显示“已保存但读取未确认”及重试，不盲目再次提交|

## 对照条件与关键状态

**以桌面1440×900和1280×800为主要验收；现有确认框断点两侧补查，避免新增状态破坏既有布局。** CSS视口与截图像素分开记录。浏览器100%缩放，DPR以实际读数记录，不能推测。

|视口|状态|依据|
|---|---|---|
|1440×900 / 1280×800|空库、合成3笔预览、保存、列表/首页返回和重载、错误/冲突|桌面核心旅程与首屏层级|
|721×900 / 720×900|正常、冲突/缺行、长文本|现有统计五列/两列切换|
|561×900 / 560×900；390×844|确认框底部、长中文/理由、错误|现有560px底部和间距断点；辅助响应式检查，不替代桌面|

没有用户允许的视觉偏离。新增必须选择状态按上述已记录需求及现有风格审查；新增状态不冒充旧版同态截图。开始实现前由 root 取得当前代表性页面截图；最终独立审查直接看参考和实际渲染。
