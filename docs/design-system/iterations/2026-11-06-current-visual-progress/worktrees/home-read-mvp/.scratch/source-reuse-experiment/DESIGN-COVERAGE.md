## 执行步骤

1. 两个候选分别只写各自实验子目录；测试先于候选实现，按原有路径建立独立对照，记录失败和通过结果。
2. 独立审查检查实现、测试、边界和数据护栏；协调者复核，通过后固定版本再测量。候选不可行则保留负结果，不为了性能放松规则。
3. 真实规模测量采用已批准的冻结来源文件的私有只读副本，检查来源和副本身份及 sidecar，全部结果不记录原始业务明细。逐项报告一次性准备与测量边界。
4. 按独立候选和合并候选结果判断值得继续的路线；此次实验没有测量桌面页面完整首屏，不能声称达到一秒。
