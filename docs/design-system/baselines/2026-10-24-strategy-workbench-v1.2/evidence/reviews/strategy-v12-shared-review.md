## Findings

### SH-01 / P1 / 公共三包样例承诺参数编辑，但实际没有

证据：`sw04-package-slots.png` 三卡仅显示“参数：默认预设/选择后显示参数”，没有预设选择、参数值、单位、来源或覆盖入口。`shared/strategy-workbench-v1.2/manual.html:15` 图注声称“参数覆盖”，`:26` 声称“参数覆盖均有独立控件”；`build-samples.py:70` 仅静态text。V1.2正文 ASM01（source/visual-design.candidate.md:198）要求有效参数与单位、来源；:587明确“选包、看说明、改参数分开”。

建议：在公共SW04中给至少一个真实参数例（如周期20日、预设/覆盖、恢复预设、锁定只读）及错误保值样例，并明确编辑发生在哪个控件/层。不能只删除图注来掩盖业务必需的缺失。复用公共输入/选择器和基础八态，不新增另一套原子样式。

### SH-02 / P2 / 日期范围图文反向，静态截止又被写入Tab序列

证据：`sw02-date-time.png` 左侧6/14被选中、6/15–30全部灰化；右侧同一个6/14输入错误写“可用数据从6/17开始，请重新选择起点”。`build-samples.py:51` disabled if day>14，与`:55`错误范围反向。未说明左右属于不同数据范围，公共例应可直接理解。`manual.html:24`“Tab到日历、时区、截止”又与图中文字“系统计算·无选择入口”冲突。

建议：统一6/17起可用的范围（6/1–16不可选、保留无效旧值14并显示错误），或把正常/错误示例明确分为两种有不同范围的状态。只读截止不加入可操作Tab序列；如需焦点读取应明确非编辑语义而非隐式选择器。

### SH-03 / P2 / 排序边界与移除状态互相矛盾

证据：`sw05-multi-select.png`“位置2/3”时上移禁用、下移可用，图未给置顶/普通组边界；`build-samples.py:80`硬编码禁用上移。同时第三行没有勾选、标注“可选”，却有可用“移除”，`:79`只按disabled行决定移除禁用。

建议：首位边界例改为位置1/3，或保持2/3且允许上移；若组边界导致禁用，必须明确本组位置和禁用原因。未选行移除应隐藏/禁用，或改为“选择”；已选行才允许从当前选择中移除。若“移除”指删除策略，应使用不同动作和说明，不与checkbox选择混为一体。

### SH-04 / P2 / 无匹配公共样例仍重复放清除按钮

证据：`sw08-recovery.png`无匹配卡内有“清除当前筛选”按钮；`build-samples.py:107,110`。V1.2正文`:507` ERR02明确“无匹配由搜索尾部清空恢复…不在空态再堆一组相同清空按钮”。

建议：SW08同时画查询栏+尾部清除、下面无匹配说明，保持唯一入口；不把按钮放入空状态。否则策略页面无法同时遵循公共样例与业务正文。

### SH-05 / P2 / 向导图注声称的离开草稿样例缺失

证据：`manual.html:14`图注“已完成、当前、未到达、提交加载和离开草稿”，但`sw03-steps.png`只画前四类；`build-samples.py:59–64`无离开确认层。文字写“离开草稿先确认”不足以给出保存/放弃/继续编辑的视觉区分。

建议：补一个独立小样例展示离开草稿选择及默认焦点/取消方向，并让失败保留草稿有相应可见反馈；或链接公共已存在的精确确认样例。基础八态可继承，但该复合业务确认不能由普通按钮八态代替。

### SH-06 / P2 / 包详情示例混入实验独立本金

证据：`sw06-summary-detail.png`左侧明确标题“包详情”、身份“EMA20买入·v1.3”，却显示“独立本金¥100,000.00”；`build-samples.py:87`。正文ASM02(:199)规定包详情内容是用途/规则/输入输出/数据依赖/市场/预热/兼容；独立本金是WIZ05(:289)运行组合参数。

建议：把包详情内容换为参数/单位或预热要求（如周期20日、所需字段），金额对齐示例留给观察检查栏或运行资金摘要。视觉边界分清480包阅读层和320运行证据层。

### SH-07 / P3 / 已在最新日仍突出返回最新动作

证据：`06-observe.png`完成、当前9/13、已展开9/13、结果截至9/13时底部“返回最新日期”仍蓝色主按钮。`source/build-artboards.py:191`固定primary。功能未被实际运行验证，故不报告为功能失败。

建议：仅回看日期早于已展开日期时突出此动作；已在最新时隐藏或禁用并保留空间稳定。该项不阻塞本轮06静态布局接受，但应避免可执行性暗示。

## 公共基线接受证据

- 深色背景/面板、浅文字和蓝色操作的主语汇与首页真实参考一致；positive绿色、negative红色清楚。常规说明不再满屏彩色强调。
- 控件普遍36px、14px文字，日历/下拉/导航均为SVG图形；日期左齐，按钮居中，金额与摘要数值右齐。
- 06观察页保留图表最大面积，摘要先于运行状态、模式和图；320检查栏承载持仓证据，主图没有被恢复说明挤压。
- 06状态放大图把查看日与运行截止分开、净值/K线与工作模式分开，较早期“所有时间一个字段”风险有明显改善。

以上仅为所见截图的视觉结论。图像不能证明键盘顺序、焦点恢复、Tab禁用策略、按钮点击、触摸命中、真实播放揭示K线、请求幂等或数据持久化。这些 **NOT VERIFIED**；纯设计任务没有运行产品/database验收，不能宣称交互通过。未查看其他V1.2页面，不把本轮10图接受外推为全套22图接受。公共manual页面本身的响应式浏览器布局也未在本轮查看，截图是直接SVG。
