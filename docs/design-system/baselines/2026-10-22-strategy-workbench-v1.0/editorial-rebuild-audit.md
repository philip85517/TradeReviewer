# 2026-10-24 全文结构重建与逐章扫描

## 依据与方法

用户要求从零交代背景、目标和取舍，自高层向低层展开理念、流程、交互分镜和组件，按可读性组织段落与列表。本轮参考首页V2.5正文第一章“目标与取舍”、第二章“阅读顺序与视觉基础”、第三至七章“模块与跨页路径”、第八至十章“公共状态、组件和验收”及历史/接口附录。借鉴的是认知顺序，不移植首页的72/64框架、固定八行表或唯一全局修复。

本轮修改前原稿保存在 evidence/editorial-rebuild/before.md。开篇与所有叙事段落重新撰写，重新分配图与章节；保留14个精确规则块以避免改写中损失业务约束。保留ST01–ST14稳定锚点的主题身份，增加ST15整体布局、ST16实现验收。章节编号按阅读顺序排列，内部ID不充当读者标题。
