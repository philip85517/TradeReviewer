# 06 成本收益率与收益质量

## 已实现

- 新增 [trading-room-metrics.ts](/Users/zhoulin/.codex/worktrees/247d/TradeReview/app/lib/reviews/trading-room-metrics.ts)，导出 `buildTradingRoomMetrics`、`buildCostReturnSummary`、`buildMonthlyWinRate` 和 `TradingRoomMetrics`。
- 成本收益率只纳入可信的已平仓多头回合：方向已知、净盈亏可用、完整买入数量/金额为正、费用已知、结算币种一致，并通过期初持仓、转入/拆股/未知成本和 IPO 现金证据链门槛。分子使用同一批回合的 `trustedPnl`，分母使用整个回合的 `metrics.grossExposure`；期前买入、期内平仓仍纳入完整成本，未重复扣费用。
- 成本摘要的唯一下游入口是 `TradingRoomMetrics.costReturn`，包含 `costReturnPercent`、`netPnl`、`buyCost`、适用/排除计数、逐原因计数、回合 ID 和不可用原因。原币小计与 CNY 转换结果均由同一 `RoomFxSnapshot` 生成；跨币种缺完整 FX 时保留原币小计且不拼接比例，单一币种可直接计算比例。
- 月胜率按闭合来源交易日自然月汇总，持平进入分母；空月返回 `ratePercent: null` 并注明无样本，端点月份标注覆盖日期，总体使用合计胜场/合计样本而非月比例平均。
- 新增 [room-quality.tsx](/Users/zhoulin/.codex/worktrees/247d/TradeReview/app/components/dashboard/room-quality.tsx) 与 [room-quality.module.css](/Users/zhoulin/.codex/worktrees/247d/TradeReview/app/components/dashboard/room-quality.module.css)。概览默认可见成本收益率、合计月胜率和样本数；原币/CNY成本、净盈亏、自然月趋势、覆盖范围和排除原因放在默认折叠的收益质量详情中。
- 03 首页 FX 接线修正：生产工作区挂载即启动 `useFxRates`，外部 `fxSlot` 只替换呈现，不再阻止快照读取；新增首页/外部插槽回归测试。
