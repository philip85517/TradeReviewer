# 01 — 核心统计范围与收益摘要

**What to build:** 让用户进入“我的交易室”后，默认在实盘范围内通过紧凑控制条选择交易性质、资产分类和三个主要期间，并立即看到与该范围一致的核心收益摘要。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 默认进入实盘，提供清晰的“实盘 / 模拟盘”切换；选择模拟盘后必须明确选择一个模拟运行，不能跨运行合并结果。
- [ ] 提供“本月 / 近 3 个自然月 / 今年至今”三个主要期间 Tab，并显示当前期间的明确日期范围。
- [ ] 资产分类保持可见但不抢占期间 Tab 的视觉优先级；低频筛选收纳到更多筛选中。
- [ ] 核心收益摘要由统一范围驱动，至少包含已平仓回合净盈亏、可信回合数、胜率和当前适用的收益率指标。
- [ ] 将暂无样本、数据不足、无法合计与可用值区分展示，不把不可用结果伪装成 0。
- [ ] 所有用户可见金额、百分比、数量最多保留两位小数，底层计算精度不变。
- [ ] 通过交易室集成测试覆盖默认范围、期间切换、模拟运行隔离、分类筛选和摘要同步。
