## 验收标准

- [x] 右上角提供实盘、模拟盘、当前持仓的清晰入口；默认实盘；模拟盘不能跨运行合并；当前持仓不被误当作第三种交易性质。
- [x] 主筛选改为市场分类，不在主筛选展示来源未知；未知数据仍可在数据状态/数据管理中诊断。
- [x] 本月、近3个自然月、今年至今和更多期间的布局一致；更多期间点击后立即出现可编辑日期，并有应用、取消和无效输入反馈。
- [ ] 收益概览和趋势视觉上合并；净盈亏卡片不再出现密集长文本；摘要、趋势、日历共享同一范围和统计口径。
- [ ] 趋势图有横轴、纵轴、零基线，比例不变形；每个点可通过点击/聚焦查看期间收益、累计收益、样本和日期。
- [x] 日历显示金额、样本以及模型可可靠计算的胜负/胜率信息；分母无效时明确显示不可用，不新增未经确认的赔率算法。
- [ ] 负持仓区分合法空头和持仓证据待核对；行情不可用明确说明缺失、过期、日期、币种、价格或数据源原因，并提供现有数据管理动作。
- [ ] 桌面与窄屏无遮挡、无页面横向溢出；同级标签和控件的顶部对齐误差不超过 2px。
- [ ] 运行相关组件/模型测试、类型检查、构建和真实浏览器验收；使用隔离数据库，原始交易数据保持不变。

## 非目标

- 不自动修正负持仓或用零值替代未知行情。
- 不新增页面路由、持仓独立页面或全站视觉重做。
