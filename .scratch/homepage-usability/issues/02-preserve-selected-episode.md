# 02 — 从交易库进入复盘时保留选定回合

**What to build:** 用户在交易库选定一个持仓回合后进入逐笔复盘，打开的始终是同一股票、同一账户的该回合，并按现有规则恢复其回放位置。

**Blocked by:** None — can start immediately

**Status:** done

**Priority:** P1

- [x] 复现并修复：在华虹宏力选择第 1 次交易后进入复盘，仍选中第 1 次交易，不自动跳到第 4 次或最新回合。
- [x] 同一股票具有多个账户和多个回合时，跳转按稳定的回合身份定位，不依赖显示序号。
- [x] 已有回放状态时恢复目标回合自己的状态；首次复盘时按现有规则从安全起点开始，不暴露未来行情、成交或最终结果。
- [x] 目标回合失效时明确提示并提供重新选择入口，不静默切换到其他回合。
- [x] 增加有意义的交互回归验证，覆盖非最新回合、多账户回合和目标失效场景。

**Verification:** 见 [验收记录](../verification.md)。
