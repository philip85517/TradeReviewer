# 全文论述结构扫描与改写记录

本轮按2026-10-23用户要求，以“先建立论述结构，再安排规则、参数和引用资料”及“围绕标题、先总后分、说明目标与取舍”为全文标准。对象为导读和ST01–ST14；不重做已接受画稿，也不变更业务约束。

## 总体问题与重写结构

原文已有业务解释，但11个章节以图稿或分镜开场，读者先面对大图，后才知道要看什么。多个章节直接列操作，没有先提出设计目标；部分取舍只在第一章和末章出现。EXP、OBS、RES、CMP规则连续塞在单段中，公共控件章又把尺寸、色值、动效和交互混排。把它们折叠起来只降低首屏密度，不能建立论述。

改写顺序为：标题界定问题，首段提出目标与主张，后续段落解释信息顺序及选择理由，图例紧接相关说明，最后用分组规则落实约束。具体参数和引用留在所支撑的规则之后。各章按内容组织，不强行套相同小标题；保留已有章节锚点、元素ID、业务语义与画稿。第一章负责全局选择，各业务章解释局部决策，第十四章集中说明待评审事项和来源权重。

## 保护范围与验证方法

改写前快照保存在 evidence/editorial/before.md；原接受记录与视觉审查不覆盖。比对每个元素ID对应规则，核对时间边界、版本/归档、个人排序、独立资金、可比区间、异常恢复及全部公共参数；图稿文件逐一核对hash未变。构建后检查章节锚点、14处折叠、21图引用和两组三帧。内容独立复核记录在editorial-review.md；本文件最终追加逐章接受结论和未解决问题。纯文档范围不触发生产UI、数据库或物理触摸验收。
