# 后端双稿交互审查稿：最终验收

本轮交付是可阅读、可批注的两份设计文档。正文面向不熟悉技术细节的审核人员，展开内容保留专业人员所需的对象、字段、规则和源码证据。文档可供审查，不表示目标设计已获批准，也不表示产品故障已修复。

## 分开验收的三个结论

**内容通过。** 原稿链接和章节锚点保留；功能总图、完整链路、八个候选模块、六层校验、六项开放决策均经过独立核对。1,866/228 等历史实验数字仍明确限定于旧隔离快照，不能解释为本轮在线数据或耗时结果。详见 `evidence/independent-review.md`。

第一轮曾 FAIL：现状稿将代码条件 `!attached && !retired` 改写成中文“未应用或未停用”，扩大了缺口含义。第二轮仅修正正文与技术详情两句为“既未……也未……”，独立对照源码复验 PASS。第一轮记录保留，未重置轮数。

**功能与保存链通过。** root 在真实浏览器中使用鼠标、键盘操作阅读器，在隔离目录创建评论；读磁盘确认实际保存，并经过回复、暂不采用、明确重开、刷新、跨文档返回和服务重启后重新读取。两份稿件分别只显示自己的评论。JSON/Markdown导出均为HTTP 200，内容包含各自保存的意见。

**视觉通过。** 非实施者直接对照 V2.5 参考截图及最终截图，检查1440×900、1280×800、721×900、719×900、390×844。正文、长表局部横滚、展开详情、协作流程、桌面及窄屏评论面板未发现阻断。正文采用17px/1.8和更宽段落，属于为文档阅读授权的调整；没有复制首页产品布局。

## 启动与使用

在项目根目录执行 `BACKEND_REVIEW_PORT=3094 sh docs/backend-design/start-preview.sh`。脚本默认只监听127.0.0.1:3091；本轮3091由另一工作树的既有审查服务占用，默认启动按预期失败后，显式指定3094，未中断既有服务。正式评论保存于 `docs/backend-design/reviews/`。正文修改后先执行 `python3 docs/backend-design/build-review.py`，再重启审查服务。端口冲突失败退出，不切换业务服务或数据库。

正式入口：

- 现状：http://127.0.0.1:3094/backend-design/review/current/index.html
- 目标：http://127.0.0.1:3094/backend-design/review/target/index.html

正式服务的最终浏览器核对记录见 `evidence/final-preview.json`：两稿标题与入口正确，评论服务已连接、各自列表为空，桌面截图为 `final-current-3094.png` 与 `final-target-3094.png`；已保留当前稿浏览器标签供用户阅读，服务保持运行。正式目录不复制隔离验收意见。以上仅接受本轮文档交付，目标设计仍需用户逐项审查。
