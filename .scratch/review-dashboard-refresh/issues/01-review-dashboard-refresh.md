# 数据更新、复盘定位与统计总览迭代规格

Status: awaiting-seam-confirmation
Priority: high
Blocked by: 用户确认页面级验收边界

## Problem Statement

用户反馈全局更新入口不可发现；单股更新时界面反复跳动，左侧成交点击无法定位，日期已知却提示没有时间；复盘主界面缺少整体盈亏比，市场筛选缺少“A股”聚合，港股通覆盖需要核查；第一导航的逐笔复盘希望改成统计总览，提供复盘统计与周/月历史盈亏日历。

源码已确认全量行情更新及有界队列存在，按钮位于股票侧栏；主导航第一项是逐笔复盘；股票库按内部市场值提供选项。现有复盘汇总包含净盈亏、胜率和分组，但未提供平均盈利/平均亏损盈亏比，且多个分组时顶层净盈亏为空。抖动、具体定位失败和港股通遗漏尚未在当前运行页面复现，不能把推测原因写成已确诊问题。

## Solution

保留现有导入、行情队列、单股复盘和交易库能力，在全局头部提供常驻“更新全部数据”入口，并在导入完成处提供同一动作；明确更新标的元数据及行情，不重写成交事实。显示进度、部分成功、失败、取消与重试。

单股刷新采用局部状态更新，保留旧行情和交互状态。点击成交执行可见的定位与高亮，只有日期或小时行情无法可靠映射时切到对应交易日的日线，不虚构时刻。同一K线同方向的多个成交在视觉上合并为 B/S 加数量徽标，并可展开明细。

第一导航改为“统计总览”，交易库和模式洞察保留；单股复盘作为从总览或交易库进入的详情流程保留。总览和交易库共享筛选与统计口径，支持“A股”聚合、沪深细分及港股通来源筛选，展示复盘进度、收益质量和按周/月汇总的盈亏日历。

## User Stories

1. As a 个人投资者, I want 在任意主页面找到全局更新按钮, so that 新导入后能一次补齐数据。
2. As a 个人投资者, I want 导入成功后看到更新入口, so that 明确下一步操作。
3. As a 个人投资者, I want 看到全量更新涵盖的股票数和范围, so that 避免把筛选范围误当全部。
4. As a 个人投资者, I want 查看排队、完成、失败和部分完成进度, so that 了解更新是否仍在进行。
5. As a 个人投资者, I want 取消剩余更新并仅重试失败项, so that 控制等待且保留已完成结果。
6. As a 个人投资者, I want 更新中仍能使用已有行情, so that 不中断复盘。
7. As a 个人投资者, I want 连续点击不会创建重复任务, so that 避免请求浪费。
8. As a 个人投资者, I want 刷新后视窗、缩放、选中交易和画线保持稳定, so that 避免界面抖动。
9. As a 个人投资者, I want 切换股票时旧请求不覆盖新股票, so that 看到正确结果。
10. As a 个人投资者, I want 点击左侧成交便能看到对应图表节点, so that 核查买卖位置。
11. As a 个人投资者, I want 只有日期时显示日期及精度说明, so that 不会被误导为没有时间。
12. As a 个人投资者, I want 小时无法可靠定位时自动切至日线, so that 仍能定位已知交易日。
13. As a 个人投资者, I want 目标日行情缺失时看到补齐入口, so that 不被定位到错误日期。
14. As a 个人投资者, I want 精确时间成交在小时图上准确定位, so that 保留已有精度。
15. As a 个人投资者, I want 同一K线同方向多笔成交合并为B/S数量标记, so that 减少遮挡。
16. As a 个人投资者, I want 展开合并标记查看每笔数量价格和来源, so that 不丢失成交细节。
17. As a 个人投资者, I want 相同K线买入和卖出分别显示, so that 不混淆方向。
18. As a 个人投资者, I want 拆分成交只改变展示不改变记录, so that 核对结果保持准确。
19. As a 个人投资者, I want 看到平均盈利、平均亏损及盈亏比, so that 评估交易质量。
20. As a 个人投资者, I want 区分盈亏比和利润因子, so that 理解不同统计含义。
21. As a 个人投资者, I want 没有亏损或盈利样本时看到明确说明, so that 不把无意义数值当结果。
22. As a 个人投资者, I want 直接选择A股并可进一步选择沪深, so that 方便筛选。
23. As a 个人投资者, I want 单独筛选港股通并与普通港股区分, so that 检查是否漏记。
24. As a 个人投资者, I want 所有视图使用一致筛选范围, so that 统计能互相核对。
25. As a 个人投资者, I want 第一导航页是统计总览, so that 打开系统即可了解交易情况。
26. As a 个人投资者, I want 从总览进入单股或单轮复盘并返回, so that 保留已有复盘能力。
27. As a 个人投资者, I want 查看已复盘、待复盘、持仓中和已平仓数量, so that 安排复盘工作。
28. As a 个人投资者, I want 查看盈利、亏损、持平和不可计算样本数量, so that 解释指标分母。
29. As a 个人投资者, I want 按月查看盈亏日历并切换周汇总, so that 观察收益发生的时间。
30. As a 个人投资者, I want 点击日期查看对应已平仓轮次, so that 追溯日历金额。
31. As a 个人投资者, I want 周、月与选定时间范围汇总一致, so that 避免重复统计。
32. As a 个人投资者, I want 按账户、市场、币种和实盘模拟筛选, so that 避免混合不可比数据。
33. As a 个人投资者, I want 不同模拟运行分别统计, so that 避免回测叠加。
34. As a 个人投资者, I want 跨币种收益缺少换算依据时显示原因, so that 不获得错误总盈亏。
35. As a 个人投资者, I want 没有成交与尚未计算的日期不同显示, so that 识别数据缺口。
36. As a 个人投资者, I want 刷新和重载后统计可重复核对, so that 信任统计结果。
37. As a 个人投资者, I want 窄屏也能更新、筛选和查看日历明细, so that 在小屏完成同样任务。
38. As a 个人投资者, I want 收益颜色遵循现有涨跌配色设置, so that 保持视觉一致。

## Implementation Decisions

- 复用全量更新入口背后的队列、覆盖范围、持久化任务状态和单股更新流程；全局“全部”指所有已导入标的，不受当前市场或账户筛选限制，按标的去重。导入期间以已持久化集合建立批次快照，运行中新导入的标的明确提示需下一次更新。
- 延续现有有界并发、瞬时错误有限重试与退避；取消停止排队并尽可能中止在途请求，已完成缓存保留。状态反馈区占位稳定；禁止通过调高服务端额度或重复启动队列掩盖问题。强制更新需绕过应用缓存及浏览器HTTP旧缓存。
- 刷新不卸载重建整个复盘页面；只发布有效的新行情和元数据。保持当前股票、轮次、选中成交、可视区、缩放、滚动、绘图和未保存复盘草稿；用户显式定位可改变可视区。切股、切周期或取消后的过期请求不得覆盖新上下文。
- 日期精度与数据可用性分开表示：只有日期显示“仅日期，日线定位”；精确时间按交易所时区映射。date-only 使用来源交易日，不能把合成时间误当真实成交时间。小时映射不足时自动切日线并提示原因；对应交易日K线也缺失则明确缺口，不静默跳到邻近日。回放模式不得泄漏尚未揭示的未来成交。
- 标记按当前可见K线、方向及当前账户/实盘模拟范围分组；数量指原始可见成交记录数，不是股数。单笔显示B/S，多笔显示带数字徽标的B/S。点击列表高亮对应组且可展开原成交。视觉聚合不合并、去重或改写持久化记录。
- A股聚合沪市和深市，覆盖现有A股范围内股票及ETF，并保留交易所细分。港股通是交易渠道，不是新交易所；依据来源证据区分普通港股。不得凭五位代码猜测渠道；身份相同的港股若混合渠道，按成交/轮次的来源显示，跨渠道轮次明确混合来源，避免拆轮后重复计收益。
- 同一统计查询范围驱动总览、队列汇总和日历明细；保留账户筛选，并按实盘、模拟、来源未知隔离，模拟按运行隔离。兼容币种与性质范围内允许沪深聚合，不因内部市场代码不同使A股总值消失；不跨币种直接加总金额。
- 盈亏比定义为盈利已平仓轮次平均净盈利 / 亏损已平仓轮次平均净亏损绝对值；利润因子为净盈利之和 / 净亏损绝对值之和。两者明确标注，展示分母、样本数和费用口径。持平轮次不进入两侧均值；胜率使用盈利轮次 / 可计算已平仓轮次，包含持平于分母。
- 只有成本、费用、币种等足以支持净盈亏的已平仓轮次进入收益样本。未平仓、不完整历史、未知费用、跨币种待换算列出排除数量及原因，不当零值。无亏损或无盈利时比例显示不可用及原因，不返回误导的0或无限数。样本不足给出样本数。
- 日历第一版为“按平仓日归属的已平仓净盈亏”，每轮在最后平仓交易日计一次，部分卖出尚未全部平仓的轮次不提前计入此口径；不称为逐日账户净值或逐日盯市收益。日、周、月合计与同范围已平仓轮次一致。日期采用市场交易日，跨市场沿用各自交易日标签；周一为周起点，月按自然月，边界显示清楚。
- 日历区分无已平仓轮次、净值恰为零、存在不可计算轮次；点击日/周/月可追溯轮次与排除项，切换汇总粒度不改变底层样本。默认显示当月，可快速跳到最近有记录的月份。
- 统计总览保留交易库下钻及返回筛选上下文；复盘编辑、画线、导入、历史回放能力不移除。首次没有数据提供导入入口，有历史数据不默认展示演示数据。收益配色遵循现有用户设置。
- 不预设新增数据库表或外汇模型；先复用已保存成交、复盘状态、行情和来源证据。新增聚合由明确的领域查询负责，UI不各自重写计算口径。

## Testing Decisions

- 最高接缝为现有页面级流程：导入 → 全局更新 → 单股复盘 → 成交定位与分组标记 → 市场筛选 → 总览/日历 → 下钻和重载。用户确认前不标记ready-for-agent。复用现有workspace、侧栏、交易库、复盘图表、队列汇总、标记映射和更新队列测试。
- 使用SQLite一致性备份生成隔离测试库及独立端口；刷新、筛选、定位及统计前后逐行核对成交、人工修订、复盘和绘图，仅预期行情/元数据/任务状态允许改变。不能以正式库做写入验收。
- 页面可观察行为优先：全局入口在所有导航和窄屏可发现；三批以上标的实际更新、成功与失败混合、取消后恢复、仅失败重试、429有限退避和连续两次强制更新；数据及状态重载可见。
- 用可控延迟/多次进度回调复现抖动，检查滚动、图表可视区、缩放、选中成交和草稿在刷新前、中、后的稳定性；测试过程中切股和切周期，确保迟到响应不覆盖。实际浏览器录像或截图序列及交互验收补充自动化，不能只凭组件渲染次数判断不卡顿。
- 定位覆盖精确时间、date-only、小时缺失而日线存在、两级都缺失、不同交易所日期、同日多笔B/S、重复金额但不同成交、拆分交易和回放揭示边界。点击后断言目标日/节点进入可见范围并高亮，而非只检查回调参数。
- 统计使用可手算夹具覆盖盈利、亏损、持平、未平仓、部分平仓、跨月平仓、日周月边界、费用未知、跨币种、沪深同币种、普通港股与港股通、账户和模拟运行隔离。日历汇总与下钻明细金额及轮次数守恒；同一轮次不因标记聚合或渠道显示重复计算。
- 港股通先核对导入后SQLite与页面筛选范围的标识/数量，区分真实遗漏、筛选隐藏和因收益口径排除；未经核对不能自动重导入。
- 实施后执行相关回归、全量单元测试、类型检查、构建及真实浏览器桌面/窄屏验收，记录实际工作区、端口和数据库；性能与视觉稳定性需用户可见交互证据。

## Out of Scope

- 本次to-spec只形成并发布规格，不实施产品改动或操作正式数据库；后续开发继续由Luna max执行、Astra协调验收。
- 不新增可转债导入、自动下单、OCR/券商扩展、外汇汇率服务、完整账户净值曲线、年化/夏普/基于净值的最大回撤或盘中精确成交时间推断。
- 不因总览替代第一tab而删除单股复盘；不清理或合并原始拆分成交，不将未知收益当零，不混合实盘和模拟盘。
