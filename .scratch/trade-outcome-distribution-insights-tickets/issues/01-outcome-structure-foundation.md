# 01 — 收益结构基础：分布、胜率与赔率

**Parent:** `trade-outcome-distribution-insights` 父规格

**What to build:** 用户进入现有“模式洞察”时，可以看到当前交易室范围内已平仓回合的费用后收益率分布、持平/盈亏数量、大小亏盈分类、胜率与赔率关系，并从图表中的任意结果回到对应交易回合。

**Blocked by:** None — can start immediately

**Status:** completed

- [ ] 生成可重建的收益结构报告，复用现有已平仓、费用后收益率和排除口径，不重新计算原始成交或跨范围合并金额
- [ ] 展示收益率直方图/分布图、零收益线、五类结果桶、样本数、占比、极值、平均/中位盈利亏损
- [ ] 展示含持平的总胜率、非持平胜率、平均盈利/平均亏损、赔率、利润因子和每笔期望收益
- [ ] 按盈利和亏损分别使用当前样本中位绝对收益率划分“小/大”，同侧样本不足时显示不可可靠分类
- [ ] 缺失收益率、不可用成本或其他排除样本显示明确原因，未知值不得填零
- [ ] 图表和替代表格支持通过既有回合打开回调定位交易
- [ ] 为报告和页面行为补充单元/组件测试，保持现有模式洞察测试通过
- [ ] 在共享页面之外提供清晰的报告 seam，供 02、03、04 添加独立分析区块
