# 控件与视觉空间登记计划

触发：本轮拆解的是V2.0整页前端与数据接线落地；依当前frontend-control-audit规范，开发后必须完整审计交易库及受影响入口/返回链。本轮只编写计划，**未运行控件检查，未冻结运行时分母**。此表是待展开的控件家族，不可宣称100%或计算0/N覆盖。

## 范围、责任与版本

完整范围：实/模拟×列表/统计四主态、筛选浮层/日期/选项、标的回合集、独立练习详情/内部配对、分布下钻及条件出现的控件、导入/更新/日期补正/冲突状态、真实回放受影响控制、来源首页进入和完整返回状态。图表原有未修改工具也核对本次适配影响面，不能无依据排除。动态行、图点、区间、菜单和页码逐实例登记；fixture页大小不是生产规则。

排除：原型底部“视觉样例”工具（V2.0 L85明确非产品）；分析/数据/策略独立页面整页检查（不在本功能范围），仍查受影响侧栏导航；本轮无产品执行故UI/数据库验收N/A。不是把已在产品范围内的失败排除。

每张实现票owner完成首次登记和自查，票19非实现者独立登记/复核，root接受。报告必须绑定最终commit+dirty内容manifest、浏览器/service URL、隔离DB与seed标识/逻辑摘要、CSS viewport/zoom/DPR、输入方式、时间。运行版变化评估受影响行后复验，不沿用旧版本分母。

## 待展开家族与设计映射

`CF-*`仅登记家族；`TL20-*`覆盖矩阵是设计需求ID，两者不是原设计elementID。正式实例ID：`CF-家族/模式/阶段/稳定对象键/动作或option`；数据实例可脱敏但不得以屏幕行号代替身份。

|家族|逐实例登记对象|矩阵映射/责任|必需行为与状态|
|---|---|---|---|
|CF-NAV|5个侧栏入口、两模式、两视图；focus与选中态|UI-SHELL、MODE-*；I13/14|普通入口立即生效、无pending；各模式状态独立，首页上下文恢复|
|CF-DATE|日期入口、快捷项、年/月/日选择、起止输入、应用/取消及详情日期修正|DATE-*、FILTER-*、ERROR-*；I10/13/14/18|上海含首尾、周/月/年/全部、无效不扩大；保存来源/reload|
|CF-SCOPE|市场/账户各option、搜索输入/清空、筛选开关/字段/确认取消、条件摘要|FILTER-*、SEARCH-*、ERROR-*；I13/18|全/a/hk/us；空/缺/坏账户；IME不误查；库内改不回写首页|
|CF-TABLE|所有实际列的排序、动态成交/练习/回合/配对行及链接、分页/页码、详情返回|TABLE-*、JOURNEY-*、RETURN-*、COUNT-*；I13/14|长名同代码异市场/空/缺/未配对、原对象焦点、稳定排序、跨页返回|
|CF-IMPORT|文件选择、日期补正、候选/差异、更新/新建/取消、历史、待核对/重载|DUPLICATE-*、UPDATE-*、DATE-*；I10/11|等价无写，变更先选，冲突恢复，人工成果不强移；新交互待D03批准|
|CF-METRIC|各指标i、完整值hover/focus/copy/export；资金/估值来源补正入口|PNL-*、RATE-*、MDD-*、UI-*；I15/16|hover/focus/Esc/外点、边缘避让、未知与0、独立分母、完整值|

|CF-DIST|金额/率开关、各区间条/频数/占比、展开/取消、下钻行/分页/返回|DIST-*；I15/17|共享最大频数、亏损正宽/0无假条、选中区间不变分母、正确模式返回|

|CF-REPLAY|阶段、前/后根、播放暂停、下一决策、事实定位、开/平仓定位、完整历史、重启、周期、侧栏、Text/数字输入、保存/重载/返回|REPLAY-FIRST、TL20-R-*；I12|每项动作独立双截止/未来暴露/视野；真实bar/trade可见；保存重开|

具体ID以coverage.json和原文为准，表内通配符表示登记前检索映射，不代表每个前缀必存在。票19将source/DOM/AX三种来源交叉核对，新增遗漏必须补入矩阵/控件清单并指派owner。

## 必需运行时表（尚无证据）

登记表每行字段：实例ID、设计行/原文/准确图、页面/模式/阶段/出现条件、可访问名称/role/selector、作用域与对象键、owner、输入方式、预期动作与下游状态、相关证据。

验证表每行字段：实例ID、初始fixture/scope、操作、正常/disabled/loading/empty/error/边界/重复/异步过时等适用状态、预期/实得、PASS/FAIL/NOT VERIFIED/N/A及范围理由、证据路径。不能强行给不存在disabled状态的静态文本编检查，N/A必须有理由。

空间表每行字段：实例ID、before/during/after截图、viewport、主区/工具/浮层/上下游rect、允许变化预算、实际delta/遮挡/对齐/密度、scroll/focus、独立结论。不得只用无overflow证明视觉。

问题表每行字段：finding ID、类型（实现故障/设计待补/数据状态）、严重性、复现步骤、当前版本、预期来源、证据、owner、依赖/影响旅程、修复版、独立复验结论。单独建issue，记录到最终接受记录；修复后保留旧FAIL。

覆盖率=有执行证据实例/冻结适用实例；通过率=通过实例/冻结适用实例，排除与未验证单列。鼠标、键盘、模拟touch、physical touch分别给分母和结果，不互相替代。物理设备不可用就是NOT VERIFIED，不能改PASS。
