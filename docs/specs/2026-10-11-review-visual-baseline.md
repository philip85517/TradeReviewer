# TradeReview：从视觉样例到真实复盘工作区的开发定义

版本2026-10-11 / r1；此次交付为文档。用户已确认真实复盘页面验收、外观逐项一致仅允许环境差异；此次不开发。规范入口：[纯净视觉基线与实现定义](../design-system/baselines/2026-10-11-clean-review/README.md)。

## Problem Statement

当前样板把真实业务、合成身份、开发说明、测试批注和样板专用样式混在一起。画面看起来变紧凑，不等于正式页面已经接入相同组件、导航、行情与保存链。直接“照截图做”会复制 DEMO 装饰、漏掉未画出的业务状态，或用删除内容、缩小字号和错误断点换取表面相似。

用户希望从已确认方案中得到纯粹的产品视觉基线，并能明确未来实现应复用什么、哪些不能改变、如何按真实画面和操作判定通过。此次希望先锁定这些定义，暂不开发。

## Solution

分别形成纯净视觉基线、兼容实现方案、真实页面验收标准和来源决策记录。纯净基线只描述产品内容与规则；来源记录保留 DEMO 净化映射、候选参数及真实测量限制。未来用同一公共紧凑契约驱动样板与正式复盘，复用当前主题、图表、绘图、双截止和持久化，不替换技术栈。

最终接受通过三条独立门槛：真实功能旅程、状态/持久化安全、独立视觉比较。用户已选择真实复盘入口；外观逐项一致，对齐、换行、标签、密度和选中反馈偏差必须修正，只允许有依据的环境差异。

## User Stories

1. 作为复盘者，我希望直接看到标的与周期，所以我能确认正在分析的行情。
2. 作为复盘者，我希望页面没有 DEMO、样板索引和设计说明，所以工作区空间用于真实复盘。
3. 作为复盘者，我希望真实草稿、未保存、保存中、失败和冲突清楚，所以我不会误以为记录已完成或已安全保存。
4. 作为复盘者，我希望图表和图上批注占据主要空间，所以我能对着行情完成判断。
5. 作为复盘者，我希望三阶段留在同一工作区，所以原图与上下文不会断裂。
6. 作为复盘者，我希望行情截止和成交揭示截止分别显示，所以我知道当前能使用什么信息。
7. 作为复盘者，我希望阶段推进后原判断仍可对照原文，所以我能评估当时的决策。
8. 作为复盘者，我希望当前补充与最终结论按形成阶段区分，所以事后分析不会冒充先验判断。
9. 作为复盘者，我希望看过后续后回填内容标为复盘补记，所以我的记录保持来源可信。
10. 作为复盘者，我希望计划、实际行情和实际成交清楚区分，所以假设不会与事实混淆。
11. 作为复盘者，我希望完整价格、数量、参考资金与风险可读，所以我无需凭被截断的信息决策。
12. 作为复盘者，我希望未知数值保持未知，所以缺失数据不会被误认为零风险。
13. 作为复盘者，我希望左、右面板在各自边缘开合，所以移动路径短且入口容易恢复。
14. 作为复盘者，我希望开合面板保留图表视口、正文和选择，所以整理空间不会改变分析上下文。
15. 作为复盘者，我希望底部执行图标居中且紧凑，所以我能快速回放并留存当前观察。
16. 作为复盘者，我希望按钮图标有清晰名称、焦点和禁用原因，所以我能用鼠标或键盘理解并操作。
17. 作为复盘者，我希望中文文字、数字、标签与框边对齐，所以长时间阅读不会费力。
18. 作为复盘者，我希望价格标签与轴不重叠，所以同价计划、成本和当前价都能分辨。
19. 作为复盘者，我希望先选择 bar/价格再拉出 Text，所以批注能对应具体行情位置。
20. 作为复盘者，我希望 Text 卡片与价格锚点独立移动，所以调整排版不会改变分析对象。
21. 作为复盘者，我希望选中 Text 后仍能反复拖动、编辑、折叠和关闭编辑器，所以控件不会锁住我的布局。
22. 作为复盘者，我希望正文选字与移动柄行为不同、光标准确，所以我知道下一次拖动会做什么。
23. 作为复盘者，我希望多行中文卡片的开合控件小而稳定，所以它不抢正文空间或遮住尾行。
24. 作为复盘者，我希望绘图从第一点就有动态预览，所以我能看出点击已生效并校正位置。
25. 作为复盘者，我希望释放后一次确认、Escape 能取消或回滚，所以没有残留半成品或错误历史。
26. 作为复盘者，我希望新选中对象有一次确认动画和持续标识，所以我能明确识别当前对象。
27. 作为复盘者，我希望选中不改变 Text 换行或几何，所以观察状态不会让页面跳动。
28. 作为复盘者，我希望新 RR 默认1:1而旧比例保留，所以创建快且既有计划不被重写。
29. 作为复盘者，我希望锁定、更多工具与undo/redo行为一致，所以复杂图形也可预测。
30. 作为复盘者，我希望下一根/播放/下一笔真的显露目标行情或成交，所以回放进度有真实图上证据。
31. 作为复盘者，我希望 Tooltip、列表、摘要和缩放遵守截止，所以工具不会泄露未来信息。
32. 作为复盘者，我希望保存后返回、重开和刷新仍保留内容与来源，所以记录能够可靠复用。
33. 作为复盘者，我希望失败和版本冲突时内容保留且可重试，所以工作不会静默丢失。
34. 作为复盘者，我希望较窄窗口和长内容仍可完成核心动作，所以密度调整不牺牲阅读与操作。
35. 作为复盘者，我希望键盘、中文输入法与触屏各自正常，所以不同输入方式不会造成误提交。
36. 作为复盘者，我希望导出完整判断和价格且不带选择手柄，所以输出能直接用于回顾和分享。
37. 作为未来实现者，我希望规范标明确认规则、当前实现与候选参数，所以我不会把偶然截图值当作设计契约。
38. 作为评审者，我希望同数据、同阶段、同视口比较实际画面，所以视觉选择与验收可复现。
39. 作为评审者，我希望每条规则映射到组件、负责人和独立证据，所以组件局部通过不会掩盖整体问题。
40. 作为复盘者，我希望止盈、止损由不同颜色的虚线指示，名称与完整价格放在右侧绘图区外并与价格文字对齐，所以计划不会遮挡K线。
41. 作为复盘者，我希望每种绘图有效完成后自动回到选择工具并选中新对象，所以我能立即调整，不会误画第二个对象。
42. 作为复盘者，我希望从主页持仓、待复盘、交易库或分析进入准确回合，并按来源返回，所以复盘与TradeReview的现有应用壳和主页任务衔接清楚。

## Implementation Decisions

- 复用现有 React/TypeScript、主题、Lucide 和 Lightweight Charts；保留 SQLite 业务持久化与 repository/API 边界，默认无 schema/API 变更。
- 复用 RecallWorkspace 已有 compactControls 和 headerActions。把获选紧凑契约放到公共工作区作用域，正式入口和样板共同使用；不复制整个样板的深层覆盖级联。
- 正式父工作区保留真实行情 hydration、周期/标的/回合、设置、返回和离页保护；样板的 no-op 回调不是兼容方案。
- 复用现有图形的市场锚点、独立布局、文本样式、阶段、cursor 和补记来源字段；Text 卡片、编辑器与连接线共享坐标和量字职责。
- 预览不提交历史或保存，确认操作一次提交；新建 RR 默认1:1，不修改旧目标或旧比例。
- 每种工具在最终有效确认后切回 `cursor` 并选中新对象；Text以正文确认、通道以宽度确认作为完成边界。取消、无效、切工具与undo/redo分别按CB18–22执行，默认不连续绘制。
- 计划线与文字分层：止盈/止损细虚线保留真实价位，名称及完整价格在右侧绘图区外呈现，与轴文字对齐；实时图、三阶段图和导出共同遵守CB14/27。精确配色、虚线节奏与图外区域宽度是待真实页面校准的候选。
- 正式入口仍是 `/` 内同一 `TradeReviewWorkspace`，沿用主页现有回合入口、主导航、`headerActions` 和来源保护；不新增复盘一级菜单或独立业务路由。入口关系及AC27-A～E见[主页兼容规范](../design-system/baselines/2026-10-11-clean-review/entry-compatibility.md)。
- 行情与执行截止分开，视口、阶段和已见后续来源独立核对。面板、选择与编辑不能意外推进 cutoff 或fit-all。
- 净化开发身份与解释外壳，保留业务草稿/保存/知识边界/用户正文。新展示数据不覆盖归档或原交易数据。
- 精确空间预算在真实页面以完整内容校准；使用当前文字与尺寸角色，不能删文、藏价或统一缩小来凑图。
- 首先接受最小真实图表及持久化闭环，再展开依赖该状态协议的布局与绘图切片。root负责整体验收；未来有界实现任务默认交给Luna，独立视觉复核由非实现者承担。

## Testing Decisions

- 最终接缝是实际父工作区到图表/绘图与SQLite的完整链，已由用户确认；尽量通过这一最高接缝验证外部行为，复用已有组件/领域测试辅助定位。
- 既有 Vitest 可证明组件编排和状态转移；mock workspace/chart/repository 不能证明真实 bar、Canvas、返回或落库。
- 必需闭环为回放、标注、保存、返回、重开、刷新；使用显式隔离数据库核对文字、锚点、布局、阶段、双截止、来源和revision。
- 功能、状态/数据、视觉分别判定。非实现者直接比较真实渲染与获选基线；严格逐项一致，仅记录可证明的环境差异。
- 比较固定数据、文案、阶段、cutoff、视口、DPR、缩放和图表范围；覆盖1440×900、1280×800、1280×720、1024×768、390×844及断点两侧。
- 逐个登记所有受影响控件和反例，区分鼠标、键盘、粗指针模拟、物理触摸、真实IME和软件键盘证据；不得将未验证改成通过。
- 高价值回归测试断言外部结果，如锚点独立、取消不提交、旧比例保留、失败内容保留和未来信息不可见；不以镜像CSS或实现内部变量充当主要验收。
- 逐种工具验证“完成→自动选择→立即调整→空白取消且不新建”，分别核对工具ICON、对象选中和焦点；实时/导出图验证虚线真实价位、图外名称与完整价格。AC27覆盖正式入口、整壳视觉及来源返回，不能用样板截图代替。
- 当前是文档任务，UI/数据库放行不适用；只验证文档引用、覆盖、边界与确认决定，不借此宣称功能交付。

## Out of Scope

本轮不修改产品代码、运行样板HTML/CSS、业务数据或已存批注；只更新规范与文档用HTML/SVG/PNG图示，不启动实现、不创建新的产品交互原型、不提交推送或发布。未来方案不替换框架、不迁移首页B、不重构无关行情后端或交易导入算法，不重新设计已锁定整体框架，不自动套用到全站。未校准的尺寸/断点和未生成的纯净金图不虚构成既有事实。
