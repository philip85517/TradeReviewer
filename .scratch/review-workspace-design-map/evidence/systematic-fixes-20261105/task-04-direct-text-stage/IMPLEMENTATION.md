# 自由 Text 直接呈现：隔离原型切片

## 目的和依据

本切片基于冻结的 candidate45，用于审阅持仓期独立 Text 的普通态显示。对照依据为设计覆盖表中 R03、E08、I15–I19、I40 及“自由 Text 直接呈现”段落，历史视觉参照为 candidate45 的 `text/buy-conflict-B-confirmed.png`。TradingView 的 [Text 工具说明](https://www.tradingview.com/support/solutions/43000516983-text-drawing-tool/)供理解普通 Text 的呈现方式；本切片不宣称与 TradingView 1:1 一致。

## 本次改动

- 已确认 Text 的 DOM 逐条渲染完整文本，不再为其生成常驻大卡片、日期价格、锚点圆环及长连线；正文为 14px、可换行，普通态透明背景，悬停和键盘焦点显示轻量边界。
- 每条 Text 直接使用原有 time、price、logical 投影；取消确认态自动避让和因避让失败而隐藏的分支，不移动或写回锚点。其他已知 Text 依原有可知截止逻辑决定是否渲染。
- 保留原有文字的点击和键盘入口，以及当前编辑器、回放与成交标记的原有逻辑。为了保留编辑器避让已显示文字的能力，现有确认态文字的矩形仍提供给编辑器作为障碍。

## 验证与范围

- `node --check workspace-v0.1/workspace.js`：通过。
- 与 `candidate-20261105-45` 逐文件 diff：JavaScript 改动仅在确认态 Text DOM 与定位循环；CSS 改动仅追加确认态外观规则。
- 按任务约束没有启动服务或浏览器；未进行鼠标、键盘、重放、跨回合、缩放平移、成交标记和视觉验收，也未检查真实屏幕阅读器。此文件是实现说明，不是验收结论。
- 修改文件的 SHA-256：`workspace.js` = `fed59355dc33792ee851d5f742651272c84ce775894abdb7d7114c806fece35d`；`workspace-overrides.css` = `0629198dcc5426876b2530118f5d28182cad398197e988e958424c5220d33fe5`。

## 待审阅与已知限制

- 创建和编辑仍使用原有带圆环和引线的浮动编辑器，**并非图上原位编辑**；既有窄窗口下编辑器可用空间和避让失败问题也未在此解决。
- 相同位置或相近位置的文字会自然重叠，各对象仍逐条存在，但逐条鼠标选择及实际可读性未经验证；历史重叠 FAIL 不因本候选而关闭。没有新增拖动锚点，因为当前锚点没有历史版本。
- 文字按实际位置展开且图表容器裁切溢出：靠近边缘或很长的文字可能部分不可见；没有省略号或程序截断，但此取舍尚待视觉和交互审阅。
- 成交标签布局算法未改动，但因文字障碍框的几何变化，标签最终避让位置及与 Text 的遮挡仍需对照检查。普通 Text 的对比度、视觉层级、在实时缩放和平移中的位置和文字密集状态均未通过浏览器验收。
