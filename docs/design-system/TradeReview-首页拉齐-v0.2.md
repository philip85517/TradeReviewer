# TradeReview 首页视觉规范候选 v0.2

日期：2026-10-07；实测更新：2026-10-09。状态：候选；已取得真实首页、响应式、菜单、滚动、导航与隔离持久化证据，整体验收仍受全量回归及未验证能力限制。当前状态以 [最终验收记录](../../.scratch/homepage-master-alignment-20261007/FINAL-ACCEPTANCE.md) 为准。此文件补充 [基础规范 v0.1](TradeReview-设计规范-v0.1.md)，首页样板以本文件及 [当前视觉契约](../../.scratch/homepage-master-alignment-20261007/visual-contract.md) 为准；复盘规则仍使用 v0.1 和既有批准规格，不迁移首页布局。

## 本次修正的设计方向

用户指出旧样板离正式 master 首页过远。源码核对显示旧样板只组合持仓摘要和历史图，而正式首页具有完整导航、统一页头、全局范围、资产分布、当前持仓、历史收益与待复盘路径。方案改为复用整个真实 TradeReviewWorkspace，保留原首页结构，在相同内容上比较视觉调整。正式结构基准为已 fetch 的 origin/master `7a5d137da3dcdf0f133a29714ee269693746472b`；工作树已有估值与首页修复仍保留，不把工作树对照冒称纯 master 画面。

这是完整现有工作台上的视觉校准：图表空间和模块顺序优先，控件与数字统一角色，减少高亮轮廓竞争。候选值继承现有主题和 Lucide；不更换前端框架、组件库或中文字体资源，不复制 TradingView 未测量的参数。

常规正文400、控件值500、标题600，优先使用14/22px与12/18px形成两级阅读密度；不将所有文字缩小。主要金融数值保留币种、符号和业务精度，使用tabular nums。原表格可局部横向滚动，不能为视觉删列或隐价格。所有数值是同一业务数据源的实际显示，未知和小计不通过样式改成“总额”。

桌面控件至少36px；现有44px控件保留，不能为统一尺寸缩小命中区。窄窗/粗指针至少44px。控件圆角6px、面板8px；内距8–12px、大分组16–24px为候选。nav宽度clamp(148px,14vw,208px)、首页原网格比例、760px导航边界和1055px图表/分布边界均保留；实际外观须按边界两侧检查。

## 颜色、图标与状态

沿用page #0b1220、surface #111a2b、raised #182337、正文#e7edf6、辅助#adbbcf。分隔只承担分组用途，选择和主要动作再用蓝色。主动作候选复用#2169cc白字；focus为2px #9ecaff，offset2px，选择与焦点独立。盈亏继续使用既有用户设置和现有业务变量，本轮不修改它的解释。已有源码中固定盈亏色覆盖的历史问题不能因预览CSS通过而视为已修复。

候选不透明颜色按 sRGB 相对亮度静态计算：正文/面板14.79:1，辅助/面板8.94:1，白字主按钮5.31:1，焦点/面板10.23:1。计算记录见[候选对比度](../../.scratch/homepage-master-alignment-20261007/evidence/candidate-color-contrast.json)；这些值不包含实际CSS级联、opacity、混色或最终画面，另已取得实际 computed style 的四组对比度 15.91、15.78、14.46、5.96:1，见 evidence/browser-20261008；仅代表所测文字/底色组合，不代表全部状态通过。

Lucide沿用，只调整导航/操作图标，不统一所有SVG；图表、圆环、轴与命中层不能套18px图标尺寸。仅图标按钮保留原中文可访问名；hover不改变边框厚度或尺寸。disabled、selected、focus、loading、error、partial各自保留文字解释，reduced-motion沿用原组件。

## 可逆范围与比较规则

/design-preview使用隔离业务副本，完整操作会写该副本，页面不称只读。“现有首页/视觉调整”只是同一次挂载的wrapper class切换；同数据、筛选、期间、导航与图表范围不能因比较而重置。顶部比较条从宿主高度扣除，宿主保留纵向可滚动。仅在 data-preview-variant 标记存在时对 html/body 设置 overflow:clip；固定预览 root 不可滚动，桌面 workspace、窄屏 host 承担内容滚动。此预览例外防止 scrollIntoView 把整个页面推离视口，不应用于正式根首页。

仅预览增加scoped样式，不改正式根首页/globalCSS。旧合成首页和S0/S1/S2组件样板保留在/design-preview/component-sample，仅作历史组件校准。后续将此候选应用到生产需取得真实画面选择、独立视觉对照和相关行为验收。

## 选定后的固化范围

1. 按样板实际computed和截图确认文字、颜色、密度、焦点及图标token，在app/globals.css与既有CSS modules逐组件迁移，清理重复覆盖。
2. 首页UnifiedPageHeader、Scope、指标卡、历史图工具、资产分布、持仓表、历史口径与待复盘统一角色；保留全部原动作与异步估值机制。
3. 如需公共Button/Field/IconButton，只加薄语义接口，不换库；状态及命中尺寸在组件层验证。
4. 回放页面仅迁移经独立验证的基础角色，不套用首页网格；S0/S1/S2、双截止、原判断、补记、未来信息和真实保存验收单独处理。
5. 最终选定后在AGENTS.md和UI模板中引用批准版规范、例外表、同状态截图要求；候选阶段不修改项目指令。

## 2026-10-09 已确认：持仓总体与市场入口

用户确认将持仓查看按“总体（CNY）→ A股 / 港股 / 美股”组织。常驻市场标签放在持仓标题和指标卡之间，默认总体；这是持仓查看的产品契约，不能用资产分布内部的币种切换代替。指标卡、历史曲线、资产分布和当前持仓表同时切换；已平仓复盘的期间和市场范围保持独立。总体按同一汇率快照折算 CNY，持仓明细保留原币；各市场按实际结算币种展示，ETF按证券市场归属。

行情或汇率不足时显示“已知市值小计”和明确覆盖分母，不称完整总额，不用已知小计计算不完整收益率。现金仍为账户范围，市场页注明“全账户范围（当前账户筛选）”。切市场保留持仓观察期间，切换期间不得把旧市场异步结果展示为新市场结果。

市场标签桌面高36px、≤759px高44px；窄屏说明独立一行，标签不可挤压截断。≤360px持仓指标卡单列，390px双列，完整保留金额、币种与正负号。方向键和Home/End移动选中及焦点，选择态和焦点圈分别可辨。

实施和验收证据：[HA06验收记录](../../.scratch/homepage-master-alignment-20261007/evidence/ha06/acceptance.md)。独立视觉范围已通过，整体功能回归状态以该记录为准，不沿用上一轮全量通过结论。
