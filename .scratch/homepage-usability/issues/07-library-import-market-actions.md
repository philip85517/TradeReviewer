# 07 — 在交易库直接提供导入与行情更新

**What to build:** 用户留在交易库即可导入新成交或更新当前股票行情，查看处理进度与结果，不再为了数据维护往返逐笔复盘。

**Blocked by:** None — can start immediately

**Status:** done

**Priority:** P2

- [x] 股票库和股票详情提供可访问的导入入口，支持现有文件导入与截图恢复流程。
- [x] 复用既有解析、复核、去重和确认规则，确认前不写入交易；取消后仍保留原浏览上下文。
- [x] 股票详情可直接更新当前股票行情，显示进行中、成功、部分可用或失败状态，避免重复提交。
- [x] 更新遵守现有缓存优先、缺口补齐及失败保留旧数据规则；仅浏览交易库不触发下载。
- [x] 操作完成后仍停留在当前股票和有效回合，新数据同步反映到列表与详情；当前选择失效时给出明确回退。
- [x] 验证导入成功、取消、行情部分成功和失败路径；不因共享操作而重置回放状态。

**Verification:** 见 [验收记录](../verification.md)。
