## 默认值与保留原则

- 新建盈亏比默认 **1:1**。合法入场与止损确定后，目标价格为 `2 × entry − stop`；在价格域计算并按项目统一价格精度处理，再交给图表映射，不能按屏幕像素镜像。
- 多头示例入场56、止损52、目标60；空头示例入场56、止损60、目标52。零风险、错误方向或无效价格须提示且不提交；不能自动翻转止损方向。
- 1:1是新建默认值。完成后目标、止损可独立调整；已有2R、自定义对象、原快照和实际成交保持原值，选择对象不重新计算价格。
- 整体框架锁定。选择不改变阶段、行情/成交可知截止、图表范围、卡片尺寸、完整原文、计划标记及盈亏颜色配置。阶段归属、原判断与补记证据继续遵守原复盘契约。

## 确认表达与参数

选中采用 **立即显示标记 → 一次短确认 → 持续保留标记**。首次可见反馈与动画分开：命中后首个绘制帧即出现轮廓和合法手柄，随后约200ms的外环扩散淡出；结束后轮廓与手柄继续存在，直到切换对象或解除选择。

| 项目 | 已确认设计起始值 / 规则 |
| --- | --- |
| 确认动效 | 约200ms，一次播放；手柄外环半径6→10px并以真实透明度淡出；Text辅助外轮廓扩展0→4px并淡出 |
| 持续轮廓 | 线段/区域辅助轮廓2px；Text细边框1px；原线色、正文背景与盈亏填色保留 |
| 合法手柄 | 可见直径8px、暗色中心、2px浅蓝边；桌面命中16px；粗指针目标至少44px并单独校准 |
| 反馈颜色 | 复用主题 `--link:#8cbdff`；与对象保存的颜色/opacity分离，低透明对象的选中标记仍可辨 |
| 首次反馈 | 目标≤50ms；需要真实事件录像测量，200ms动画不代表响应延迟 |
| 位置稳定 | 数据坐标完全不变；DOM几何测量舍入差≤1 CSS px；仅辅助轮廓可外扩最多4px |

这些是已确认方案的设计起始值，不是当前运行页面的实测参数。后续依据真实图表、DPR与视口进行校准并记录差异；改变反馈模式、操作意图、信息层级或既定框架须单独记录设计变更。动效层独立、非交互，不抢指针、不扩大滚动区域；结束时真正透明消失，避免以背景色覆盖产生残环。

## 状态规则

| 状态 | 表达与行为 |
| --- | --- |
| 普通 | 保持对象原有颜色、线型和文本背景，无选中手柄 |
| 悬停可命中 | 轻微轮廓预告与相应指针；不显示整套手柄、不播放确认脉冲；离开恢复 |
| 刚选中 | 首帧显示轮廓与全部合法手柄，再播放短确认；动画不阻塞点击或拖动 |
| 持续选中 | 指针离开后仍保留轮廓与手柄；切换对象立即撤去旧对象标记；重复点击同一对象不重播 |
| 拖动 | 当前操作手柄实心；几何和价格即时跟随指针；释放一次命令，取消恢复原值与先前选中态；不重播选中动画 |
| Text编辑 | 选择身份与编辑态分开，纯选择不自动打开输入；保持选中边框与独立移动把手，输入caret和编辑工具区只属于编辑态；选择文字、滚动正文不移动卡片。完整LD01的新建/点击/双击/拖动入口方案保持原评审状态 |
| 键盘焦点 | 独立2px焦点环，焦点不等于选中；提供对象/热点可访问性等价入口，Enter/Space选择对象 |
| 锁定/只读 | 细轮廓与锁/只读身份；无可拖手柄或移动指针；长Text仍可完整阅读 |
| 减少动态效果 | `prefers-reduced-motion:reduce` 时直接显示最终选中态，持续标记保留；Canvas自己读取偏好并取消相应RAF |
| 解除选择 | 无编辑草稿时空白点击解除；有未保存输入时遵守草稿保护；Esc优先取消当前拖动/编辑草稿，无草稿才清除选择 |

## 对象与手柄的操作意图

| 对象 / 元素 | 选中标记与真实操作 |
| --- | --- |
| 趋势线 / E03/E04 | 两端价格/时间手柄与线辅助轮廓；主体可整组移动，原线色保留 |
| 横线 / E03/E05 | 一个调价手柄与线辅助轮廓；原价格标签完整。无时间语义时不画假时间端点 |
| 盈亏区域 / E03/E04 | 区域外轮廓；entry/stop/target三个圆形调价手柄；右侧独立调宽柄使用短竖握柄与左右提示；主体移动整组，调价与调宽不能同形误导 |
| 价格批注Text / E08 | 卡片细边框、独立移动把手、市场价格锚点与连接线；拖框不改bar/price，拖锚点不改原文；无缩放行为时不画假角点 |
| 自由文字 / E08 | 卡片细边框与移动把手，无假市场锚点 |
| 垂线、箭头、矩形、平行通道、斐波那契、价格标注、测量 / E03/E04 | 共用短确认与持续标记，只显示已有真实控制点：垂线调时间、价格标注调价格、箭头/测量两端、矩形两个既有控制点、通道三个、斐波那契两个；不改变这些工具的新建流程 |

手柄必须对应实际操作。密集/重叠对象按当前拖动意图、手柄、对象距离及z序决定身份；一次选择后不随移动跳对象。重叠价格柄须有可辨标签或候选入口，不改真实价格或价差来腾空间。

## 身份、空间与数据安全

- 桌面默认单选。动画由选择身份切换驱动，不随render、hover、行情更新或同ID重命名重复播放；切对象、解除选择或卸载时取消旧动效。
- 画布与图层列表共用选择身份。隐藏/离屏对象保持原坐标与可见性，在图层说明原因，不自动平移视口。横/垂线原锚点离屏而线仍可见时，可在可见线上提供操作代理，不能回写伪造市场锚点。
- 选择与焦点是临时交互状态，不写数据库、撤销历史、留存、导出或快照。实际位置修改按原保存/撤销契约；编辑和拖动按已确认的回放暂停与截止保护执行，纯选择不修改回放政策。
- 完整原文、重要价格、标签基线与图表范围稳定。辅助外环不遮价格文字；临边可裁剪装饰外环，功能手柄仍须可到达。正文与盈亏语义色不因选中改变。
- Canvas与DOM统一CSS像素和DPR映射；CSS媒体查询不能替代Canvas减少动态处理。临时反馈不修改对象保存的style.opacity。

### 2026-10-10 长文与密集标签的实现校准

- 展开长批注的正文滚动区统一预留 `padding: 4px 4px 48px`。普通、选中及取消后保持同一排版；底部编辑/折叠操作不能覆盖滚动到底的末行。验收使用35行中文，桌面300×661与窄屏236×220分别比较，不能用首屏可读替代末行。
- RR标签布局避让入场、止损、目标和时间宽度四个真实控制柄，按其实际命中矩形计算。空间不足时采用有背景的可滚动读数区，保留六行价格/距离/比率及适用计划信息；检测fallback与四柄交集，滚动后仍须可点。已测安全槽位不外推到不存在35×35可用区域的任意极端空间。
- 窄屏右侧栏开关保留44px区域，样板索引右边界为 `calc(44px + 8px)`，不能覆盖链接。链接需实际点击进入索引、返回、刷新验收。
