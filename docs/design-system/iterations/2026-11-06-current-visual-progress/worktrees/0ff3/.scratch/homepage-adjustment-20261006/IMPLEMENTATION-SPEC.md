日期 2026-10-06。权威需求：用户“开始推进修复”，执行已交付的[调整草案](adjustment-proposal.md)推荐方向。具体尺寸、阈值与布局采用协调者推荐默认值，属于可调整的实现裁定，不伪称用户逐项回答了六张 HITL 票。六张规划票保留历史；本次实施以本契约与实施票为准。

## 范围与默认选择

覆盖原评审八项问题；保留深色、既有左导航、单页单主滚动和持仓在前。轻量待复盘入口前移，数量来自真实 pendingModel，与通知数分离；未知数不可显示零；不凭空增加“继续复盘”。不改交易、供应商、财务算法或全局导航。已接受的异步估值修复是本轮基线。

## H01 / H02 / H08 — 范围与下一步

页头在窄屏压缩为当前性质、账户、计价摘要与筛选按钮，展开后可编辑。折叠时启用标签仍可移除。桌面保留主要范围控件。页头提供“待复盘 · N”到现有待办区域；保留统计期间、列表页、精确回合、返回上下文和滚动。分页用前后页、当前页/总页数，避免全页码展开。入口→准确回合→保存→返回→重载必须在隔离库验证。

## H03 — 金额可信范围

每币种独立一行，币种与金额不拆开，等宽数字。指标分别计算可用性/覆盖，市值不因缺成本消失；未知不为零。完整用“持仓市值”，部分用“已知市值小计”；部分盈亏用“已知未实现盈亏小计”。本币覆盖贴每币种，全组合覆盖明确标识，估值日期本地可读，详细时间不隐藏。保留报表折算与缺 FX 回退规则；净值/总敞口/率/参考现金口径不变。

## H05 / H06 — 分布与诊断

比例完整有效且分母正才画分布。可信空头以 Σ|市值| 作总敞口分母，净值独立。无效去掉灰环，呈现已知小计、分类金额、估值覆盖（数量覆盖非配置比例）、缺口。主区最多三类摘要和“查看全部问题”，不把重叠分类加总成唯一仓位数。不重复展开上千现金原因。

问题详情采用桌面侧抽屉、窄屏全屏；搜索原始证据，分页每页最多 30 条，分组解释和对象保留。Esc、关闭与动作回到触发点，焦点限制在打开详情内。缺行情调用手工更新；数量/成本/方向/记录属性调用现有 onOpenDataCheck，不用行情修复代替。接口 RoomAllocation 新增 onRetryValuation?:()=>void 与 onOpenDataCheck?:(dimension:TradingRoomQualityDimensionId,ids:readonly string[],episodeId?:string)=>void，由 review-dashboard 真正接线。原始原因全部可追溯，不靠截断丢弃。

## H04 / H07 — 趋势与日期

标题→指标→观察期间→币种/粒度→图形→详情。原币单币轴，稳定优先 CNY/HKD/USD，范围内合法选择保留，图内选择不改全局筛选。固定身份：CNY 青绿圆、HKD 紫菱、USD 蓝方，业绩图同规则。实/虚线保留完整/部分含义。部分显示已知小计，全缺留空，成员/可信状态变化断开，单点可选。

自动粒度 ≤92 天日、93–730 天周、更长月；手工日/周/月在同一挂载范围中保持，显示实际粒度。区间末快照不得累加；桶内状态变化保留边界点，不能跨缺失连线。‘本月’表达自然月。查看某日持仓仍在趋势组件已有历史详情/表格中，日期一致并有“返回当前持仓”；下方当前持仓面板仍独立，标题当前时点。无新增外部选中日期状态，避免耦合当前基准和历史观察。

| 动作 | 持仓基准 / 复盘期间 | 历史可知与视野 |
| --- | --- | --- |
| 改区间 | 不变 | 按新范围，不沿用不兼容旧图 |
| 点选/键盘/日期 | 不变 | 详情该实际快照；不提前显示未来点详情 |
| 币种/粒度 | 不变 | 同期间，重选实际日期，单币轴 |
| 返回当前 | 不变 | 清除历史选择，回当前提示 |
| 自定义应用/取消 | 不变 | 仅显式有效应用改变区间 |

此首页趋势不是交易回放，不改主图双游标/未来曝光/保存状态；这些 replay 项 N/A，现有详情安全仍必需。最小真实图旅程：选币→单币曲线→选择历史点→同日表格→返回当前，协调者接受后才扩大依赖其新状态的集成；独立页头/诊断工作可并行。

## H09 — 更新反馈
