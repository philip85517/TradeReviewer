# 练习收益率本金口径的确认

类型：讨论记录，部分决策已确认；整票保持 open。

## 确认依据

助手建议：练习收益率＝练习净盈亏÷该次练习初始资金。初始资金缺失或非正时，收益率显示“暂不可计算”，仍展示可计算的盈亏金额。

用户回复：“确认”。

## 已确认

- 练习收益率采用本次练习初始资金为分母，百分数显示为净盈亏÷初始资金×100%。
- 初始资金必须已知且大于零；缺失、零或负数时收益率暂不可计算。
- 净盈亏仍沿用已确认的结束时点计价与费用规则。
- 净盈亏可计算而初始资金缺失时，金额仍可展示；依据已确认的胜率规则，该练习仍可按净盈亏判定胜负并计入胜率。
- 金额和收益率的可计算样本集合可能不同，不能因收益率缺失把已知净盈亏隐藏或当作零。

例如，净盈亏60、该次练习初始资金1000，收益率6%；同样净盈亏但初始资金缺失时，金额仍为60，收益率暂不可计算。

## 数据约束及后续事项

这不确认现有文件已包含初始资金。项目历史对账中的账户暂定本金不等于每次练习的已知初始资金，不能擅自将其套用为所有练习的分母。实际字段来源、结束时点和估值价格须核查；账户与练习关联仍待确认。
