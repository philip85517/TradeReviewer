# 首页 V2 HP05–HP07 独立设计审查

审查日期：2026-10-16。审查版本：工作树 `6406092fa49fa1420ca3c1af04b414e1d675cf75` 上未跟踪的 `2026-10-16-homepage-v2.0` 设计包。触发：用户要求逐章、逐控件、逐评论子要求和异常分镜审查。范围：HP05 当前持仓、HP06 历史/贡献/交易库交接、HP07 加载与异常。排除：C34/C38 窄屏；产品实现、数据库与运行时验收不适用于本次设计稿。D01 历史持仓日期为待决定，不能记为 PASS。

## 结论

设计稿不能作为无歧义的实现基线。共发现 **8 项**：**P1 4 项、P2 4 项**。其中 4 项 P1 阻断设计验收：贡献展开滚动锚点互相冲突；待复盘队列的市场状态没有路由/状态来源；历史区年份选择、空年与历史贡献入口没有可比较分镜；scope 原子切换的失败回滚和竞态没有分镜或确定状态机。

本次直接检查范围内 29/29 张渲染图，未看项 0。旧 `comment-review.md`、`DESIGN-COVERAGE.md` 的 PASS 仅作为索引，不作为本审查证据。

## 发现

### F01 · P1 · C29 · HP06-CONTRIBUTION-MORE：展开后的视线锚点契约互相冲突

- **位置/证据**：`visual-design.md:226,236`；`images/motion.svg` 标题“旧列表顶端作为滚动锚点”、中间态“展开后按钮随列表底部向下”、页脚“不自动滚动到页底”；`comment-review.md:341-347`。
- **预期**：同一操作应给出唯一可实现、可测量的滚动结果，包括点击前按钮的 viewport 坐标、插入位置、动画期间 scrollTop、结束后焦点和按钮可见性。
- **实际**：正文要求“按钮附近保持/保留视线锚点”，图稿却固定旧列表顶端且把按钮向下移动 10 行。若 scrollTop 不变，按钮会离开原位置；若补偿滚动维持按钮位置，又不再是旧列表顶端锚定。这里不是措辞差异，而是两种不同的 viewport 结果。
- **影响**：实现者可任选两种相反行为，C29 的“向下扩展动效结果”无法客观验收；50 项连续展开时偏差累积。
- **建议**：由设计明确选择一个锚点，并补充 10→20、20→30、50→收起在 1280×800 的 before/during/after 坐标与焦点；不要用“附近”代替阈值。
- **置信度**：高，正文和分镜是直接冲突证据。

### F02 · P1 · C27/C31/C33 · HP06-LIBRARY-QUEUE：待复盘路由无法解释分镜继承的“美股”

- **位置/证据**：`visual-design.md:238`；`comment-review.md:321-327,370-378,394-400`；`images/library-handoff.svg` 三格分镜从首页“美股/今年/实盘”进入后显示“待复盘 × 美股 ×”及“08-14·美股·待复盘(3)”。
- **预期**：队列跳转应明确传递市场，或明确定义 `scope` 的结构、序列化和优先级足以恢复市场；刷新、返回和深链应得到同一结果。
- **实际**：规定的队列路由仅为 `/trades?queue=pending-review&scope=<scope>`，没有 `market`；同段又承诺刷新不丢市场。设计未定义 `scope` 包含市场，而日期路由反而显式同时携带 `market` 与 `scope`，说明二者不能据此视为同义。分镜无来源地继承“美股”。
- **影响**：实现可能落到交易库默认市场、沿用隐式内存状态或错误复用 scope；刷新/复制链接后结果改变，C33 的迁移链路无法验收。
- **建议**：补齐唯一状态契约：显式 `market`，或定义可持久化 scope schema 及 market 字段、URL 优先级和非法值回退；为直接打开、首页跳转、刷新、返回分别画结果。不要预设哪种方案。
- **置信度**：高，路由文本与分镜显示直接不一致。

### F03 · P1 · C04/C31 · HP06-HISTORY：年份选择、空年与历史贡献入口只有文字，没有状态分镜

- **位置/证据**：`visual-design.md:208` 要求默认展开当年、按年滚动、按年统计、市场同步、期间不影响、空年份、复盘数为 0；唯一 `images/history.svg` 只显示 2026 汇总卡和一张多年折线图。
- **预期**：至少呈现正文已经承诺的年份选择/滚动、空年份、复盘 0、市场切换后的同构状态，以及进入历史已平仓贡献和返回的结果；明确焦点、滚动与统计字段。
- **实际**：图中没有可操作的年份选择/滚动状态、空年或 0 复盘状态，也没有当前期间贡献与历史已平仓贡献之间的进入/返回分镜。正文未明确要求“历年折叠”，本发现不把折叠作为硬要求。
- **影响**：文字虽声明规则，但布局密度、交互层级与异常结果无法比较，C31 对历史区重新组织的要求只能算部分回应。
- **建议**：补齐上述离散状态和至少一条完整年份选择旅程；为每格标注市场、年份、closed-only 统计和焦点位置。
- **置信度**：高，直接检查唯一历史图即可确认缺失。

### F04 · P1 · C08/C16/C19/C20/C30/C36 · HP07-SCOPE-ATOMIC：原子切换/失败回滚/竞态没有可执行状态链

- **位置/证据**：`visual-design.md:280` 声明 market/account/period/filter 切换时标题、单位、金额、曲线、贡献“同一成功响应后一起替换”，失败保持旧 scope；`state-updating.svg`、`state-error.svg`、`retry-result.svg` 没有标出旧/请求中/新 scope 身份。
- **预期**：分镜应覆盖 A→B 请求前、请求中、成功、失败回滚，以及 A→B→C 乱序返回；明确期间控件是否锁定、取消/忽略旧响应规则、标题与内容在每帧属于哪个 scope。
- **实际**：现有 updating 只画通用旧值和状态环；没有失败后控件值回滚、旧请求晚到、重试期间再切 scope、无缓存新 scope 的结果。正文也没有取消、超时或响应世代规则。
- **影响**：最危险的混合 scope 状态恰好无法验收；“原子”只能做主观判断，无法证明 C19/C30/C36 所要求的稳定体验。
- **建议**：定义 scope request state machine 和响应采纳规则，并用带具体 A/B/C 标签的 before/during/success/failure/late-response 分镜验收。
- **置信度**：高，契约要求存在而验收证据缺席。

### F05 · P2 · C24/C26 · HP05-LOCAL-SEARCH：浮层与表格高度恢复的文字/图稿关系不清

- **位置/证据**：`visual-design.md:188` 称“表格标题下方展开 280px 局部浮层，关闭后表格高度恢复”；`images/local-search.svg` 中浮层覆盖在现有表格行上，外层卡片高度未变化。
- **预期**：明确浮层是绝对定位覆盖、还是插入布局并改变表格/卡片高度；打开、无结果、清除、Esc 后的几何位置应一致。
- **实际**：“高度恢复”暗示打开时高度变化，图稿却表现为覆盖。两种实现对下方历史区位移完全不同。
- **影响**：C24/C26 要求的布局稳定性仍可能被相反实现破坏。
- **建议**：给出坐标/层级和是否 reflow 的明确值，并补一张带下方相邻区块的打开态。
- **置信度**：中高，静态图能确认覆盖表现，但“恢复”可能是措辞误用。

### F06 · P2 · C22/C23 · HP05-NAME/DETAIL：低频查看缺少完整关闭与焦点分镜

- **位置/证据**：`visual-design.md:184,188`；`images/holdings-name-tooltip.svg` 只展示最终 tooltip；`images/holding-detail.svg` 只展示最终 overlay，并以注记声称 ×/Esc 返回原行按钮。
- **预期**：hover 与 keyboard focus 两条路径应分别有出现、指针离开/焦点移出、Esc、关闭后焦点；详情还需定义外部点击是否关闭及遮罩行为。
- **实际**：最终态清楚，但 before/during/after 和互斥规则未画；详情的可关闭方式只在注记中出现。
- **影响**：行高稳定已回应，但键盘可达性、误关闭和焦点返回不能从设计证据验收。
- **建议**：补 tooltip 和详情各自的鼠标/键盘分镜，明确外部点击策略与焦点陷阱范围。
- **置信度**：高。

### F07 · P2 · C25/C30/C36 · HP07-COLD-ERROR：中央重试提示的可操作性与焦点语义未定义

- **位置/证据**：`comment-review.md:294-302` 声明重试只在错误 tooltip/异常浮层，不进入主浏览路径；`images/cold-error.svg` 的持仓主内容中央显示“查看错误原因并重试”，同时顶部错误浮层也有重试按钮。
- **预期**：冷失败应明确中央文案是纯提示、错误详情入口还是可触发重试的控件，并给出可访问名称与焦点次序。
- **实际**：中央出现“查看错误原因并重试”，但静态图没有控件边界、状态或键盘路径；它可能只是提示文字。现有证据不足以证明存在第二个可点击入口，也不足以推断并发重试。
- **影响**：实现者仍需猜测该文字是否可操作，C25 的“重试不进入主浏览路径”缺少可直接验收的冷失败例外说明。
- **建议**：标注该元素的角色与交互；若为提示，改成不暗示点击的说明并指向唯一浮层入口；若为控件，再定义焦点与 pending 状态。
- **置信度**：中高，文案与语义未定义确定；是否可点击未知。

### F08 · P2 · C09/C16/C36 · HP07-NO-FX：绿色不可用占位误用了正收益颜色语义

- **位置/证据**：`images/state-no-fx.svg` 用与正收益相同的绿色显示多个长横线占位，而正文把这些值定义为不可汇总且不得伪装成 0。
- **预期**：不可用值应使用中性、不会表达涨跌方向的视觉语义。
- **实际**：绿色通常在同一套图稿中承载正收益，这里却表示没有可汇总值。
- **影响**：用户可能把 unavailable 误读为正向或有效状态，异常原因与数值语义相互冲突。
- **建议**：对 unavailable 长横线使用中性色，并保持原币可查看提示。
- **置信度**：高，颜色和同图内业务含义均可直接确认。错误浮层临时遮挡 KPI 属常见 tooltip 表现，正文未要求打开时所有 KPI 完全无遮挡，本报告不将其列为缺陷。

## 验收边界

本报告评的是设计契约是否一致、完备、可操作验收。未启动产品、未写数据库、未点击真实控件；因此产品功能、持久化、浏览器布局与真实动效均为不适用，而不是 PASS。C34/C38 是明确排除；D01 是待决定；其余“部分/遗漏/冲突”不能被旧审查的 PASS 覆盖。
