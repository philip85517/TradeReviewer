# 04 — 精简收益卡片并提供可操作的详情

**What to build:** 收益卡片突出金额、期间和简短口径，用户能主动打开完整的原币及汇率证据。

**Blocked by:** 无 — 可立即开始

**Status:** completed

- [x] 卡片不再把长原币/汇率说明裁成两行；主金额与简短说明可直接读懂。
- [x] 明确的详情入口支持点击、触屏和键盘，完整信息可读而不依赖title。
- [x] 摘要和趋势继续使用统一范围与金额计算；区分暂无样本、数据不足和无法合计。
- [x] 桌面及窄屏无文本遮挡，展示金额与百分比最多两位小数。
