## Implemented in TSX/model

- Kept `RunningPrototype` props (`draft`, `visible`, `onList`, `onReady`, `onStatus`) and the existing `RunningDraft` shape compatible. One- and two-strategy drafts are still accepted; each selected strategy uses an independent synthetic ledger and principal.
- Extracted the shared synthetic model to `running-model.ts`. Public downstream boundary: `RunningDraft`, `Calendar`, `Snapshot`, `TradeEvent`, `PortfolioMetrics`, `SymbolId`, `SYMBOL_IDS`, `makeCalendar(draft)`, `portfolioSymbols(draft, strategy)`, `buildLedger(calendar, maxCursor, draft, strategy)`, and `portfolioMetrics(snapshots, snapshotIndex)`. Results work can consume these same candidate symbols, snapshots and metrics rather than define a second calculation path. `T0_CURSOR` and strategy names are exported too.
- At T0 the value chart receives exactly one point with normalized value 1; the summary shows four portfolio metrics and the status callback reports `待开始`. The first advance reveals the next bar and opening execution/holdings. Synthetic replay and chart data stop at the current view cursor.
- Added actual Lightweight Charts line/candlestick series. V-clipped market bars, portfolio values, markers and event lists are derived from the viewed cursor; the next-known-event affordance only shows date and event type. T0 and V use separate vertical annotations, while event markers use neutral semantic types.
- Manual advance, autoplay, speed, historical-date review, previous/next known events, return-to-latest, price/value chart switching, holding-to-symbol chart navigation, and list/reopen state are wired. Opening the date/config controls pauses playback; changing or focusing the speed selector preserves playback. Closing paused overlays does not resume playback. A resize reapplies the saved logical viewport, and returning from the hidden list keeps the chart mounted along with the current drawer selection.
- Event/config overlays pause replay, trap Tab focus, close on Escape, and restore focus to the opener. Event detail includes the known-time basis, execution/fill details, and valuation/fee basis; each trade can open its symbol's K-line and closes the detail overlay with focus moved to the K-line tab. Partial-coverage copy follows the selected strategy set and the same dependency explanation as creation. The chart heading keeps the T0 start date/time visible when its vertical T0 rule is outside the viewport. Newly revealed chart endpoints use a brief outline pulse; the permanent V circle was removed while T0 and V vertical rules remain.
- For partial samples, the same strategy-specific candidate set used in creation is now invested by the running ledger: EMA uses A/B/C at 30% each plus 10% cash; low-volatility quality uses A/B/D at 26.67% each plus 20% cash. Complete coverage remains A/B and empty coverage remains cash-only. Later synthetic rebalances tilt the first two candidates by 10 percentage points while additional candidates retain their base target weight. C/D market bars and event fills are available in the chart and event detail.
