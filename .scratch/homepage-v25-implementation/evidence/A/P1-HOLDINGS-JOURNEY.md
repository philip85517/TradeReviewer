## Exact journey states

1. **`/home` initial scope.** Load market, account, currency and holdings data under the selected scope. The page order and C summary must match the inspected homepage frames. A scope failure retains an explicit error/recovery state and never mixes new scope labels with old data.
2. **Scan and local controls.** Search the holdings table only. IME composition must not query; debounce 300ms. Name sort is the default supported identity sort; floating P/L sort is available when FX conversion is complete. Any search, clear, sort or market change returns to page 1 while retaining the global scope.
3. **Open detail.** Activate the row's only detail icon with mouse or keyboard. The target is a holding detail view, with the accessible name “查看持仓详情”. Record source row, query, sort, page, scroll, market, account and URL.
4. **View transaction.** In holding detail, activate the unique “查看交易” action. This navigates to the ordinary `/trades` library using Appendix 2 `:652-655` URL contract (`/trades?symbol=...&rangeMode=...&market=...&scope=live&accounts=...`). No queue IDs, replay phase, execution cutoff, chart future-information rule, or new playback behavior is in this P1 scope.
5. **Navigate/refresh.** `/trades` must be directly addressable and refreshable. Back/close returns to `/home` with source context. If the source row disappears, focus the holdings heading and show the documented fallback. If the URL or source record is invalid, show an empty-contract/error state with recovery, never a misleading row.

## Current code migration note

`ReviewDashboard` currently exposes `onOpenInReview(instrumentId, episodeId, queueIds?)`, and `RoomHoldingsPanel` currently calls it from a row action. This is an existing migration seam only. The approved implementation must introduce/use a holding-detail route and a single `查看交易` handoff into `/trades`; it must not define the direct callback or queue IDs as the P1 target contract. `holdingsBrowseState {query,page}` and its restore seam remain useful for source-context preservation.
