# 01 — 修正趋势图坐标、比例与点详情

**What to build:** 用户能从正确的日期、金额刻度读懂累计曲线，并通过鼠标、键盘和触屏查看同一份点详情。

**Blocked by:** 无 — 可立即开始

**Status:** completed

- [x] 曲线、点、坐标共用映射；点与刻度锚点误差不超过2px，零基线位置正确。
- [x] 1440/1280/390/320px下比例稳定，点不变形、端点不裁切、标签不遮挡，图例对应实际曲线。
- [x] 悬停、点击和键盘聚焦呈现期间收益、累计收益、可信样本、胜负及日期；缺失/多币种状态不伪造合计。
- [x] 覆盖空值断点、首点缺失、负值、日周月及最多两位小数；相关行为测试通过。

验收依据：[交付记录](../acceptance-report.md)、[独立审查](../independent-review.md)。
