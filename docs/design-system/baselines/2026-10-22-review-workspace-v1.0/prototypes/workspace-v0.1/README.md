## 审阅重点

先看 1440×900 的整体密度，再在 1280×800 比较侧栏开合。左侧是当前股票的三次交易，按买入日期由近及远；中央是图表与收藏工具。右侧在买入前填写计划、平仓后填写评价；持仓过程中收起记录区，留出图表空间。1292px 以下默认收起左栏；开左栏会收右栏。审阅条属于原型外层，可隐藏与恢复。

A 把计划字段连续铺开，保留顺序填写的结构。中途买卖仍是图表成交事实，不再触发独立的加仓/减仓记录表单。绘图收藏条从 647×48 等比例缩小到约 539×40，原 SVG 图形几何保持。

## 可操作范围

- 当前股票的交易次数/日期筛选及三次合成交易切换；计划方向、三价、规模三模式与资金来源；缺项和无效价格提示。
- 单步、播放/暂停、0.5/1/2 倍速、选择日期和下一节点。实际 Lightweight Charts 蜡烛图逐根揭示合成行情，成交标记只显示当前时点已知事实。
- Text：T → 点击图表自由定位 → 输入 → 确认；每次可新建独立文字，点击已有文字可编辑，取消或 Esc 保留确认前内容。输入焦点暂停回放，不要求选择单根 Bar 或区间，不生成右侧记录表单。
- 结束原因、提前退出状态、计划符合度和四维评分；记录查看及退出后返回。

收藏条保留已有 13 个 SVG 图标候选的比例。仅 D02 Text 可演示；其余绘图、拖动、周期、实时、导出及更多入口禁用并说明原因。**TradingView 1:1 实际功能仍未完成**，这份原型不替代工具对齐验收。

## 样本时间边界

每次交易均为 62 根合成日线，首次买入日期依次为 2025-02-03、2025-01-06、2024-12-02。买入前 28 根；首次买入 29 根；持仓场景 31 根；后续买入成交 34 根、部分卖出 41 根、最终平仓 49 根。自动回放暂停在 33、41、49 根。回看早期隐藏未来成交与尚未创建的 Text。合成日期用于验证切换，不是交易日历或真实交易。

计划、结束评价和多条 Text 按交易回合隔离；Text 与买卖表单节点分离。记录、退出与恢复仅演示内存往返。没有业务数据库、持久保存、生产计算或导出。手机只提供窄屏提示，完整手机、物理触摸和系统输入法组合输入尚未验收。
