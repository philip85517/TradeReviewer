# 本轮需求契约

权威来源：2026-10-07 用户本轮完整请求。旧首页方案B、旧复盘固定栏宽不覆盖用户当前“不预设复盘栏数和比例”的明确约束。

R01 阅读项目指令、运行资料、现有设计资料、用户设计启动包。
R02 检查首页、主题、字体加载/中文回退、图标来源、公共组件与复盘页。
R03 最新截图、真实字体/字号/行高/颜色/尺寸/内边距/间距；无法取得标NOT VERIFIED。
R04 每个主要问题含位置、画面、组件/样式源、现象、影响、原因、具体规则、验收。
R05 覆盖层级/图表空间/中文字体与字重行高/控件/图标重量与命中/间距基线/颜色语义与实际对比/交互态/长内容/窄窗口。
R06 主图与图上批注为复盘工作面；首页B不直接移植；不预设栏数比例。
R07 S0入场前、S1持仓中、S2退出后是同一工作区；按阶段揭示，阶段、市场可知截止和成交截止明确。
R08 原图形/原判断继承、有图表关联与可见证据、可读原文；新观察/最终结论按形成阶段区分，事后回填标复盘补记。
R09 计划/假设与实际行情/成交可区分；Tooltip/列表/摘要/缩放都过滤未来。
R10 中文、暗色、沿用盈亏配置；完整固定文案/判断/重要价格不因排版删减。
R11 规范包含方向/文字角色/语义颜色/尺寸间距/图标/公共组件与状态/复盘/验收/例外。
R12 复用现有主题、React/CSS模块、Lucide、Scope控件、ReplayChart/DrawingToolbar/ChartToolbar；候选数值在真实页面校准，未实测明确。
R13 先一个推荐样板；无必要不增加密度候选。baseline/recommended仅用于同数据前后对照。
R14 样板含阶段截止、主动作、真实工具栏/图表/计划线、多行中文批注、原判断和补充、选中/焦点。
R15 同数据/文案/阶段/视口/图表范围比较。
R16 交付问题证据、推荐取舍、规范实际路径、运行样板/前后截图/状态、验证边界/审美选择、固化范围。
R17 不修改正式存储或原成交；可逆样板无保存/导出承诺。

本轮是设计样板，不替代旧生产复盘完整开发。只实现能验证视觉与已有低层组件连接的有限内存旅程；没有真实图验收之前不扩展生产回放、保存、导出或侧栏状态契约。原生产验收FAIL/NOT VERIFIED保留。
