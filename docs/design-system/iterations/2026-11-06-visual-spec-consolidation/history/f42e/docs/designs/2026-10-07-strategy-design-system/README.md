## 3. 文字角色

以下为推荐候选值，最终实测校准记录在样板验收文件。单位 CSS px，不由截图像素反推。

|角色|字号 / 行高|字重|用途|
|---|---|---|---|
|工作区标题|18 / 24|600|标的/实验名称；不压过图表|
|分区标题|16 / 24|600|计划、原判断、当前补充|
|正文|14 / 22|400|完整中文判断与依据|
|图上 Text 批注|14 / 21|400|保留原生文本几何的1.5倍行高，避免视觉样板改动锚点与卡片尺寸|
|控件|13 / 20|500|周期、菜单、按钮；表单标签使用400的局部例外|
|阶段与选中控件|13 / 20|600|当前阶段和当前工具|
|辅助说明|12 / 18|400|来源、保存状态、单位、次要时间提示|
|价格/数量|13–14 / 20–22|500|tabular-nums；精度沿用业务数据|
|图表轴/读数|12 / 图表API度量|400|显式字体链；图上文字14/21|

本轮实际 computed 字体链：`Geist, "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`；推荐 UI 与图表显式共用该顺序。Linux 的 `"Noto Sans CJK SC"` 是未来跨平台校准候选，本轮未加载或验证，不写成已经使用。当前 next/font 变量本身可能带 generic，后续固化时必须检查实际展开顺序，不能只在变量后补字体名就宣称有效。保留中文系统回退、暂不增加大型中文 Webfont。

数字可用现有 Geist Mono 或 `font-variant-numeric: tabular-nums`；不要把整段中文说明改成等宽。普通文本不连续大面积600/700，不对长中文强行单行省略。价格、阶段、 cutoff、原判断不作为可截断内容；标题若截断必须另有完整可见入口。

中文、英文、数字混排测试串须包含：`计划入场 ¥56.00；初始止损 ¥52.00。若跌破前低，原判断失效；不能因事后上涨回填当时信心。` 切换系统平台后复核换行和字重。

## 4. 语义颜色与对比

|语义|沿用/候选|规则|
|---|---|---|
|画布 / 面板 / 浮层|#0b1220 / #111a2b / #182337|图表底沿用#101722，降低无功能的大面积高亮|
|正文 / 次文 / 辅助|#e7edf6 / #adbbcf / #9cacc2|辅助不等于不可读；未知/未揭示有文字含义|
|结构线|#243145 / #1c2736|低对比装饰线可用；不能独自承担输入边界或选中含义|
|动作蓝|现有#2f80ed|保留语义，不直接作为13px白字实心背景|
|实心主动作 normal / hover / active|候选#2469c8 / #2b72d3 / #205bac|对白字分别5.344 / 4.719 / 6.659:1，须与最终computed吻合|
|焦点 / 链接|#8cbdff|2px焦点外框，offset2；各背景复算|
|计划 / 假设|现有#f3ba2f|虚线/文字“计划”；不伪装实际成交|
|盈 / 亏|沿用#26a69a / #ef5350与用户chart setting|不因审美替换、反转或另存一套权威配置|
|已选工具|浅蓝文字+蓝色淡底+边界/标识|不与实心主动作竞争，不只靠颜色|
|错误 / 失败|现有红+错误说明+重试|不把未揭示或未知涂成失败|

对比验收依据 [WCAG文字最低对比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)：普通文字4.5:1；本项目不以放大中文控件达到大字例外。必要图标、控件边界、焦点等依据 [非文字对比](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)检查3:1。透明背景必须逐层合成后计算；opacity、hover、active单独记录。disabled属状态例外，不把可用控件藏进disabled规避要求。

`#44546b`在面板#111a2b上仅约2.26:1，适合作装饰/弱分隔，不能写成已达3:1的唯一输入边界。最终交互边界需采用更亮候选并实测。

推荐样板实际输入边界为 `#58708f`，面板背景 `#111a2b`，对比3.423:1；实际主按钮normal为 `#2469c8`/白字，5.344:1。焦点 `#8cbdff` 对面板8.983:1、画布9.663:1，真实Tab截图已验证2px外框/offset2。hover/active颜色及比值由源码计算，本轮尚未分别用鼠标取得computed，不把状态规则当浏览器实测。当前保存动作保持secondary，不能被primary hover覆盖。

## 5. 尺寸、间距与图标

- 间距基准4；同组间4或8、组间12或16、段落/分区16或24。既有14px图表与侧栏间距可保留为验证过的局部例外，不为整齐破坏已批准布局。
- 桌面常规控件高36、左右padding10–12、input左右8–10；独立图标按钮36方形。紧凑数据行可28–32但不可混进同一主要操作栏。粗指针样板目标44；这是项目选择，不声称WCAG规定44。[WCAG2.2最小目标](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)另有24px及间距例外。
- 圆角：控件4–6、上下文容器6–8、pill只用于阶段/来源小标签；不全页胶囊化。图表本身保持安静边界。
- 保持 Lucide 统一线形，常规工具18、绘图18–19、stroke候选1.75–2；状态图标14–16可用，但点击框仍按角色。同组图标光学中心与文字基线需看实图，不只比较CSS宽高。
- 不混用 Unicode 字符作相同语义工具；有数字/符号含义的内容符号不必替换。图标按钮有中文accessible name，悬停中文说明；装饰SVG设aria-hidden。
- 控件和图标尺寸独立：扩大点击范围无需放大笔画。焦点环、tooltip和菜单不被overflow裁切。

本轮实测补充：常规工具SVG18、原生Lucide元素的stroke属性仍为2；推荐CSS笔画规则1.75用于视觉校准，不能把属性读数直接当最终光学重量。行情来源图标14属于状态图标例外，外框仍36。正文14/22、输入14/22/500、标签13/20/400、H1 18/24/600、H2 16/24/600均取自实际computed。

## 7. 复盘工作区规则

### 时间与来源

S0入场前、S1持仓中、S2退出后同一工作区。每动作明确 phase、行情可知截止、成交可知截止、视野和已看未来标志。日期至少`YYYY-MM-DD HH:mm`并注明时区；未揭示显示“尚未揭示”，不显示0成交/0收益伪装已知。

原判断、原计划和原图形保存形成阶段及图表关联，推进后保留可见证据。新观察属其形成阶段；最终结论属S2。历史事后回填必须标“复盘补记”，原判断来源不能因返回S0被洗成当时记录。对照可展开全文，不能静默覆盖或为排版改短。

### 图表与范围

- 只把当前市场截止以内的数据交给可见图表；Tooltip、成交列表、摘要、统计与缩放都使用同一已知投影。
- Candle以`knowledgeAt`（完成后可知时刻）判断可揭示，而非仅K线起始时间；成交以独立`executionCursor`判断。跨周期时不可用粗周期起点提前揭示整根高低收；同一K线的两笔成交按成交截止分别揭示。
- 下一根/下一决策应在真实图上显示新增bar/成交，必要时平移到新增对象；仅状态变化不算通过。
- 面板开合/resize保持用户范围和价格轴；切阶段恢复该阶段已保存范围，不默认每次fitAll。
- 基线/推荐候选固定 fixture、文案、阶段、viewport和range；不能靠推荐稿多显示未来行情显得丰富。
- 原判断Text、计划价位、实际成交可读；价格轴沿用有效精度，至少84px只是现有参考例，不是所有标的固定值。长价位/多位小数要实际测量。

### 密度与响应式

先保证图表可操作面积、完整判断和关键价。现有320px计划面板只作为样板校准起点，不作为所有复盘预设比例。选择能容纳工具栏、价格轴、读数和完整长文的布局；内容不足时收折辅助功能，关键判断不能被折叠成无法察觉的状态。

桌面按1440×900、1280×800评审。断点由现有组件真实宽度约束推导，并在两侧测量，不拿“没有横溢出”替代内容可达。窄屏390×844采用页面自然纵向滚动，图表220–240高、工具/动作换行、完整计划面板自然高度；保持核心价格可见和中文14px阅读。若固定底部控件，必须预留真实高度且不遮挡最后一项。

本轮推荐校准规则：<=1100px头部明确分三行；<=900px图表stage240、全文默认展开；901–1200px stage360，壳层按真实子内容自然高度；桌面stage使用360–460的视口高度clamp。这些是该样板的内容约束结果，不能推广为所有复盘预设栏数/占比。OHLC独立于绘图区，不与计划价签重叠；body仅推荐样板解除overflow锁。普通/全文/More展开必须共同遵循自然页面流，不能再继承一屏固定预算裁掉动作。

导航展开会缩窄实际图表容器，因此须把“窗口宽×导航开合×计划/More开合”一起验收。>=901px计划打开及More打开均按真实stage+读数解除壳层高度上限；不能只修901–1200窗口。解除sticky时使用relative+top:auto，保留“适应全部”等绝对定位子控件的图表锚点，不能改为static导致其漂到全文/回放区。每种状态验证图壳容纳真实stage、时间轴/量柱可见、控制归属与可点击范围。

已记录取舍：1440基线图壳625.7→推荐469px，约减少25%；1280为500→454px，主要推进动作在y858，超过800px首屏；390文档约2038px，完整计划、原文和主要动作需下滚。推荐优先扫读阶段/截止及完整中文。原图上完整长文仍保持真实锚点，可能覆盖行情或越出图缘；同源全文区保证阅读和图形选择，但不宣称图表毫无遮挡。若用户更重视首屏图表面积，下一轮以减少重复提示/渐进显示辅助内容换空间，不能缩字、删判断、隐价格。

键盘：Tab顺序服务工作流，真实focus-visible；绘图输入编辑时方向键不能误推进；Escape退出编辑保留草稿；恢复面板返回发起控件焦点。鼠标、键盘、浏览器窄视口、emulated touch、物理触摸证据分开。

## 8. 评审与验收方法

每项问题记录：位置、fresh截图、源码、computed/尺寸、任务影响、事实与推断、修改规则、验收证据。截图记视口/DPR/阶段/双截止/fixture/range/时间，不用旧图替代新状态。

三个门槛独立：

1. **功能旅程**：原生下一根实际揭示bar，Text可编辑/关联，阶段与原判断对照可达。
2. **状态安全**：S0/S1/S2双截止、已看未来、tooltip/list/summary/zoom；隔离DB和原成交hash；本轮样板内存保存范围准确。
3. **视觉**：未实现UI的审查者直接对照匹配截图与本规则；font/contrast/controls/longcontent/narrow/focus分别判断。测试通过、DOM存在或无overflow不能取消重大画面差异。

PASS有直接证据；FAIL保留问题；NOT VERIFIED明确原因；NOT APPLICABLE仅范围理由。样板通过不关闭真实回测、正式SQLite保存/重载、正式导出或历史策略功能票。当前字体glyph、物理触摸、启动包符合性没有证据时明确不宣称通过。

最终评审记录：[FINAL-ACCEPTANCE.md](../../../.scratch/strategy-design-system-2026-10-07/FINAL-ACCEPTANCE.md)。候选值如需偏离，更新本规范、coverage和截图证据一起记录，不静默改值。
