# 03 汇率实现报告

日期：2026-09-19

## 已完成

- 新增独立 `app/lib/fx` 模块：`FxState`、CNY 房间金额快照适配、BOC HTML 解析器、服务端存储/刷新服务和浏览器 hook。
- 解析中国银行 `#priceTable` 的真实表头和单元格，不依赖 `data-currency`；使用「中行折算价」并按每 100 外币除以 100。空白、零值、未知币种、缺失时间和坏表格会被忽略或拒绝，按币种保留最新有效行及各自源发布时间。
- 使用 SQLite 既有 `app_settings` 专用 key `trading-room.fx`，通过现有公开 `getSettings/putSettings` 读写，没有新增表、修改 `ChartSettings` 或写入交易库。
- GET 按 `Asia/Shanghai` 的尝试日期每天自动尝试一次，失败也持久化当天尝试；POST 手动刷新可同日重复。服务端 singleflight 合并并发请求；请求、响应 body 和有限重试均有界。刷新失败沿用旧汇率、旧发布时间和旧抓取日期；首次失败保留 `missing` 状态。
- 新增 `/api/fx` GET/POST，响应 `Cache-Control: no-store`，源请求固定为中国银行 URL，不转发账户、交易或其他用户输入。
- 新增数据管理汇率面板：显示来源、每币种 `1 USD/HKD = … CNY`、各自源发布时间、最近获取日期、部分币种和失败沿用提示，并提供手动刷新。工作区在生产数据管理页面接入该面板，并把同一状态转换为 dashboard 的 `RoomFxSnapshot`；没有外部汇率状态时不会补零。
