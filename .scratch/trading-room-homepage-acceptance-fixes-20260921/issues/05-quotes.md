# 05 — 完善持仓行情诊断与处理反馈

**What to build:** 持仓行显示一个清晰的问题摘要和主要动作，用户可查看来源细节并获知行情重试的实际结果。

**Blocked by:** 无 — 可立即开始

**Status:** completed

- [x] 首页和数据管理的行情原因一致，区分缺失、过期、早于交易、晚于截点、无效价格、币种不符、源不支持/中断。
- [x] 行首精简，日期、采集时间、提供方等放入可展开详情；避免原因重复。
- [x] 重试有进行中、成功/仍不可用/失败反馈，沿用已有更新能力且无新增provider。
- [x] 查看数据定位正确标的/账户；不可用浮盈亏不以零代替；测试成功、失败和证据优先级。

验收依据：[交付记录](../acceptance-report.md)、[独立审查](../independent-review.md)。
