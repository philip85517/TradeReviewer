## 技术裁定记录

- 首页专用新模型不扩改全站 RoomScope/币种类型，必要适配在边界完成，避免影响模拟盘和其他页面。
- 显式 URL 参数优先；非法账户/证券不能静默扩大范围。来源快照带版本并可跨刷新保存；重返时读取最新数据而非旧业务值。
- 搜索先采用现有导入交易与 instrumentMetadata 的已知证券全集，保留唯一身份；不得引入外部供应商或伪造未覆盖证券。若原文要求超出此集合，记录缺口，不宣称全市场搜索已通过。
