# 复盘工作区原型：独立验收问题的诊断与逐项修复

> **2026-11-06 范围调整：** 用户自行布置 Text，影响阅读时自行调整文字控件范围，不要求针对文字与文字或成交标记的重叠专门自动避让；第 4 项中此前的碰撞避让目标及同点同时可读验收不再执行。保留普通 Text 的放置、内容编辑、回放边界和用户调整能力检查；其他顺序与范围不因此改变。限定检查见[人工调整能力核对](task-04-direct-text-stage/coord-manual-check-20261106-v2/REPORT.md)。

触发：用户在独立验收后要求使用系统性调试定位整体问题，并按顺序修复。仅涉及复盘工作区的合成行情与内存草稿原型；不改业务页面、真实数据库或正式视觉规范。候选方案仍需用户审阅确认。

基线：独立审查锁定 candidate-v37，证据、原始问题和未验证项保留在 [独立验收](../independent-acceptance-20261104/DESIGN-COVERAGE.md) 及三个独立报告中。不得在冻结核验结束前改变九个原型源码文件；后续每次更改记录新版本摘要和回归证据，不覆盖旧结果。

总负责：协调者负责整页视觉一致性、跨文件状态链和最终真实浏览器验收；实现者不担任其更改的独立视觉审阅者。按项目开发流程，默认实现模型为 `gpt-5.6-luna`，若不可用须记录实际限制。UI 合同、元素和确切参考映射沿用 [W01–W12、R01–R05 / I01–I40](../independent-acceptance-20261104/DESIGN-COVERAGE.md)，并按下表确定受影响项目。修复任务按表顺序进行，前一项完成必要复测后再开始下一项；同一源码只有一个实现所有者。
