## 严重度发现

### F01 · P1 · C39 的逐格可验收合同未成立

- 预期：78 个适用格均有真实形态、尺寸、触发、反馈、退出/恢复、键盘、异常结果。
- 现状：`visual-design.md:303-315` 每类仅一行；`build-detail-frames.py:155-160` 大量使用 150×36 模板。两张 controls 图互相补充仍未覆盖逐格合同。
- 影响：实现者必须自行决定关键行为和几何，无法按同一基准验收。
- 建议：以 78 格为清单，为 Popover/DataTable/ChartTooltip/EmptyState 优先补真实状态板和焦点/恢复时序。
- 置信度：高。

### F02 · P1 · 16px 图标规范与实际 path 外包络不一致

- 预期：IconButton 36×36，内部图标 16（`:305`）。
- 现状：`build-frames.py:12-15` 使用 24 坐标 path 平移到 36 框中，但 path 不都填满 24；search 约 14、filter/eye/info 约 18、library 约 16。`build-detail-frames.py:15` 的 eye 又是 16 外包络。坐标系为 24 不能证明实际图形为 24，也不能证明统一为 16。
- 影响：主页、控件示例和实现没有单一像素基准，C27/C35/C37/C39 无法一致验收。
- 建议：冻结同一 16×16 viewBox 资产，明确 stroke 是否计入包络并统一复用。
- 置信度：高。

### F03 · P1 · 默认 36px 命中区与 24/32 例外未闭合

- 预期：`:295,301,339` 的 36px 命中区应与 Token 删除区 24（`:309`）、Retry 高 32（`:315`）明确区分视觉框与交互框。
- 现状：tokens/controls 图均未画透明 hitbox；Token 的 `×` 没独立 24×24 边界，Retry 也没有 36px 外层。
- 影响：实现可能产生 24/32px 真实点击区，或自行加入会重叠的透明 hitbox。
- 建议：分列可见尺寸/最小命中区/焦点环，并画出例外几何。
- 置信度：高。

### F04 · P1 · 覆盖总结误称 37 条 PASS，交叉引用又误绑 C28 与 D01

- 预期：只有 C18 保持 D01 待决；C28/C31 按盈亏日历原锚点评估。
- 现状：`:343` 误称 C28 涉及 D01；`:347` 又称 37 条 PASS，与 `:345` 的待决和本审查四条部分不一致。
- 影响：既扩大了 D01 范围，也抬高完成度。
- 建议：修正映射并按实际状态报告；本范围为 32 满足、4 部分、1 待决、2 排除。
- 置信度：高。

### F05 · P2 · 动效缺反向、中断和竞争合同

- 预期：除正向关键帧外，定义 Esc/反向、重复触发、scope 连切、重试中关闭时的最终 DOM、请求和焦点。
- 现状：`:282,331-335` 与 motion 图仅给正向和 reduced-motion。
- 影响：实现仍可能闪烁、重复提交或丢焦点。
- 建议：补四条时序分镜及取消规则。
- 置信度：高。

### F06 · P2 · tokens 图无法证明 Web Sans 候选且未完整呈现所称几何 tokens

- 预期：候选应以实际字形、相同内容直接比较；图注声称的间距也应可量测。
- 现状：B 明示无字体文件、仅回退；图只直接比较字号/行高/颜色，未图示间距、圆角、命中区。
- 影响：字体 B 的视觉取舍和部分几何 token 仍只能依赖文字，不能按图验收。
- 建议：若 B 仅作理论候选，应明确排除视觉比较；另补 spacing/radius/hitbox 标尺板。
- 置信度：高。
