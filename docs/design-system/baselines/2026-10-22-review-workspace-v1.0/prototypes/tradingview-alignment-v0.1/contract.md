# TradingView 绘图与回放逐项对齐方案 v0.1

2026-10-24 · 可审阅提案，未定稿。仅覆盖复盘工作区的绘图收藏条与底部回放条（E03/E06/E08/E19），不改业务页面。

## 1. 设计目标与核心取舍

本轮首先保证图标指向同一种工具、动作产生同一种结果，再约束形状、顺序和视觉状态。用户要求绘图图标与实际功能 1:1，底部按钮形态也沿用 TradingView；因此不能把相似轮廓配给项目中方便实现的另一种动作。

当前问题的根因有三层：截图只显示自定义收藏栏的一个静止状态，缺少名称和完整操作证据；旧规范要求统一 Lucide，无法表达这些专用工具；项目把绘图、交易计划和回放阶段放在同一操作面，但尚未明确它们各自改变哪些对象。直接描图只能解决第一眼外观，不能解决语义和状态一致性。

建议采用一套参考锁定方案：保留截图的 13 个绘图槽位、顺序、轮廓和 7 个回放入口；仅在这两个区域覆盖通用图标规则。原图、候选描摹、工作区适配分别展示。未知槽位保留原轮廓和编号，取得 tooltip/操作证据后才定名。外观密度、工作区颜色和状态反馈目前都是提案，不冒称用户已批准。

原图像素是参考测量，不等于 CSS 像素。用户图中的蓝色图表背景、顶部报价/指标控件和红色标注框不在本次复刻范围。评审页为静态讨论载体，点击只查看契约，绝不证明真实绘图或回放功能完成。

### 2.1 每种图形都必须完成完整生命周期

创建前选择工具；创建中显示临时图形和下一步提示；完成后显示选中反馈与可编辑锚点；点击空白退出选择。所有候选工具都必须依次补齐创建、选择、整体拖动、锚点拖动、属性、取消、删除、撤销/重做及保存重开证据，D11/D12 在身份确认之前不冻结锚点数和手势。

提案的共同规则：Esc 取消未完成创建；属性编辑取消恢复本次编辑前状态，文字草稿可恢复；Delete 仅在图形被选中且没有输入焦点时删除；一次连续拖动计为一步撤销。文字编辑及中文 IME 期间暂停回放，快捷键不穿透输入框。这些是复盘工作区拟采用的行为，TradingView 的具体快捷键、撤销粒度、双击行为仍为 NOT VERIFIED。

属性面板按样式、文本（适用时）、坐标、可见性组织，但不先虚构各工具的字段/默认值。D02 的普通 Text 与 Anchored Text 不能混用；D06 的 Arrow 与 Arrow marker 不能凭轮廓混同；D10 的三个放置点不等于三个编辑手柄；D11/D12 未知不能由实现者自行换成折线或普通文字。

### 2.2 绘图对象与交易计划的边界

D03/D04 是多空仓位测量图形，显示入场、止损、目标及距离/比值；它们不是买卖指令。候选方案先作为独立绘图对象保存，用户显式“用于当前节点计划”时才将价格复制到计划草稿并校验多空方向。已冻结的原计划风险分母和历史快照不得被拖动覆盖。是否建立后续双向联动，由“节点计划与持仓标注的协作方式”任务决定。

每对象拟保存稳定 ID、工具类型、时间/价格锚点（若最终确认为画布锚定，则另存锚定类型）、样式、文本、记录归属 D、创建时 M/X 和修订。回放推进不会把对象转移给下一笔交易。重开恢复同一对象；已留存快照引用固定修订。失败时显示未保存状态并保留草稿，不伪装已写入。

## 3. 底部按钮如何对应

底部按钮保留参考的形状、顺序和分隔关系。日期、播放、步进、速度、周期候选、末端动作和关闭分别定义；“下一根”“下一成交”“下一待复盘交易”不是同一个动作。

|槽位|外观/名称|参考功能与边界|工作区适配提案|
|---|---|---|---|
|R01|日历回退图标＋文字＋下拉；选择日期|官方支持选择历史起点。|提案：暂停后选择可用日期/柱；定位M，按动线合同计算X，D不因日期自动换绑。|
|R02|右向三角；暂停图标原图未出现；播放 / 暂停|官方支持自动播放与暂停。|提案：每次只揭示下一完成K；X受实际可知边界限制。Text/IME编辑时暂停。默认1秒/根继承当前规范，非已核实的TradingView 1x定义。|
|R03|右向三角＋竖线；向前一步|官方Forward逐步前进；不是下一笔交易。|提案：暂停状态推进一个约定步长，新K必须进入视野；同K多笔成交的显示由X合同约束。|
|R04|1x文字；速度 1x|官方允许播放前或播放中调整速度。|提案：只改变调度间隔，不跳K、不改变M/X/D；每根均需可观察。|
|R05|文字“天”；“天”（身份未知）|周期或回放更新间隔尚未唯一确认；不能直接定为图表周期切换。|本版只保留原图外观与待核标记，不写入业务动作。若将来确认为周期，切换不得推进M/X。|
|R06|右向三角＋双竖线；返回实时（候选）|官方存在结束回放并返回实时的动作；原槽位映射待提示确认。|推荐候选A：保留外观和原语义；本地只有历史数据时禁用，说明“无实时数据”。候选B：改成查看完整历史，须明确改名、记录未来暴露并由用户批准，属于语义偏离。|
|R07|最右侧X；关闭回放面板|官方X关闭回放面板；不是关闭整个工作区。|提案：先暂停，再收起回放条，保留M/X/D及绘图，提供重新打开回放条入口；不导航、不自动完成复盘。|

### 3.1 回放中的状态与视野

M 是可见行情截止，X 是可见成交截止，D 是当前记录归属。以下是与现有规范衔接的候选合同；精确成交边界及交易节点迁移仍由连续动线任务统一决定。

|前态与动作|M / X / D|可见反馈与视野|取消、结束与恢复|
|---|---|---|---|
|暂停 → 选择日期|M 定位所选合法 bar；X 按该市场时刻推导；D 不暗换|未来 K 线、成交、指标输入均截断；定位 bar 必须可见|取消日期选择不改游标；超出数据范围明确提示|
|暂停 → 播放|按完整 bar 推进 M，X 随对应边界推进，D 不随计时器变化|按钮变暂停；新 bar 真实出现；视口跟随/用户平移后的恢复策略需集成动线|编辑输入暂停；到行情末尾停止并禁用继续；缺行情不跳过|
|暂停 → 单步|M 只前进一个已定义回放单位，X 同步合法边界，D 不变|目标 bar 可见；在 R05 未明确前不可擅自定义多 bar 跳步|末尾禁用；不自动打开下一交易|
|调整倍率|M/X/D 不变|只改变推进时间间隔|保持暂停/播放状态；项目既有每秒一根不能称为 TV 的 1x 定义|
|点击“天”|语义未核实，不定义状态变更|保留外观与待核说明|取得菜单和跨周期实操证据后补规则|
|末端动作|推荐保留“返回实时”候选语义；仅历史数据时禁用|提示“无实时数据”；禁止偷换为下一交易|若选择另案“查看完整历史”，必须明确改名并记录未来信息暴露|
|关闭回放条|暂停；M/X/D 与绘图保留|收起控制条，保留重新开启入口|不关闭工作区、不标记复盘完成；重开恢复暂停位置|

R06 有两个可审阅方案：**A（推荐）**保留参考语义，历史工作区无实时数据时禁用；**B** 改成“查看完整历史”，显式改变名称和语义并记录未来暴露。B 是偏离 1:1 的产品决定，不能由实现默认采用。当前原型只展示 A 的说明，没有执行任一方案。

### 5.1 本轮与后续验收的区别

本轮检查审阅页20个槽位能否查看正确契约、3个视图是否可返回/刷新、状态样本与选中槽是否一致、参考和文档能否打开、1440/1280/390下是否可读，并由未实现页面的coordinator独立对比原图。结果见审阅记录；这仅证明提案可审阅。
