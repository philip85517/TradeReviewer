# D/E 导航比较原型实现记录

State: implementation-ready (throwaway visual sample)

本轮只新增 `docs/design-system/baselines/2026-10-22-trading-library-v1.0/navigation-de-prototype.html` 与本记录。页面无数据库、网络请求或正式产品代码依赖，数据来自既有交易库样例：实盘成交、模拟练习、统计指标、趋势与缺失回撤 `—` 均在两个方案中复用。

## 控件清单与已接线行为

| ID / 控件 | 行为 |
| --- | --- |
| `de-variant` | 底部 D/E 方案切换、左右箭头；`?variant=D/E` 写入并刷新稳定保持方案。 |
| `de-mode` | 实盘/模拟盘单选按钮；共享当前列表/统计页，分别记忆日期选项；模拟盘显示紫色边界、文字与形状。 |
| `de-tab` | 列表/统计页签；两方案位置固定，切页更新标题、日期标签与主体。 |
| `de-date` | 成交日期、平仓日期、练习保存日期随模式/页面变化；提供长日期以检查密度。 |
| `de-preview` | 底部比较面板可切换正常、加载、空结果；导航和工具区保持位置。 |
| `de-origin` | 底部比较面板提供首页/直接进入单选；只有首页来源显示弱返回入口。 |
| `de-return` | 返回动作显示明确“演示反馈”，不宣称生产返回。 |
| 键盘 | `1/2` 切换模式，`L/S` 切换列表/统计；聚焦模式/页签时左右键切换其组选项，其他空白区域左右键切换 D/E；输入/选择框及已聚焦单选/页签不被比较器劫持。 |

## 规格覆盖与边界

- D：交易库标题、模式、页面相邻于顶栏；E：标题与返回在顶栏，模式与页面相邻于紧凑第二行。
- 去除了重复根标题、面包屑、来源说明与重复应用摘要；上下文仅保留一次且日期口径仍在控件/上下文中可读。
- 1440×1000 与 1280×800 使用稳定侧栏、顶栏、工具区和结果区；模拟列表保留未平仓提示，统计保留最差练习回撤 `—`。
- 本文件是待确认的视觉样例，不关闭 Issue06，不代表正式生产采用；真实浏览器交互、截图和最终接受由 root 独立记录。

## 未覆盖 / 由协调者验收

本原型不提供业务分页、搜索、数据库持久化、移动/触屏版本。上述项目不属于本次 D/E 导航视觉比较范围。
