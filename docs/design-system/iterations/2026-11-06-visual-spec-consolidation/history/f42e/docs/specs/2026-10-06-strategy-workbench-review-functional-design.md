# 策略工作台评审修订：功能设计

日期：2026-10-06。设计负责人：当前聊天 root。状态：**已确认进入视觉原型迭代的功能设计稿**；用户已选固定底部操作栏，其余新增呈现通过本轮原型收集反馈。本文不代表原型、生产功能或既有决策票已接受。

## 1. 本轮边界与依据

用户要求“按策略工作台评审要求完成功能设计”，并以“确认”选定本次终点为正式功能设计规格。前一轮将[策略工作台设计评审](../../.scratch/strategy-portfolio-backtesting/design-report-2026-10-06/策略工作台设计评审.docx)的八项建议转为页面职责、动作、状态、异常与验收条件；前一轮止于文档；用户随后确认本轮进入视觉原型迭代，正式业务开发仍暂缓。

评审的 R01–R08 在本文记为 **DR01–DR08**，避免与原产品需求 R01–R06 混淆。新增局部元素使用 RD 前缀，LIB/WB 仍指既有区域。

继承的共同契约以[V1 与 A 融合设计](2026-09-30-strategy-workbench-v1-integrated-design.md)的 IF01–IF10 为准；库与创建采用[策略库规格](2026-09-30-strategy-library-and-experiments.md)的 SL/LD/LT 与[交互模型](../../.scratch/strategy-portfolio-backtesting/strategy-library-interaction-model.md)的 M11–M15；观察、结果、事件采用[稳定工作台规格](2026-09-30-strategy-stable-workbench-design.md)的 SW/WB/WD 与[第三轮行为契约](../../.scratch/strategy-portfolio-backtesting/workbench-design/REPAIR-03-CONTRACT.md)。本稿只细化八项评审建议，未决的包数量、排序默认值和比较指标顺序继续由原决策票处理。

继承约束与新增提案分开：四步创建、五档期限、独立本金、历史版本锁定、时间安全和已选 A 布局均不重新选型；固定底部操作栏已获用户确认；信息分组与提示位置通过本轮视觉原型供用户反馈。历史图是问题和尺寸参照，不是八项改动已实现的证明。

## 2. 完整旅程与页面职责

```text
我的实验 → 设置起点 → 选择完整策略 → 预览组合 → 确认
                                                    ↓ 锁定一次
列表 ← 暂停并返回 ← 待开始 → 推进完整日 → 暂停/回看
                       ↑                   ↓
                 重开原运行            阶段结果/组合对比
                                           ↓ 保存来源
                                      事件日观察投影
                             关闭详情 ↙          ↘ 返回来源
                                  停在事件日      恢复原结果/对比
```

- 策略库管理可复用方法；普通新建实验入口只在“我的实验”。切业务页签不创建草稿、不隐式选择策略。
- 实验选择的是完整策略版本。每个所选配置形成一个独立组合，各有独立本金；策略定义与仓位/调仓预设分别显示。
- 预览只说明候选、信号与目标分配，尚无持仓、成交或收益。确认成功锁定快照并进入待开始，不自动推进；首次推进不承诺必然成交。
- 结果和对比读取已有运行。查看事件只回看已知事件日；关闭详情与返回来源是两个动作。
- 库详情、包历史及嵌套配置逐层返回；实验草稿、查询、滚动、焦点和运行来源均按 IF04 保留。

F18 的回撤样例与 A 的动量样例仍是独立设计材料。后续必须用同一实验及锁定快照建立整条状态链；跳到固定 A 样例不算创建成功。

## 3. 八项功能设计

### DR01 · 固定时间状态组（评审 R01，P1）

**元素：RD01（既有38px业务上下文行，位于WB02摘要下、WB03图头上）；关联WB05状态位。** 集中展示“当前查看日”“已运行至”“结果截止”，顺序固定。日期采用等宽数字；查看日用主文字与较高字重，另外两项用次文字，状态区别不只依赖颜色。组合身份仍在原实验身份行/组合选择器，不为新增标签再加标题行。

| 状态 | 标签和值 | 解释与限制 |
| --- | --- | --- |
| 待开始 | 当前查看日 T0；已运行至 T0；结果截止“尚未查看结果” | 初始净值 1，现金为该组合本金，持仓/成交 0；不暗示已回测至计划终点 |
| 播放/暂停 | 当前查看日 V；已运行至 M；尚无结果截止时用明确文字 | 推进完成后整页同步；加载中保持最后完整投影，不能只先换日期 |
| 回看 | 当前查看日 V；已运行至 M；结果截止保留已有上下文或“尚未查看结果” | V≤M；注明“回看”，不把查看日误当运行退回 |
| 阶段结果 | 当前查看日保留观察来源 V；已运行至 M；结果截止 R | 图头明确“阶段结果”；只计算至实际可用截止，不自动推进 |
| 组合对比 | 保留 V/M/R；图头另明确“共同截止 C” | C=min(R,M,所有纳入组合的完整执行截止)，指标采用共同有效区间；不能用 R 替代 C |
| 从结果/对比看事件 | 当前查看日为事件日；已运行至 M；结果截止显示来源 R | 图头明确“事件日回看”；来源截止是已知上下文，不允许展示事件日以后的收益/持仓/成交 |
| 部分失败 | V为当前所看日；M保留实际行情进度，各组合Mᵢ保留各自最后完整执行截止；结果截止不虚构 | M可晚于失败组合Mᵢ，不全局倒退M或把失败组补齐到M；行情/成交各受其截止限制，未知不能作0 |

38px 行不换成两层，也不缩小关键文字。完整长名称通过 RD08 查阅；若压力状态容不下，先减少重复身份文字，再调整同一行分配，不删时间字段。显示过去日期时，图表、轴范围、tooltip、摘要、持仓和事件都受所看投影截止限制。

### DR02 · 四步创建的常驻主动作（评审 R02，P1）

**元素：RD02 / LIB09；用户已确认固定底部操作栏。** 把已有创建页操作栏放到内容滚动区域之外、业务页签以下工作区的底部，复用现有 62px 操作栏、≥36px 按钮和字体。正文与摘要在其上方滚动；操作栏实际占空间，不覆盖表单。本轮沿此已选布局迭代，不再实施右侧摘要主按钮候选。

| 步骤 | 唯一主动作 | 次动作 | 主动作不可用或执行中 |
| --- | --- | --- | --- |
| 设置起点 | 下一步：选择策略 | 返回我的实验 | 必填/日期/金额错误显示字段原因和汇总；定位首个错误，保留所有输入 |
| 选择策略 | 下一步：预览组合 | 上一步；新建策略为页面内次动作 | 未选择或定义不完整时说明原因；详情查看不代替选择 |
| 预览组合 | 下一步：确认配置 | 上一步：选择策略 | 正在检查或必需条件失败时不能继续；无需候选/信号时按 DR03 区分 |
| 确认并进入 | 确认并进入待开始工作台 | 上一步：预览组合 | 检查中/阻断/提交中/结果不确定分别显示原因；提交中禁止重复动作 |

操作栏左侧仅放简短状态与可达的“查看检查详情”，完整多条原因置于正文检查区；不把长错误塞入固定行而挤掉按钮。未填写信息不能靠缩小字体、隐藏字段或取消研究期限解决。正文末尾保留可滚到的最后字段；Tab/Shift+Tab 可到操作栏和原因入口；定位错误时字段不被遮挡。

上一步及返回列表保留草稿身份、当前步骤、期限、日期、本金、集合、所选版本和预设。实验来源新建策略成功追加选择，取消原样返回，保存失败保留策略编辑内容与原实验草稿。

确认的重试必须核对同一提交结果：明确失败可重试；结果不确定先核对是否已生成运行，不能再次盲建。锁定发生在确认成功时；进入工作台前已经锁定，首次播放不再补做锁定。

### DR03 · 预览、实际预检与演示能力分层（评审 R03，P1）

**元素：RD03 / LIB09。** F17 摘要首屏突出“尚未成交”，并保留“标的持仓 0／现金为独立本金”。内容按“候选范围”“买入信号”“目标配置与成交检查”组织；目标权重、金额与实际持仓分开，目标不能绘成已发生的成交。

| F17 情况 | 用户可见状态 | 对下一步的影响 |
| --- | --- | --- |
| 有候选，信号待运行确认 | 候选数及其 T0 可知依据；“信号待逐日运行确认；尚未成交” | 定义/数据检查通过可继续；不生成交易 |
| 无候选 | “当前时点无候选，组合保持现金”及筛选依据 | 无候选本身不是数据故障；符合既有策略规则时允许继续 |
| 无买入信号 | “当前时点无买入信号”，与无候选分开 | 不假定信号必在下一日出现；不生成持仓 |
| 必需数据未知或不足 | 所属组合、包版本、缺失能力/区间和处理动作 | 不能以 0 个不足或无候选代替；阻断继续确认 |
| 包不兼容/版本不可执行 | 精确指出策略、包和版本 | 返回选择/配置处理；保留输入，不自动升级或替换 |

F18 依次展示三组信息：**实际必检项 → 执行口径及限制 → 合成示例/待接入能力**。“示例检查通过”不使用实际通过的总徽标，也不能使真实确认按钮可用。

| 检查状态 | 展示与动作 |
| --- | --- |
| 未检查/检查中 | 逐项可见；真实确认不可用，说明等待哪项；保留草稿 |
| 已通过 | 每项绑定当前草稿、策略/包版本、区间、本金/预设和数据依据；总体通过才可确认 |
| 不满足 | 关联对象、原因、缺失范围及“修改配置/调整区间/重新检查”；不得丢字段 |
| 未接入/未知 | 明确“未接入”或“无法确认”；若是运行必需能力则阻断真实确认，不能把它降为提示 |
| 版本或配置变化 | 保留显式所选版本；使受影响的旧检查失效并重新检查，未完成前不能确认 |
| 检查失败/响应过期 | 保留输入及最后检查信息，旧信息标过期；忽略不匹配当前草稿的响应，可重试 |

必检项包括：策略/包引用与可执行版本、参数与预设完整性、市场/数据能力、区间与预热、历史可知口径、交易日历及有效终点、宿主执行与费用能力。显示实际范围，不虚构检查已接入。费用、分股、下一可交易时点和日线无法证明盘中先后等限制保留原口径，不从示例推导新成交规则。

“尚未成交”只描述当前事实；预检通过只说明配置可进入运行，两者都不保证未来信号或收益。静态设计可另设明确标注的演示导航，不能伪装成真实确认成功。

### DR04 · 只读原因紧邻回放控件（评审 R04，P1）

**元素：RD04 / WB04回放条；关联WB05状态位。** 阶段结果与组合对比保留原 44px 回放条及播放、单步、速度槽位。禁用控件旁常驻“只读，返回观察后推进”，提供“返回观察”动作；无需悬停即可理解。详细原因可通过聚焦邻近说明访问，禁用控件使用可读名称及说明关联。

“返回观察”恢复进入结果前保存的观察组合、V、图表模式/视野和面板，保持暂停；M/各组合完整执行截止不变。返回不会立即播放；若V<M仍属回看，播放/单步继续禁用并提示“正在回看，返回最新进度后推进”，用户主动返回最新才将V定位到M且不扩大M。后续推进还需检查运行是否完成或失败；完成/失败说明对应原因与可用动作，不能把所有禁用原因统称只读。

38px 上下文、44px 图头和44px 回放条的职责各自固定。只读说明置于回放条，不新增下方行；完整详情在既有检查区可读。输入或中文 IME 焦点期间快捷键不推进；只读模式也不响应播放快捷键。

### DR05 · 事件关闭与返回来源分开（评审 R05，P1）

**元素：RD05 / WB06–08。** 在 320px 检查区的现有标题动作位显示“返回阶段结果”或“返回组合对比”，按真实来源命名；详情末尾保留“关闭详情，停在事件日”。首次进入事件时，现有提示区说明：“关闭后仍查看事件日；返回［来源名］恢复来源截止和位置。”不增加覆盖式抽屉。

| 动作 | 目标与保留 | 视野/不可发生 |
| --- | --- | --- |
| 在结果/对比点事件 | V=该事件日；M/各组合截止不变；整页原子切到事件日观察 | 显示该日目标点；不只更新右栏，也不显示未来数据 |
| 关闭详情 | 同一事件日观察，检查区退回该组合常规详情；保持暂停 | 保留事件日视野；不回来源结果、不推进 |
| 返回阶段结果/组合对比 | 恢复来源模式、R、组合/纳入集合、筛选、滚动和图表视野 | 只恢复原来源；不重新运行、不自动播放 |
| 事件→锁定配置→包历史→逐层返回 | 先回配置，再回事件日详情 | 不越层回结果；查看历史版本不改运行 |
| 来源无法恢复/对象失效 | 仅来源视图上下文不可恢复、原运行和事件仍有效时，可停当前事件日并提供合适入口；实验/运行/事件对象已失效时，说明原因并按IF04回我的实验/策略库合适入口 | 不把失效对象的缓存当有效投影，不猜测另一个实验或替换截止 |

Escape 关闭最内层可关闭详情并恢复入口焦点；事件详情层与“关闭详情”相同。浏览器返回遵循 IF04 的来源层级：嵌套详情退一层，事件详情先退到同日观察；来源结果恢复使用明确的命名动作，不能把首次关闭当成恢复结果。关闭后仍保留返回来源入口，直至用户完成显式返回或合法切换到新的来源。

保留事件全部解释字段：触发原因、截至事件日的可知依据、旧/目标/实际权重、成交/未成交、费用；长内容在检查区内部滚动。没有下一已知事件时显示原因，不推断未来事件；“展开剩余”沿用单独确认与取消契约。

### DR06 · 实验卡片只做文案去重（评审 R06，P2）

**元素：RD06 / LIB08。** 保留当前卡片布局、外尺寸和字段槽位；状态徽标是唯一重复性状态展示位置。研究起点与含同一起点的区间合并为“研究区间：起点 → 计划终点”，时区仍可见；未设置部分明确“未设置”。运行/结果的实际截止仍单独显示，不能拿计划终点冒充已运行至。

| 状态 | 唯一主动作 | 保留信息 |
| --- | --- | --- |
| 草稿 | 继续编辑 | 原步骤、已填范围、已选组合数；未设置值不编造 |
| 待开始 | 进入观察 | 初始范围、组合数、未推进状态 |
| 运行中/暂停 | 返回观察 | 当前运行进度；离开先暂停，重开同一运行 |
| 完成 | 查看结果 | 实际结果截止，完整实验身份 |
| 失败 | 查看原因 | 失败摘要、最后完整截止、恢复入口 |

不因此删除查询、版本、组合数或更新时间，不合并原运行与派生实验；失败原因保留可读摘要与详情入口。高度压缩、信息重排、字段删除和默认排序变化均不在这次去重授权中。

### DR07 · 独立组合与版本身份贯穿创建（评审 R07，P2）

**元素：RD07 / LIB09、WB01/08。** F16 计数旁显示“已选 N 个完整策略，将生成 N 个独立组合；每个组合本金 ¥X”。选中区分别列“策略定义：名称/版本/三类包”和“组合预设：仓位/再平衡/退出执行口径”，避免把宿主执行预设误当策略包内容。

选择与取消使用稳定策略/版本/配置身份，不按名字匹配。查看详情、嵌套包详情和关闭均不选择策略、不切最新版；取消选择仅移除指定配置。重复点击同一条目不重复创建组合，不推导未经决定的多预设选择规则。

F17、F18 使用同一份所选身份、版本、独立本金、预设及区间；缺失版本显示原因，不替换样例。改变选择/参数后重新检查，确认时冻结所有关联版本；从运行看配置只读。两策略必须显示两个独立组合，不能落到固定的单策略预览；取消一个后仅删除该配置，另一配置和草稿原样保留。

### DR08 · 长名称与详情连续性（评审 R08，P2）

**元素：RD08 / LIB07–09、WB01/06/08。** 长实验/策略/包名称在现有槽位省略时保留完整可访问名称；悬停与键盘聚焦提供完整名称，不依赖浏览器原生 title。已有名称为链接/选择器时复用该焦点；纯文字确被截断时提供“查看完整名称”入口，避免给全部元数据新增 Tab 停靠点。完整名称层 Escape 可关闭、焦点返回原入口；不能触发播放或导航。

320px 详情保持内部滚动，长内容时显示可见滚动条/底部连续性提示；滚到底后提示消失，短内容不出现假提示。切到新组合/事件时从新内容起点读，返回来源则恢复所保存的滚动；加载同尺寸中性占位，不能闪现前一组合或未来快照。滚动及提示不改主图边界。

## 4. 状态、数据与返回的一致性

本节描述语义约束，不冻结数据库表、API 或实现文件。

| 对象/上下文 | 必须维护 | 更新或保存边界 |
| --- | --- | --- |
| 实验草稿 | 实验身份、步骤、输入、所选策略/包版本、每组合配置及本金、检查状态 | 前后步/就地新建/返回不丢失；配置变化使相关检查失效 |

| 锁定运行 | 实验/运行/组合身份、版本、参数、区间/时区、数据快照、费用/执行口径 | 确认成功一次生成；库后续变动不能修改快照 |

| 观察→阶段结果/对比 | 保持M/执行截止；单组合阶段结果R受M及所选Mᵢ约束；对比计算至C=min(R,M,纳入组合的Mᵢ)及共同有效区间 | 失败组合保留原因；显式排除才重算；读取已有结果 | 保存观察来源；同一固定框架；记录原有未来暴露来源 |

| 已知观察→展开剩余/取消 | 明确确认才推进M及可成功执行的组合；取消不变 | 保留已看后续标记及来源；下一已知事件不替代此动作 | 沿用原运行；返回/刷新/派生均不能清除暴露来源 |
| 失败/加载→重试 | 保持最后完整快照；成功后才切入新投影 | 不把未知作0，不漏未来，不串身份；重试不重复成交 | 同尺寸占位；正式写入按原运行与提交身份核对 |

### 完整旅程

**J-RD01 创建与观察。** 我的实验→四步创建→选择两策略→取消一个再选回→包详情原处返回→预览→确认→待开始→真实图表推进完整日→暂停→列表→重开同一运行。沿途核对身份、版本、日期/期限、预设与每组合本金；确认不推进，推进必须显示新 bar/点，首次成交取决于实际信号。先由协调者接受此最小链，才扩大结果/对比接线。

**J-RD03 结果与事件。** 暂停→阶段结果/对比→事件→锁定配置→包历史→逐层返回→关闭详情停事件日→命名返回来源。核对整页投影、M/执行截止不变、R/C及筛选/滚动/视野恢复、未来信息不泄漏、不自动播放。失败组合未被静默排除。

**J-RD04 压力与可访问性。** 两档桌面/两导航态/断点，六组合、长路径/长名称、大金额、长错误和长事件详情；鼠标与键盘分别走查。主动作首屏可发现、输入不遮挡、完整名称可读、详情尾部可到达、只读原因不用hover、图表固定预算不变。
