## 本轮设计

主路径为：确认实验与组合 → 推进或播放 → 回看日期 → 查看调仓原因 → 阶段结果/组合对比 → 返回原观察位置。A 的应用导航、身份区、四项摘要、主图、图下回放和右侧详情保持固定分区。

- 净值图从实验起点开始；标的 K 线使用独立 OHLC，明确标的、日线及 CNY。约 80 根起点前历史、170 个模拟工作日用来检验连续密度和长时间回放；未接交易日历。
- 图表切换及回放使用可见文字。回看与运行分组，日期选择和速度具有名称，禁用原因就近显示。
- 模式为「回放观察 / 阶段结果 / 组合对比」；右侧为「组合详情：概览 / 调仓记录 / 统计指标」。结果和对比使用净值，返回观察恢复原图表和视野。
- 调仓进入事件日的整个工作区；关闭详情停在事件日，返回来源恢复原模式、截止和视野。无下一调仓时使用静态说明，不诱导展开未来。
- 场景进入默认关闭的原型演示工具；日常界面仅提供已选 A，B/C 作为历史设计记录保留，不再提供切换入口。日常界面使用业务日期，不要求理解 V/M/R。

准确来源：[稳定工作台规格](../../../docs/specs/2026-09-30-strategy-stable-workbench-design.md) SW01–10 / WB01–08 / WD01–07；[用户红框反馈](../references/2026-09-30-round2-workbench-feedback.png)；[TradingView 参考](../references/2026-09-30-round1-tradingview-reference.png)。借鉴紧凑工具和图下回放的组织方式，保留本项目深色、蓝色动作与净值优先的层级。
