# 港美股历史月结单导入设计

## 目标与依据

用户已将目标扩展为设计与实现。首版围绕股票/ETF 买卖回放，保留影响持仓、成本的辅助流水。原始 PDF 保持按月份归档，一份综合账单按行识别市场。研究依据见 `docs/research/monthly-statement-{template,time}-evidence.md`；旧 JSONL 不作为金标准。

## 设计

1. PDF.js 本地读原件，内容检测券商，再按列、章节和主从关系识别模板。历史日期仅作证据，不作为唯一分支。文件指纹和逻辑成交行定位稳定 ID；主行/合计不当成交，多笔相同经济字段保留 multiplicity。
2. 统一时间解释模块区分原时间、时区、UTC、市场日历日、业务交易日、账期及交收。行内明确时区优先；文档图例次之。IANA 区域按发生日期计算 DST，拒绝不存在/歧义时刻。用户明确选择来源时区可处理无证据或文档冲突，并保留 user 来源。下单时间不能升级为成交秒；日期精度限制为日级回放。
3. 逐笔保留模板、语义、来源页/行片段、金额、净现金和费用证据。Decimal 计算；费用详情与小计不双计，费用分配需对组小计守恒。缺费、未知成本、缺时区均不能静默补成可信值。
4. 月结单附带期初/期末持仓、转仓、IPO、分派及费用事件。库存快照不是虚构成交；市值/昨收价不是购入成本。复盘需识别初始非零库存与历史缺口，无法确定收益时明确未知，而非产生假的卖空或成本收益。
5. 原始文件只在浏览器解析。预览显示模板、月份、时间规则、问题、辅助事件和对账信息。用户可以对不确定时区重新解析，明确确认带警告的数据；结构损坏或数字不守恒等错误不自动放行。确认后证据随成交/导入历史写入 SQLite，取消不写入。
6. 接入现有股票分类、去重、冲突复核和回放路径，兼容 Excel/截图/招商。无成交月可作为文档与库存覆盖记录，不能视为损坏或伪造零笔成交。

## 验收

- 各历史模板有脱敏布局样例并对真实原件使用 PDF.js 抽验；完整扫描报告列出成功、无成交、需复核、拒绝和未覆盖情形，条数不等于正确率。
- 重点：同秒相同成交、主从跨页、费用分组、空方向、补回、账户隔离、股票基金分区、期初持仓卖出、转入后卖出。
- 时间：明确 GMT+8/US/Eastern，富途原件图例变化，未知与冲突选择，DST 春秋边界，跨午夜与夜盘月界，下单/日期精度限制。
- 导入取消、确认、重导、冲突、SQLite 重载以及原有输入路径回归；运行单测、类型检查、lint、build 和适用运行时/UI 检查。

### 使用方式

从“导入交易记录”选择一个或多个 PDF，逐份核对账期、模板、来源时间及辅助证据；需要时选择有依据的时区重新解析。随后检查股票分类及冲突，再确认保存。取消不写入。新导入的真实账户资料仍需用户在界面中确认，本次验收没有代为保存。
