# 首页和交易库：真实数据副本的读取基线

## 结论与范围

当前桌面页面未达到完整展示 1 秒的目标：在 1440×900 的内置浏览器中，首页提示“读取已超时，新范围未应用”，从首页进入交易库后提示“目标交易集合读取超时，请重试”。这是当前代码和隔离副本的一次实际观察，不是优化后页面的验收。页面上的“0 条持仓”伴随读取超时，不能解释成真实持仓为零。

单独探针确认两个读取接口各自返回 **34,315,599 字节**（约 32.7 MiB），它们仍然在传输同样大小的全量数据。探针直接请求 API，与浏览器首屏不是同一种计时，不将其耗时直接相加，也不以此推算完整首屏时间。

## 测试环境与副本

- 代码：隔离 worktree 的 `codex/home-read-mvp-experiment-20261029`，HEAD `0bbf7c4bfeabc325b4987966f93f45ff19f74d1f`；产品代码无本次修改。
- 机器：Intel Core i5-1038NG7、16 GiB 内存、x86_64；Node v26.0.0、SQLite 3.53.0；开发服务，端口 52955。
- 来源：按 `conf/runtime.json` 配置的共享业务库，通过 `scripts/debug-local.mjs` 的 `prepareDebugDatabase` 执行 WAL 感知在线备份，只对副本进行项目规定的初始化。冻结文件为 `.data/mvp-baseline-20261029/seed.sqlite`，51,781,632 字节，SHA-256 `176beaee3afe356984a3407f3ee99d276dd25862e2edc284eceafbbb9b6993e6`。副本文件未纳入 Git；不记录交易明细。
- 从冻结文件生成各自的可写工作副本；启动服务时显式设置 `TRADEREVIEW_DB_PATH`。浏览器会自动写入部分本地元数据或复盘信息，因此浏览器副本不能再当作未经触碰的冻结输入；实际副本可能包含 WAL，不能仅凭主文件哈希判断写后状态。
- 桌面浏览器验证前设置 1440×900，结束后已恢复视口。为避免实验中的自动标的名称解析访问外部服务，桌面服务通过 Node 的 `--use-env-proxy` 和指向本机不可用端口的 HTTP/HTTPS 代理阻断外网 fetch；这不关闭页面内自动解析队列，该队列失败后仍可能再次读取 bootstrap。外部行情补齐及其耗时不在此次数据齐备的本地目标内。

## 独立接口探针

顺序执行请求，响应写入 `/dev/null`，只记录状态、首字节、总耗时及字节数。第二次启动所用工作副本从冻结种子复制后设为可写：

| 请求顺序 | 接口 | HTTP | 总耗时 | 首字节 | 字节 |
| --- | --- | ---: | ---: | ---: | ---: |
| 1 | bootstrap | 200 | 12.404 s | 12.386 s | 34,315,599 |
| 2 | homepage-source | 200 | 4.106 s | 4.091 s | 34,315,599 |
| 3 | bootstrap | 200 | 4.446 s | 4.326 s | 34,315,599 |
| 4 | homepage-source | 200 | 8.154 s | 8.139 s | 34,315,599 |

首次请求包含开发服务编译；后续样本仍受本机负载及缓存影响，每项仅一次，不代表分位数。直接请求 `homepage-source` 无浏览器带的版本参数；这一测试用于识别载荷和单请求成本，不能代替页面场景。

复现方式：在隔离 worktree 中，从该冻结种子复制出新文件并设置用户可写权限；以 `TRADEREVIEW_DB_PATH` 指向该文件，使用项目锁定的 Node 启动 `scripts/start-local.mjs --dev --hostname 127.0.0.1 --port <空闲端口>`。服务就绪后依次运行 `curl --silent --show-error --max-time 60 --output /dev/null --write-out 'status=%{http_code} total=%{time_total} first_byte=%{time_starttransfer} bytes=%{size_download}\n' http://127.0.0.1:<端口>/api/storage/<接口>`，接口顺序为 `bootstrap`、`homepage-source`、`bootstrap`、`homepage-source`。必要时另行设定本地外网代理，完成后停止仅由本次实验启动的服务。

## 环境失败记录

第一轮探针的工作文件从只读冻结样本复制后继承了只读权限，接口返回 HTTP 500。对该探针文件进行独立 SQLite 写入检查得到 `attempt to write a readonly database`；重新从种子复制并设置可写后，四次接口请求均返回 200。该失败是实验配置问题，不作为产品 500 或性能结果，也未触及业务库。

## 当前限制

事实投影实验如果只返回成交身份、范围与分页，不能证明首页持仓、财务指标、回合、行情、汇率或完整交易库的正确性与一秒体验。需另行检验版本失效、实际变更后的首次读取与完整 UI；暂停任务仍按原限制处理。
