以下保留过程记录。

2026-10-25：用户确认[练习日期的补填、更正入口及来源保护](comments/TL11-D02/2026-10-25-practice-date-edit-confirmation.md)，已同步领域规范。未知日期的筛选展示仍待决定。

2026-10-25：用户确认保留历史信息、能够合并更新的尽量合并更新，以保护人工工作为主要原则。已同步[领域规范](../../docs/design-system/domain-language.md)及[确认记录](comments/TL11-D02/2026-10-25-preserve-manual-work-confirmation.md)；未受影响部分沿用，受影响部分保留内容并待核对。

2026-10-25：用户确认同一账户、标的和练习日期下，全部交易内容相同，仅格式或行顺序变化，也属于重复。已同步领域规范与[确认记录](comments/TL11-D02/2026-10-25-equivalent-duplicate-confirmation.md)，不代表运行时能力已实现。

2026-10-25：用户确认练习命名，同时补充导入时需要比较文件是否完全一致，防止重复导入。同一文件重导不新增练习和编号；仅格式变化与修订文件的识别仍待决定。已核对现有文件指纹及成交级重导逻辑，见[确认与源码证据](comments/TL11-D02/2026-10-25-naming-dedup-confirmation.md)。

2026-10-25：已保存[三种时间的确认](comments/TL11-D02/2026-10-25-date-confirmation.md)并同步公共领域词汇。练习日期用于标题及模拟盘筛选、排序和统计归属；历史交易区间与导入时间分别呈现。无法识别练习日期时显示待确认。命名及日期异常交互仍未决。

地图是权威索引，每个决策只保存在自己的票及后续独立 Resolution 中。以下命令只读，不领取或关闭票：

```sh
python3 .scratch/trading-library-v11-design-decisions/frontier.py
python3 .scratch/trading-library-v11-design-decisions/frontier.py --all
python3 .scratch/trading-library-v11-design-decisions/frontier.py --mermaid
```

建图不等于决策完成或 UI 交付。下一步默认从“账户、练习与完整交易的边界”开始，一次只解决一张票；与业务语义无依赖的模式滑块/底色探索也可独立推进，但不改变先处理概念冲突的优先顺序。

2026-10-24：用户确认实盘两份开平仓配对计两个复盘回合，并要求项目统一使用。已新增[项目公共设计规范：领域词汇](../../docs/design-system/domain-language.md)及全站设计索引入口；统计与账户关联仍待确认。

后续统计层级已确认：模拟盘汇总按练习，内部配对统计放在详情，列表可增加预览列；具体收益计价与样本资格仍未决定。

2026-10-25：已确认练习整体收益包含结束时点浮动盈亏，费用只扣一次，缺少必要估值价格显示暂不可计算；收益率本金与胜率样本资格仍待确认。

2026-10-25：胜率分母已确认，持平计入，暂不可计算单列且排除；五次练习中2盈、1亏、1平、1未知的胜率为50%（2/4）。收益率本金与账户关联尚待明确。

2026-10-25：已确认练习收益率以本次练习初始资金为分母；本金缺失或非正时百分比暂不可计算，金额和胜率依据其自身输入判断。剩余重点为账户关联及实际数据来源。

2026-10-25：已确认一个模拟账户可以包含多次练习，账户下拉筛选所属练习，不拼接权益曲线。已核查导入字段及其与新定义的差距，见[源代码核查](evidence/2026-10-25-import-capabilities.md)。仍需澄清分批成交与交易决策的计数边界，概念票保持 open。

2026-10-25 最新澄清：复盘跟踪人的行为，同次买入决策对应的一次卖出操作即使技术拆单也只计一个回合。此前“两份配对即两个回合”的解释暂停使用，历史记录已加指针；一次主动卖出关联多笔开仓的反例尚待确认。见[行为边界澄清](comments/TL11-D01/2026-10-25-human-action-confirmation.md)。

2026-10-25 当前结论：用户已明确一次主动卖出80股即一个已完成配对回合，剩余70股随后主动卖出后累计两个回合。多笔开仓配对或技术拆单不增加回合；配对完成与用户完成复盘分开。此前计数争议已解决，见[本次确认](comments/TL11-D01/2026-10-25-completed-action-rounds-confirmation.md)。

2026-10-25 语义补充：已完成回合指“已完成的单次交易”，一次完整交易包含开仓与本次平仓的配对；继续区分交易完成、持仓清零、复盘完成。见[用户原话及规则](comments/TL11-D01/2026-10-25-completed-trade-meaning.md)。

2026-10-25：已保存[领域定义决策结论](comments/TL11-D01/2026-10-25-resolution.md)，关闭概念票。新增“人的交易行为识别与配对范围”，承接未决识别规则并阻塞复盘状态聚合；不阻塞练习名称与日期讨论。
