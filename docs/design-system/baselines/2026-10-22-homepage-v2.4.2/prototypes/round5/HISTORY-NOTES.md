# 历史图表原型实现记录

最终实现由 root 接管整合，覆盖单年/月度、跨年/年度、净盈亏/累计/胜率/回合，四卡与曲线同一数据口径。范围选择后直接读取；600ms示例等待，成功才应用范围，失败保留旧范围，重试可完成。没有额外“应用”按钮。

图高354px，宽度随桌面容器计算；窄屏保留1148px画布横向阅读。线2px，点径6px为候选；零线#A8B6CB、网格#283448。未知不等于零，累计缺失传播到后续。当前表现仅线条样式参考，无当前曲线交互。

真实动作、图稿、范围限制见 [集成验收](evidence/ACCEPTANCE.md)；[独立复核](evidence/INDEPENDENT-REVIEW.md)。初稿失败证据保留，旧worker对未实现API/固定viewBox的描述以本记录替代。
