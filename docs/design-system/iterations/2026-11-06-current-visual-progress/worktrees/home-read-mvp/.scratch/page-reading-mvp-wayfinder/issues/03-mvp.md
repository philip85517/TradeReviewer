## Question

隔离 MVP 能否通过提前准备并保存可复用结果，加上轻量摘要与分页，减少重复计算，同时保留正确性、可追溯和清楚的更新状态？

## Scope / Refs

- 在实验副本和独立代码中实现最小可证伪原型，不修改正式产品、不部署，按用户确认的暂停范围限制运行。
- 保留范围、缺失状态和版本；记录准备时间、CPU、空间和传输，不假设行情、汇率和成交相同更新节奏。
- 不改变历史成交或关闭原有校验；隔离测试的合成数据与来源副本明确区分。
- 按页面设计保留正常展示、日期口径、完整范围的筛选排序统计及必要详情；不能做到的范围显式标注，不冒充完整 MVP。

## 验收标准

- [ ] 留下可执行的实验方案和一次性原型、数据来源、控制变量及边界。
- [ ] 与基线对照展示不重复准备时读取成本、首次准备、变更更新、重启后的读取和资源消耗。
- [ ] 用至少跨账户、跨页、补导入历史成交、金额依据缺失和版本变化反例判断正确性；涉及暂停范围的反例仅列待恢复，不宣称已验证。
- [ ] 记录用户对原型结果的实际判断及独立 Resolution；不得把样本通过扩展为完整产品通过。

## 2026-10-29 隔离实验进展

- [真实数据读取实验](../../real-data-fact-experiment/RESULTS-RUN-02.md)：准备后的窄数据读取成本很低，但首次准备单次耗时 7,312.530 毫秒，其中来源读取和完整合同校验各约 3.5 秒；尚未验证浏览器完整首屏。
- [历史补录和跨组修订实验](../../update-publication-experiment/benchmark/reports/run-review-approved-01/COORDINATOR-ACCEPTANCE.md)：真实规模的实验投影上，合成变更的增量更新与完整重建结果一致；没有接入实际导入流程。
- [显示信息与重启复用实验](../../display-cache-restart-experiment/COORDINATOR-ACCEPTANCE.md)：合成数据中，名称或账户显示名变更能够使旧缓存失效，重启后未变更的数据可复用；摘要计算的真实规模开销尚未测量。
- [来源准备分段诊断](../../source-preparation-profile/reports/approved-01-plain-report.md)：真实规模隔离副本上，三组对照的完整来源读取与合同解析约 7.3–8.5 秒；重复编码、复制和逐页解析是后续优化候选，不能将子阶段时间直接相加。独立结果审查仅接受本次诊断范围，不代表页面达标。
- 首页与交易库的桌面完整首屏一秒仍未验收，财务、Bars 和重复导入任务保持暂停。本票继续开放，不能把独立实验通过视为产品目标通过。

## 2026-10-29 来源复用真实规模对照

- [实验结果](../../source-reuse-experiment/reports/real-sample-01.md)：12 样本内容一致；材料复用总耗时中位数 7.99 → 7.63 秒，编码复用的解析中位数 4.09 → 3.66 秒，但总耗时中位数 7.52 → 8.19 秒，受来源阶段波动影响，均不能证明一秒目标。
- 材料候选有可复现的旧 context 接口风险；实验代码尚不能直接用于产品。数据为预热后的后端对照，不包括完整桌面首屏、首次准备和重启首次读取。
- 总票继续开放：真实导入接线、轻量摘要与分页、真实浏览器一秒验收、生产更新和失效等尚未通过；财务、Bars、重复导入保持暂停。
