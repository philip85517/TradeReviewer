# 第二轮独立验收：仅限非财务读取实验

结论：**实验范围通过；首页、交易库和一秒目标尚未验收。** 独立验收由未参与实现的 Luna 6 Max 完成，协调者核对结果与限制。首轮 B 路线重复排序导致公平性未通过，原始记录保留；第二轮修正后再次测量。

- 冻结代码与运行身份摘要一致；第二轮 58 项内部检查通过，两种范围各有 A、B、C 三条路线各 7 个样本。
- 数据源是隔离且只读的冻结副本，实验结束后源与种子摘要保持不变。真实样本覆盖同标的跨两个账户与同日跨页；精确时间戳相同、空账户和撤销记录没有真实反例，只能按实际合成测试范围说明。
- 独立验收补充以内存数据库检查预备结果的旧游标遇到四类绑定变化均被拒绝。这不等于产品已经具备动态更新或失效机制。
- 全范围 A、B、C 的中位数分别为 8,474.79、7,175.89、0.677 毫秒；C 的数字是进程内的非财务摘要与一页读取，不能代表 HTTP 或页面完整展示。每组仅 7 次，报告中的 p95 实际为该组最大值；CPU user 和 system 取样时刻有一次函数调用差异，只能视作近似值。
- 首次准备 7,312.53 毫秒；没有验证导入或修订后自动更新，也没有验证财务、持仓、回合或真实页面。组合范围 B 出现 44.5 秒最大样本，不能把其当成稳定收益。
- 每次读取不会重新计算全部持久化数据摘要；返回内容的校验不能证明整个存储未被篡改。并发发布、断电恢复及产品级数据版本管理尚未验证。
