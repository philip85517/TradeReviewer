## 设计方向与取舍

把复盘做成安静、可读的图表工作台：看行情和在图上写判断是主任务。阶段是时点约束，计划是当时假设，成交是实际证据，结论是后续形成内容。视觉应帮助分清这四种角色。

推荐保持中文阅读尺度与明确字重，保留现有暗蓝主题和盈亏色；标的、图表工具、阶段与辅助动作分组，桌面宽度允许时共用紧凑一行，不足才按整组换行。常驻两行不是默认要求；额外高度必须有可说明的内容或动作收益，不能只为重排占用图表。侧栏按内容需要和绘图区预算取宽，不能先规定三栏或比例。与首页布局无继承关系。

本轮只推荐一种修订方向：紧凑顶部、角色明确的右侧阅读区；同数据baseline用于比较，不是第二候选。用户已指出顶部空耗，本次直接纠正，不把这个缺陷继续当作审美取舍。

## 文字角色

| 角色 | 字号/字重/行高 | 用途 |

| 阶段 | 14/500/21 | S0入场前、S1持仓中、S2退出后/事后复盘，不能只剩S编号 |
| 面板标题 | 16/600/24 | 原计划、当前观察、退出评价 |
| 组标题/字段 | 14/500/21 或 label12/500/18 | 划分判断、事实、规模，长字段完整显示 |

| 元信息 | 12/400/18 | 来源、时间、版本、帮助，不承载核心判断 |
| 数字 | 14/400/21 tabular | 价格、数量、盈亏；单位随值，未知不写0 |
| 图上Text | 默认14/21；保留用户12/14/16/18/24/32 | 段落完整，手动换行保留；已有文字尺寸不得批量覆盖 |

不要用字重400的h标签假装层级；也不要把所有标签加粗。中文行高以完整段落校准，数值标签以基线校准。价格不得为排版裁小数，只允许派生指标有明确约数和完整值查看。

## 语义颜色

沿用既有tokens：page #0b1220、surface #111a2b、chart #101722、text #e7edf6、muted #adbbcf、faint #9cacc2、blue #2f80ed、gold #f3ba2f。涨跌默认#26a69a/#ef5350，尊重用户现有teal-red/green-red/blue-orange设置；阶段、好坏评价不得借用盈亏色做唯一编码。

选择/焦点用蓝色；计划假设用金色+虚线+文字；历史原判断用带来源/阶段的原Text；当前补充另写，不覆盖原文。风险警告用语义文字和图标同时表达。装饰网格/分隔允许低对比；输入识别、选中边界与焦点不能按装饰处理。实际颜色验收用层叠后背景和opacity计算，不只检验hex。

## 尺寸、间距、图标

间距以4/8/12/16/24为基准。4用于同控件内部标签与图标，8用于相邻操作，12用于同组字段，16用于段落/面板内边距，24用于主题区分。已有14px chart/aside间距可保留，作为经过图表轴预算验证的例外，不强行改到16。

按钮/输入桌面36px高，内边距8–12px；主要推进若40px需同组统一。窄窗或coarse pointer44px高。图标大小与命中框独立：常规18、绘图19、附属16px，Lucide stroke2；不要放大到充满按钮。长按钮文字自然换行或一组下移。圆角6控件、8面板、10大型模态；禁止每张信息块都加独立外框。

### 面板开合与操作入口

左右面板入口分别靠工作区左、右边缘，展开/收起由同一常驻入口完成，不从另一边或底栏恢复。下方记录入口与回放工具保持同一操作基线；记录展开不能把入口变成另一条全宽按钮。开合只改变布局，不能推进双截止、fitAll、改写原文或清空表单。

图标化只改变可见表现，仍使用实际 button；完整中文 aria-label、hover/focus 动作提示、禁用原因、选中/按下/展开状态和 36/44px 命中框都需保留。工作区快捷键必须让原生按钮的 Space/Enter 激活，不得误启动回放。内容收起或 Escape 后焦点回到可见入口。

本轮候选使用18px图标、2px组内间距、8px组间距、4px操作圆角；父级间距与组分隔只能计算一次，不能叠加成双倍空白。手机最终级联必须保留44×44；左右入口锚定顶栏首行顶部4px，宽屏coarse入口各预留56px。左右提示向内、底栏提示向上，检查实际焦点/hover下没有裁切。这些是源码规则，等待真实computed/rect校准，不冒称为TradingView实测参数或最终视觉通过。

验收独立登记入口和目标区域：在同态视口检查左右边缘对应；开→关→重开保存按钮/父容器/舞台/价格轴的 before/during/after rect 和滚动偏移，验证入口不跨区域、不变长，内容可恢复。还需对 More/计划互斥和恢复、窄断点两侧、编辑中/禁用/空记录/长截止、键盘 Tab/Space/Enter/Escape 分别取证。截图静态整齐、CSS 设置正确和组件 mock 均不能代替这条实际动线。

## 复盘页面规则

S0/S1/S2是一个工作区的知识状态。阶段名与市场可知截止、成交截止同时明确。按阶段逐步展示事实；S2主动完整历史后，回退仍标“已看后续补记”。Tooltip、列表、摘要、图层、图表范围不能暗中泄露后续价格或成交。

每个判断有形成阶段、所属决策/全局、图表锚点和知情截止。推进保留原图形与原Text可见证据；新观察独立，最终结论独立；历史分析补填标复盘补记。原计划和实际结果并排或前后可对照，但不要求固定栏数。固定评论、完整理由、重要价格不能为排版缩短。侧栏收起可以释放图表，不等于删除内容。保存留存必须实际持久化。

默认视口服务当前决策。图表绘图区、右轴、工具栏和阅读区按可用宽预算；缺空间时降低并排复杂度而非无止境缩字。旧参考300–320侧栏不是永远固定比例。样板初步采用更易读预算，最终参数以截图/实测附录为准。
