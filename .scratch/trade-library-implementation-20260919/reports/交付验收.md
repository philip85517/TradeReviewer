# 交易库改造：实现与验收

当前状态：01–09实施与验收已完成，独立 Luna QA 已对照 R1–R8 收口，协调者完成代码复核、真实浏览器验收与最终回归。

## 实现范围

- 默认实盘、按标的浏览；两个视图共用筛选与排序，复盘返回保留展开、页码和浏览位置。
- 常用条件常驻，高级筛选改为右侧抽屉，应用才生效；来源平台多选、友好运行名称、可移除条件标签。
- 同一证券跨账户合并为一行，展开后按完整交易回合进入复盘；不同模拟运行分开统计。
- 已平仓净盈亏、按开仓金额加权收益率、胜率与复盘进度统一口径。未知/持仓中样本不按零收益处理，统计详情披露样本与排除原因。
- 最新汇率折算人民币，保留原币。汇率只在手动触发时向外部来源更新；失败保留完整缓存及日期。
- 最近成交、人民币净盈亏、收益率表头排序；模拟盘须明确选择单个运行才允许绩效排序。
- 每页最多100个股票/回合；分页只限制显示，统计、排序及“开始复盘”仍使用完整筛选范围。
