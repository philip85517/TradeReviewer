# 交易室布局与导航重构规格

状态：已实现并完成布局与交互验收；验证详情见本地任务验收记录。
日期：2026-09-21
功能编号：`trading-room-layout-reorganization`
设计原则：简约、聚焦、清晰

## Problem Statement

当前一级功能位于顶部，各模块内的切换位置不统一，导航、筛选与内容之间缺少清晰层级。本次将四个一级功能移至左侧，将必要的二级切换统一放到内容顶部。

本期聚焦导航和布局，复用现有业务内容。此前关于收益计算、趋势能力和数据配置的要求继续由原有规格约束，不在本次导航重构中重新扩展。

## Solution

### 布局

- 左侧放品牌和四个文字导航：我的交易室、交易库、模式洞察、数据管理。当前项用浅色背景与明确文字状态标识。
- 右侧顶部只保留一行页面标题和必要操作；有二级切换时紧接一行标签，其下为筛选和内容。
- 不另设全局顶栏、常驻面包屑、重复页面说明或装饰性统计卡。
- 二级标签用于切换独立内容；期间、实盘/模拟盘、分类和排序仍是筛选或视图控制。只有一页内容时不显示标签栏。

### 各模块安排

| 一级功能 | 顶部二级标签 | 内容安排 |
| --- | --- | --- |
| 我的交易室 | 无 | 统一范围 → 收益摘要与趋势 → 当前持仓，保持同页阅读 |
| 交易库 | 按标的 / 按回合 | 将现有浏览切换移到顶部，下面保留共用筛选和列表 |
| 模式洞察 | 阶段总结 / 模式分析 | 分别承载现有总结与模式内容；规则建议保留在模式分析内的折叠区域 |
| 数据管理 | 数据接入 / 数据质量 / 收益配置 | 分组呈现现有导入与行情更新、质量与待检查问题、本金与汇率配置 |

交易室的摘要和趋势共用统计范围。当前持仓保留“截至时间”及现有筛选语义，不随业绩期间变成历史持仓。数据质量详情和本金配置在数据管理查看，交易室仅保留必要的简短提示及直达入口。

模式分类继续作为模式分析页内筛选，不新增第三层页面导航。数据管理只搬迁已有能力，不新增“历史记录”页面或操作审计系统。

### 交互

- 首次进入默认我的交易室；交易库默认按标的，模式洞察默认阶段总结，数据管理默认数据接入。
- 当前会话内切换一级模块，保留该模块上次选择的二级标签及合法筛选；交易库两种视图共用筛选。
- 复盘保留现有专注布局和返回入口，不新增一级导航。返回恢复来源页面、筛选及选中回合，沿用已有滚动恢复能力。
- 无数据时也显示页面标题和可用导航。主体用一句原因与一个适用的操作入口表达空状态；筛选无结果提供清除筛选，无交易数据提供导入入口。
- 加载和错误继续使用现有状态表达，不能呈现为无解释的空白页面。

### 视觉与窄屏

- 使用现有字体、颜色和控件；以留白、字号和细分隔线表达层级，减少卡片嵌套、阴影与重复边框。
- 页面标题、标签、筛选和内容左边缘对齐。选中态、焦点态清晰，辅助文字保持可读。
- 桌面左栏建议宽约 180–200px，主内容使用剩余空间；页面采用一个主滚动区域，避免嵌套滚动及多层吸顶。
- 窄屏通过“导航”按钮展开同一份左侧菜单；顶部二级标签允许局部横向滚动。表格可在自身容器滚动，页面整体不横向溢出。
- 导航支持键盘操作及当前项语义；盈亏继续使用符号和颜色共同表达。
- 金额与百分比沿用最多两位小数的展示约定；未知值不得替换为零。保留必要的统计口径和估值时间，详细解释按需展开。

## User Stories

1. 作为交易者，我希望从左侧稳定入口切换四个功能，并清楚看到当前位置。
2. 作为交易者，我希望模块内的切换统一位于顶部，筛选紧邻内容。
3. 作为交易者，我希望在同一页查看收益摘要、趋势和当前持仓，减少来回切换。
4. 作为交易者，我希望切换浏览方式或从复盘返回时，保留原来的范围和选择。
5. 作为交易者，我希望数据维护与配置集中放置，首页优先展示交易表现。
6. 作为交易者，我希望没有数据时能看到原因和下一步操作。
7. 作为交易者，我希望窄屏和键盘操作下仍能访问所有功能，文字与状态清晰可辨。

## Implementation Decisions

- 以现有工作区为主交互入口，共用简单的侧栏和顶部标签样式，复用已有业务组件。
- 标签切换只负责内容显隐与选中状态；不为本期建立通用导航框架、插件注册机制或新的路由体系。
- 延续现有状态管理。新增标签状态只要求当前会话内保持；刷新继续遵守原有恢复规则，不新增跨会话持久化要求。
- 搬迁内容时保留现有操作及反馈，避免同一配置或业务内容在多个页面重复渲染。
- 原始交易数据、指标计算、实盘与模拟运行隔离、汇率更新策略均沿用现有规则。
- 若现有代码已满足某项展示要求，只验收保留，不重复改造。

## Testing Decisions

以完整工作区的用户行为为主验收边界，复用现有测试，不为静态间距或样式增加独立测试体系。

1. 四个左侧入口可达，顶部标签与表中约定一致；交易室摘要、趋势和持仓仍在同一页面。
2. 切换一级、二级页面及从复盘返回后，选中态、合法筛选和目标回合正确；导航本身不触发额外导入、刷新或配置写入。
3. 交易库两种视图共用筛选；模式分类与规则建议可用；数据管理原有操作均可找到。
4. 无交易数据、筛选无结果和洞察样本不足分别显示明确状态，不出现空白主体。
5. 在 1280px 和 390px 宽度的真实浏览器中检查导航、文字、焦点、内容对齐和溢出；复盘页面不因侧栏挤压而丢失关键操作。
6. 同一范围的统计值在布局改造前后一致；沿用已有财务计算测试。执行相关测试及构建检查。

如浏览器验收需要写数据，使用隔离数据库。交付实现时提供仍在运行的预览链接及启动方式。

## Out of Scope

- 新增收益趋势算法、周度统计、日持仓历史或其他金融指标。
- 将交易室拆成概览、趋势、持仓三个二级页面。
- 新增操作历史、审计日志、独立规则建议页面。
- 改造业务表格、复盘图表、导入流程和模式识别算法。
- 新增 URL 深链接、浏览器历史管理、跨会话导航持久化。
- 全站换肤、导航自定义、底部导航或多套响应式导航方案。
