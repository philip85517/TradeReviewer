首页 V2.3 共享控件状态手册

版本身份：本手册属于当前 V2.3 设计规范；文中出现的 V2.2 仅表示继承的历史合同，不是当前版本标题或验收结论。

这份手册按控件用途整理首页的交互方式。阅读每章时，先看尺寸基准，再按“默认、悬停、聚焦、按下、禁用、加载、空、错误”的顺序了解控件在不同情境下如何出现、如何操作，以及异常时怎样回到稳定状态。

表格中的尺寸是该控件的状态样例尺寸；账户选择器的样例宽度为 180px，首页页头实际建议宽度为 176px，两者是同一控件在不同位置的布局差异，不产生新的尺寸规范。每个状态样例还应与 布局与颜色样例板 对照；样例中的文字、表头、金额和颜色 token 是可视化校准，不是新增入口。

全局对齐与内层尺寸

按钮、分段标签、日期快捷项和“应用”在命中盒内水平、垂直居中；输入文本左对齐，金额表头与数据右对齐，名称、说明和错误文案左对齐。持仓表列比例固定为 25% / 8% / 10% / 11% / 11% / 15% / 14% / 6%，表头和值由同一列定义生成锚点，数值共用右边界，查看动作在 6% 列中心的 36px 命中盒内居中。列定义同时给出最小宽度与溢出策略。全局搜索使用覆盖页头与首页内容的全屏搜索遮罩，桌面舞台最大 960px、左右至少 24px，结果区独立滚动并阻断底层操作；窄屏使用两侧 24px 内边距。交易库持仓搜索保持页面内的独立筛选输入，不打开全屏搜索遮罩。筛选浮层宽 320px，字段高 36px。详情中的“查看交易”在主动作命中盒内居中。

价格展示保留两位小数，原始精度只在详情、提示、悬停/聚焦读数或复制/导出中提供。金额按绝对值达到 1 万显示“万”、达到 1 亿显示“亿”，均保留两位小数；不增加“万亿”单位。悬停或键盘聚焦查看完整值，复制和导出均保留完整值；单价仍保留两位小数。展示缩写不改变原始数据。表格保持八行槽；“没有持仓”和“搜索无匹配”是两种不同空态，后者只保留输入框尾部 X 作为清空入口，不增加重复空态按钮。日期快捷范围使用自然本周、自然本月、自然本年，并显示提交后的实际起止日期；具体日期/区间使用日历图标，纯年份使用下拉箭头，静态日期不使用图标。历史年份选择只刷新历史模块，历史下方插图属于同一模块的局部状态示意，不是新页面。

搜索浮层（Popover）

用于实体搜索和筛选编辑；覆盖内容，不推动标题、KPI 或表格。实体搜索在触发器点击后打开覆盖页头的独立全屏搜索遮罩，桌面舞台最大 960px、左右至少 24px，窄屏保留两侧 24px 内边距，结果区独立滚动并阻断底层操作。筛选另使用 320px 浮层。交易库内部搜索保持页面内的独立筛选输入，不调用此全屏搜索遮罩。

尺寸基准：桌面舞台最大960px、左右至少24px；窄屏使用可用宽度减去两侧24px，空间不足时全宽；输入与结果共用舞台列锚点。

筛选浮层（FilterPopover）

筛选浮层是独立的 320px 浮层，不复用全局搜索遮罩的舞台或滚动容器。浮层编辑区承载标的类别、是否有未实现数据、是否待复盘等附加条件；市场和账户仍由页头控制。编辑值先进入草稿，只有“应用”成功后才改变已生效范围。

尺寸基准：外观 320px 宽；字段和按钮高 36px；浮层底部与第二行操作区保留 16px 间距。清除附加只移除附加条件，恢复全部默认还原市场、账户及附加条件，二者不能合并成同一动作。

筛选条件标签（Token）

使用边界

控件状态只描述可观察交互，不改变首页已确认的信息层级、数据口径或布局顺序。搜索与筛选的草稿在明确应用前不改变已生效范围；外点或 Esc 键关闭筛选时保留草稿，账户或市场切换时丢弃旧草稿。请求失败保留上一组完整有效值，冷启动失败不伪造零值；缺失行情、汇率或结果时使用明确原因。

文档对齐和注释层默认关闭，仅用于审查时辅助定位；状态图、分镜和说明图只用于说明状态，不作为产品界面或默认内容。

图表提示的有效点支持左右键、Home/End、Enter 固定与 Esc 键关闭；缺口不插值，不用最新值回填。数据表固定八行槽，空表不显示误导性的第 1/1 页。所有重试动作都遵循首页唯一恢复入口的约定。
