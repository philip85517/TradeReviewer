## Question

用户如何独立管理策略库、用三类命名包创建或复制完整策略，再从实验中选择策略、指定时间段并运行？先给出完整交互模型供反馈，不重新采访用户已确定的三类划分与包式配置方向。

## Scope / What to build

产出领域关系、信息架构、两条完整用户旅程、关键状态转移和低保真线框/故事板。覆盖库内先建策略、实验中就地新建、历史复制、保存/取消/失败返回、版本锁定和缺数据提示。交互模型先于视觉细化、代码原型和正式开发；本票只解决模型与设计判断。

识别需要后续落定的规则：每类包的数量和公开参数、仓位/再平衡的归属、止盈止损触发与执行区分、冲突与重新入场语义。不给出未经用户确认的交易阈值或日内成交保证。详细生产执行契约由后续正式拆票完成，不为了本票虚构已支持能力。

本轮整体模型获用户认可，补充与当前网页风格兼容，以及包说明/细节的可达入口和原处返回。覆盖包目录、组装、选择面板、完整策略详情及锁定实验配置；查看不选择、不丢草稿，历史配置不随库更新。

修订03继续纳入大量包管理：紧凑目录的搜索/筛选/排序/分页、标签备注、包级与版本级引用数、开发/发布信息、个人置顶与移动顺序、可恢复归档。具体规则见 M12/J4，四张新画板F10–F13供审阅；仍为设计文档，不提升为功能原型。

修订04纠正实验入口：库中移除“用于新实验”，补齐“我的实验”列表及四步创建，分别表达库内独立保存与实验来源新建/返回；见M13/F14–F19。

修订05按用户要求补齐两页顶部搜索/筛选/排序，统一查询控件，见M14/SL17/LD12/LT-O。卡片空间与视觉效率的[专业评估](../strategy-library-card-ui-review.md)给出测量和建议；卡片尚未重构，建议尺寸不视为已批准。

修订06统一全局元素与用户文案：面包屑、同类输入/按钮、边框和字体颜色遵循[UI06-01–05契约](../strategy-library-wireframes/STYLE-06-CONTRACT.md)，设计说明移出产品区域，保留必要数据/版本/执行限制。对应M15/SL18/LD13/LT-P；不扩展为卡片重构或正式开发。

## 验收标准与反例

- [ ] 无实验→进入策略库→浏览/建立完整策略→再创建实验，模型清楚区分模块包、完整策略、Portfolio、实验、运行；反例：建策略就生成实验结果。证据：模型图与独立 resolution。
- [ ] 实验已填区间/本金/已选策略→就地新建→成功返回并选中；取消、保存失败分别画出返回位置和保留字段。反例：日期或已有选择丢失。证据：状态表与 LT-C 走查。
- [ ] 三类命名包均可见，示例覆盖形态/财务筛选、形态/规则买入、固定/移动退出；明确技术形态和退出的脚本扩展。反例：要求逐个配置原子条件。证据：低保真组装图。
- [ ] 历史策略→复制→在复制草稿中替换一个包→保存新策略；来源和旧实验保持不变，复制策略与派生实验两条路径分清。反例：复制带入旧持仓或改写历史。证据：身份/版本状态表。
- [ ] 空库、缺包、不兼容、历史数据不足、无候选、无买入信号、未保存修改和保存失败均有可观察状态与下一步。反例：所有异常统一标成“无结果”。证据：LT-A–LT-H 覆盖映射。
- [ ] 保留四步骨架、五档期限、独立本金、历史可知截止、原运行不改写及窄屏暂缓；明确新授权变化仅是策略库与包组装等第一轮反馈范围。证据：与旧契约的差异清单。
- [ ] 用户对实际模型的选定/修改理由记录到独立 resolution，并把批准区域、状态和下一步设计输入写入覆盖表。反例：仅引用这轮“固化任务”的指示就关闭交互模型票。
- [ ] 包详情涵盖三类包的说明、版本、规则、有效参数和数据/适用范围；入口与逐层返回明确，查看不改变选择和草稿。反例：详情只能回库首页、误换包或误显示最新版本。模型证据：[M11 与 F09](../strategy-library-interaction-model.md)；新增画板用户反馈待记录。
- [ ] 明确复用当前 TradeReview 框架与控件风格，详情长内容和常驻返回在两档桌面可读；最终视觉与真实交互验收仍交任务10。证据：[修订审阅记录](../strategy-library-model-review.md)。
- [ ] 大量包的搜索/筛选/排序/标签备注/分页和返回有一致模型，统计区分当前不同策略数、所看包版本子集和历史引用；开发、发布、导入不混用，未知不作0。反例：多个历史版本重复算成多个当前策略，置顶越过筛选。证据：M12、F10/F12、LT-K。
- [ ] 置顶与移动明确个人偏好、两组顺序、跨页定位、保存/取消/失败及返回查询；归档/恢复说明全部版本与原引用关系，覆盖活动草稿、已有策略新实验和复制。反例：整理改变执行顺序，归档删除历史，恢复丢身份。证据：M12/J4、F11/F13、LT-L/M。

- [ ] 库中无实验CTA，业务tab进入真实“我的实验”列表；列表→新建→设置起点→主动选择策略→预览→确认，并区分纯库和实验来源的策略保存/取消。反例：只靠画板导航切页、普通选择页默认出现刚创建提示、样例之间丢失所选策略。证据：M13/F14–F19、LT-N。

- [ ] 全部19板在两档桌面统一导航、控件、线框和文字层级，产品无设计编号/调试说明，数据限制与历史语义保留；独立直接读图，不能用DOM尺寸替代视觉。证据：UI06-01–05、M15、LT-P。
