## 2. 结论与阻断项

HP01–HP04 的结构重排和大部分公共控件已有可实现形态，但当前稿不应作为“所有原始评论均完成响应”的冻结稿。共发现 **4 个阻断级设计缺口（P1）**、**3 个一般缺口（P2）**，另有 **1 个 D01 待决方案完善建议**：

1. **F01 / P1：曲线点位详情缺少非期末日样例，截止日字段语义含糊。** HP02 要求任意日期点显示该日市值、该日浮盈、截至该日累计已实现和累计净盈亏（`visual-design.md:33`）；HP04 使用“期末浮盈”（`:110`），`chart-hover.svg:1` 画期初/期末浮盈、期间已实现、浮盈变动、期间净盈亏，且唯一示例恰好是期间最后一天 10-15。对 10-15 而言，“期末浮盈”可以同时就是该日浮盈，因此这不是数学矛盾；问题在于图稿没有说明点选非期末日时，“期末”是所选点当日截止值还是整个已应用期间终点，也没有非期末日期例子证明累计值会截至所选日。影响：实现者可能把全期间终值复用到任意历史点。建议：把 tooltip 标签明确为“截至该日浮盈/累计已实现/累计净盈亏”，增加一个非期末点（例如 05-01）的完整数字算例并核对公式。置信度：高。
2. **F02 / P1：缺口声称可点击看原因，但没有原因结果状态。** `visual-design.md:110,118,132` 明确“缺口可点击查看原因/显示原因入口”；`chart-gap.svg:1` 只有不可识别为控件的文字“行情缺失 · 不插值”，没有按钮、focus、点击后浮层、缺行情与缺汇率区分或恢复动作。影响 C16.4、C18.3，无法实现或验收键鼠路径。建议：补“默认缺口→hover/focus→原因浮层→关闭/恢复”连续帧。置信度：高。
3. **F03 / P1：日期提交分镜没有成功与失败终态。** `visual-design.md:124` 承诺成功替换完整上区，失败保留旧范围并提供原因和异步重试；`:138–142` 仅列草稿、字段校验失败、更新中。没有新范围成功后的 KPI/曲线/贡献一致状态，也没有请求失败后的范围、原因入口、重试中/重试结果。影响 C08.3、C16.6/.7、C20.1/.2、C21.3。建议补两条闭环：应用→更新→成功；应用→更新→失败→异步重试→成功/再次失败。置信度：高。
4. **F04 / P1：日期弹层文字要求快捷范围，图中完全没有。** `visual-design.md:124` 写“输入起止日期与快捷范围”；`date-draft.svg:1`、`date-invalid.svg:1` 只有两个日期字段、应用、取消，无“今年/近1月/近1周”。影响 HP02 与 HP04 对同一控件的合同一致性，也使实现者不知道快捷项是在页外 tabs 还是弹层内重复。建议明确二选一并让文字/图统一；若弹层必须有快捷项，补选中、切换与应用状态。置信度：高。
5. **F05 / D01 待决方案完善建议：候选 A/B 尚未放进真实图点详情上下文。** `visual-design.md:126,133` 提议若保留，唯一位置为图点详情内“查看该日敞口”；`snapshot-options.svg:1` 已提供 A/B 候选，而 `chart-hover.svg:1` 没有该入口。由于 D01 未获用户批准，这不是“必须实现”的缺陷，也不应作为放行阻断；为了让用户决定时能比较密度与发现性，建议在同尺寸 chart tooltip 中展示 A/B 上下文，继续标为待决定。置信度：高。
6. **F06 / P2：搜索规范要求清除按钮，打开与选中图均未见。** `visual-design.md:63` 明确“搜索输入、清除按钮”；`search-open.svg:1`、`search-selected.svg:1` 没有可见清除控件或清除后状态。影响 C11.5/C12。建议画出有输入时的清除按钮、命中区、键盘行为及清除后的候选恢复。置信度：高。
7. **F07 / P2：C08 的旧请求覆盖规则不够明确。** `visual-design.md:79` 说失败回上一组完整范围、成功原子替换，但未规定快速连续切换市场/账户/期间时如何识别过期响应。影响 C08.4。建议固定 request/version 规则，并在“先选 A 后选美股、A 后返回”的分镜中明确丢弃旧响应。置信度：中高。
8. **F08 / P2：C07 的“图表粒度与统计期间区别”只被隐含处理。** 图标题固定“按日”（`:108`），期间 tabs 在 HP02，但没有明确写 V2 删除独立粒度控件的取舍。影响实现者可能把“近1周”误作曲线粒度。建议写明“曲线粒度固定按日；期间是统计边界；无独立日/周/月粒度控件”。置信度：中。
