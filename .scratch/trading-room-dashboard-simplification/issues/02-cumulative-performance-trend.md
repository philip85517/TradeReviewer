# 02 — 累计收益趋势图

**What to build:** 在核心收益摘要下提供一张与摘要完全同口径的累计净盈亏趋势图，让用户能按自然月、自然周或本月日级变化理解期间收益和累计变化。

**Blocked by:** 01 — 核心统计范围与收益摘要

**Status:** ready-for-agent

- [ ] 趋势图使用与核心摘要相同的范围、期间、模拟运行、分类和货币口径。
- [ ] 近 3 个自然月和今年至今默认按自然月分桶；本月提供适合近期变化的日级展示，并可在适用范围切换月 / 周分桶。
- [ ] 图表提供横轴日期标签、纵轴金额刻度、零基线、期间收益和累计收益点值。
- [ ] 聚焦或查看数据点时展示覆盖日期、期间净盈亏、累计净盈亏、胜负样本和分母。
- [ ] 对空样本、数据不足和混合货币不可合计保持明确状态，不绘制误导性的聚合线。
- [ ] 模型测试验证图表累计终点与摘要总收益一致，组件测试验证坐标、分桶、点值和可访问数据描述。
