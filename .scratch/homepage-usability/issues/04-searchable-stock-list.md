# 04 — 提供适合大量股票的查找与筛选列表

**What to build:** 用户在复盘股票列表中直接搜索、筛选并选择交易对象，无须滚动大量卡片或转去图表工具栏寻找搜索。

**Blocked by:** None — can start immediately

**Status:** done

**Priority:** P2

- [x] 列表顶部常驻名称和代码搜索，支持清除搜索；同一股票跨导入批次仍仅出现一次。
- [x] 使用紧凑列表行，保留股票身份、选中状态和必要状态提示；长名称不挤掉代码或选择操作。
- [x] 默认按最近成交时间降序排列；时间相同使用稳定排序，避免刷新后列表跳动。
- [x] 提供“待复盘”筛选：至少有一个未完成复盘的回合即纳入；没有复盘记录的回合视为待复盘。
- [x] 复盘完成状态变更后筛选结果同步更新，当前正在复盘的上下文不会被静默替换。
- [x] 无搜索或筛选结果时展示明确提示及清除条件入口。
- [x] 使用至少 81 只股票验证搜索、筛选和选择链路；浏览与筛选不触发行情下载。

**Verification:** 见 [验收记录](../verification.md)。
