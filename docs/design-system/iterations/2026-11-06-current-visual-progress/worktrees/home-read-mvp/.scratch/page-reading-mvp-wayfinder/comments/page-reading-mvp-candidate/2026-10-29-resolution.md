# 优先实验哪些计算和读取方式：候选筛选

这是实验选择，不是最终架构或产品承诺。依据是[独立审查](../../../../docs/backend-design/page-reading-architecture-review-2026-10-29.md)、[来源协议分析](../../../home-trades-recovery-diagnosis-2026-10-28/PROTOCOL-REVIEW.md)、[当前来源组装代码](../../../../app/lib/storage/homepage-source-snapshot.ts)及两页视觉合同。原诊断的一次 34.33 MB 数据不构成新实验基线。

## 推荐先测什么

先用一次性原型比较：**在数据变化时准备可复用的轻量结果，读取时只返回符合完整筛选与排序条件的摘要和当前页**。用同一批合成成交，比较每次请求重新全量处理与准备后读取；记录首次准备、变更后的准备、重启后读取、传输量和一致性。它可以验证减少重复工作是否值得继续，不能据此决定具体业务字段和发布架构，更不能证明两页的完整首屏已达标。

|选择|可能收益|主要成本与反例|实验取舍|
|---|---|---|---|
|现有方式：每次读取、整理和校验完整来源|不额外维护结果；保留原有依据|历史样本重复传送材料，且服务和浏览器都要处理大包；全量路径可能持续增大|作为真实系统的现状参考；合成实验里的朴素全量路径只是受控对照，并非原服务替身|
|只做轻量接口，每次仍完整计算|传输量下降；详情可按需获取|全量计算和校验依旧可能慢；分页前必须对全部匹配结果统计排序|可作为额外对照；小响应不等于快|
|变更时预先准备、读取时分页|多次打开复用计算；有望减少首屏传输和重复整理|增加准备耗时、存储与版本管理；更新失败、历史补录、多来源变化可能使结果过期|首选实验，先测可复用性和反例，不接入正式写入|
|混合：稳定结果预先准备、易变部分按需计算|适应成交、行情、汇率不同变化频率，避免全量重建|依赖版本组合、发布一致性、失败恢复和待定业务合同|作为后续设计候选；不预设所有指标都能增量计算|

可证伪假设：在相同数据集和正确结果下，准备后再次读取比每次全量整理耗时更少、返回更小；一次准备和变化后的重新准备有可记录的成本；重启后不会丢失结果；切换账户与跨页不漏不重，版本变化不会把旧摘要和新列表冒充同一版。若这些条件不成立，不能用该原型支持预先准备路线。资源占用与写入等待也应报告，不能只展示快的读取时间。

## 页面不能被实验简化掉

- 首页：[视觉规范](../../../../docs/design-system/baselines/2026-10-22-homepage-v2.5/source/visual-design.candidate.md)要求期间指标与曲线、最新持仓、历史统计、贡献区以及搜索筛选；持仓固定每页八行。市场和账户作用于整页，期间作用于期间统计，持仓搜索作用于表格。筛选、排序、计数基于完整适用范围，不能只算当前八行。
- 交易库：[视觉规范](../../../../docs/design-system/baselines/2026-10-22-trading-library-v1.0/source/visual-design.candidate.md)要求实盘与模拟视角、列表和统计、搜索筛选、分页及详情回合。实盘列表按成交日期，已平仓统计按回合平仓日期；模拟练习按练习保存日期。详情、复盘、导出与返回上下文仍须保留。
- 两页都需要明确范围、版本、正常、空、未知、失败和缺失原因；未知金额不能填零，详情必须能追溯原始事实。页面读取合同和数据资格尚在[原设计地图](../../../page-reading-architecture-wayfinder/issues/00-map.md)中待定，实验不得替其做决定。

## 范围与边界

可独立试验：人工合成的交易数量、账户/标的筛选、稳定排序、分页、版本隔离，以及变更后对合成结果的重新准备。实验不得改正式业务数据库或正式产品，也不得以合成变更代替真实导入/修订验收。财务 P1/F07、Bars 和重复导入继续暂停；真实财务口径、行情、汇率、这些写入路径以及两页完整浏览器一秒门槛均未验证。真实规模对照和页面基线另由[基线任务](../../issues/02-baseline.md)收口。
