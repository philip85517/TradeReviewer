# 04 盈亏趋势与三级日历报告

状态：04 模型、趋势/日历组件和 dashboard 装配已完成，协调者复验中的浏览器回归已收口。父组件显式授予本票 dashboard/CSS/test 装配权，因此同时移除了旧的独立日历主路径，并将页面顺序固定为统一范围/摘要 → 业绩趋势与日历 → 当前持仓 → 收益质量。

## 交付内容

- `buildTradingRoomCalendar(entries, options)` 统一消费 `RoomScope`、metadata 和同一 `RoomFxSnapshot`，按回合最后平仓交易日归属。模型输出摘要、日历格、累计趋势、原币累计和指定格详情；累计末值与同范围摘要共用同一 money view。
- 月层级在本月显示每日格，并延伸到自然月末；今天之后的格子标记 `future`、不生成 0、不允许下钻。自定义跨月范围按实际起止日截断两端并按月汇总；单月范围按日显示。年层级始终输出 12 个月，全部年份从历史回合年份生成，不先套当前月份窗口。
- 月汇总格使用自然月标签（例如 `2026年8月`）；两端截断的月份追加 `覆盖08-15至08-31`。累计趋势只保留 `startDate <= asOf` 的桶，且以零累计点作为区间基线，不把未来桶累计值重复画到今天之后。
- 近 3 个自然月切换日历时保留父级期间并显示 3 个自然月摘要；点击月份才把父 scope 改成该月。年/全部年份下钻、月翻页和顶部期间/分类/性质/运行变化均同步父 scope；顶部 scope 变化通过专用 reset token 清掉旧详情并恢复趋势，日历翻页不会重挂载组件或丢失当前视图。
- 趋势使用包含零的共享坐标域并绘制动态零基线。FX 完整时多币种绘制一条人民币合计线；FX 缺失时按原币分别绘制，共享坐标尺度并显示图例和不可合计提示。没有伪造 0，日详情保留来源交易日、账户、金额/不可用原因和精确复盘回调。
- 统一摘要保留人民币主金额与原币小计及汇率来源/时点；纯 CNY 不重复显示。没有可信已平仓样本时显示“暂无已平仓样本”，不把空金额归因于 FX。范围排除统计只计已平仓不可信样本，未平仓与未知资产另列，避免和持仓口径混淆。
- dashboard 接入 `buildTradingRoomMetrics(roomModel.rows, { period: roomScope.period, fxSnapshot })`，摘要新增合计胜率和交易成本收益率；`RoomQuality` 折叠详情放在持仓之后。旧 `buildDashboardCalendar`、旧日历状态和独立下钻路径已删除。日历下钻同步父级自定义日期草稿，避免有效期间与输入值分叉；实盘/模拟使用独立固定身份 badge。

## 04 接口

`RoomPerformance` props：

```ts
type RoomPerformanceProps = {
  entries: readonly TradeLibraryEntry[];
  scope: RoomScope;
  onScopeChange: (patch: Partial<RoomScope>) => void;
  instrumentMetadata?: TradingRoomMetadataInput;
  fxSnapshot?: RoomFxSnapshot;
  asOf?: string;
  onOpenInReview: (instrumentId: string, episodeId: string, queueIds?: string[]) => void;
  renderMoney?: (money: RoomMoneyView) => ReactNode;
};
```

组件不发起网络请求，不依赖外部 chart 库；dashboard 传入与范围摘要相同的 `entries/scope/instrumentMetadata/fxSnapshot`，以及同一个复盘回调。导航层后续只需继续传父 scope 变化，不需要维护第二套日历状态。
