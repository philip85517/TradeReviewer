# TradeReview 交易复盘

记录交易复盘中已确认的领域术语，用于保持业绩表达一致。

## Language

**已平仓回合净盈亏**：
完整交易回合结束后、扣除费用的盈亏；首页统计仅纳入可可信计算的已平仓回合，不包含尚未结束回合的结果。
_Avoid_：账户整体收益、账户净值变化、未注明口径的收益

**持仓浮盈亏**：
尚未平仓持仓基于特定时点估值与成本形成的未实现盈亏，与已平仓回合净盈亏分别展示。
_Avoid_：已实现盈亏、已平仓收益

**模拟账户**：
组织模拟成交、持仓、盈亏及现金口径的账户，与实盘账户隔离。按2026-09-28用户明确指示，当前四份TradingView导入归属同一个TradingView模拟账户，不按四次运行分别统计或处理。
_Avoid_：每个导入文件自动建立一个模拟账户、将导入批次等同于账户

**模拟导入来源**：
记录模拟成交来自哪个文件、批次及原始报告，供追溯和重导去重；它不是本次TradingView模拟账户的统计隔离边界。
_Avoid_：模拟运行（用作当前四份TradingView数据的账户边界）

**人民币估算盈亏**：
将原币盈亏按最新可用汇率折算的人民币金额，随汇率更新而变化，原币盈亏保持不变。
_Avoid_：历史汇率盈亏、实际换汇所得

**交易成本收益率**：
符合计算条件的已平仓回合净盈亏合计与同一批回合买入成本合计的比值，累计成本包含资金反复交易形成的投入。
_Avoid_：账户收益率、累计百分比收益、资金净值回报

**本金参考收益率**：
选定统计范围和期间的可信已平仓回合净盈亏与该范围手填本金的比值，不包含完整账户资产与资金流的回报计算。
_Avoid_：账户整体收益率、跑赢大盘证明

**本金分类**：
独立填写本金的互斥分类，分为A股股票、美股股票、港股股票与全市场ETF；前三类均不包含ETF，证券的市场身份不因本金分类改变。
_Avoid_：包含ETF的市场总本金与ETF本金重复汇总

**现金基准**：
用户针对某个账户及原币确认的截至特定时点的现金余额，此后股票及ETF成交现金变化在其基础上按含费买入支出扣减、扣费卖出回款增加。它不表示券商的可交易或可提取额度。
_Avoid_：可用资金、可提现金额、自动核对的完整账户现金余额

**今日卖出回款**：
今天股票及ETF卖出成交扣除交易费用后的现金回款合计，包含部分卖出，按成交日期归属。它包含卖出本金回收，不等同交易盈亏或已交收可提现现金。
_Avoid_：已平仓回合净盈亏、今日净现金流、今日已交收现金

**当日盈亏**：
同一统计范围当天交易及持仓估值产生的损益，包含当天已卖出部分的当天损益；买卖本金不计为盈亏，当天交易费用只扣一次。它不等同于当天平仓回合自开仓以来的全部利润。
_Avoid_：未实现盈亏日差、今日卖出回款、当日平仓回合累计净盈亏

**当日盈亏率**：
当日净盈亏与前一应有交易日持仓市值加当日买入支出（含费）之和的比率，买入支出逐笔累计、卖出回款不抵减分母。它表示本项目的当日交易投入口径，含空头或分母不可用/非正时不提供该比率。
_Avoid_：账户收益率、时间加权收益率、本金回报率、未实现盈亏率

**持仓总敞口**：
同一账户范围、估值时点和计价口径下，各持仓市值绝对值之和，多头与空头不先相抵，不包含现金。它是本项目含空头分布占比的分母，与带符号相加的持仓净市值不同。
_Avoid_：账户净资产、持仓净市值、可用资金

**参考现金**：按账户和原币，以带时点的现金基准加后续股票/ETF成交现金变化计算的参考金额。用户于2026-09-28选择本口径，不包含基准之后其他非成交资金活动，不承诺与券商完整余额一致；缺基准或关键证据时保留覆盖状态。
_Avoid_：可用资金、可提现额、已核实的完整券商现金
