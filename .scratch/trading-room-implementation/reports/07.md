## 接线约定

```tsx
const principalSettings = usePrincipalSettings({ scope: roomScope });
const principalSummary = buildPrincipalReferenceSummary(
  roomModel.rows,
  roomScope,
  principalSettings.state,
  fxSnapshot,
);

<RoomPrincipal
  key={principalScopeKey(roomScope)}
  scopeKey={principalScopeKey(roomScope)}
  config={principalSettings.config}
  summary={principalSummary}
  loading={principalSettings.loading}
  saving={principalSettings.saving}
  error={principalSettings.error}
  onSave={principalSettings.save}
  onClear={principalSettings.clear}
/>
```

`RoomPrincipal` 自身维护按 `scopeKey` 分开的脏草稿；空草稿会随异步 config 重载显示已保存值，scope 切换不会带入另一运行的编辑内容。dashboard 页面装配仍由 scope 所有者完成，本票未修改 dashboard。
