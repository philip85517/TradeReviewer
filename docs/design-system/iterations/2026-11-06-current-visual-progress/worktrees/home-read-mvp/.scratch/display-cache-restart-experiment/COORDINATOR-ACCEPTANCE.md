# 协调者验收：名称变化与重启复用原型

日期：2026-10-29  
结论：**PASS，仅限两条合成成交的离线原型。**

证券名称、不同语言名称、逐笔账户标签单独变化时，成交版本和事实摘要不变，但展示内容摘要变化。原型会拒绝旧结果；刷新后能返回新名称。无变化时，独立子进程重启后复用结果，同一连接的变更计数差值为零。双连接事务和无事务负例验证了实验范围内的新旧快照一致性；独立审查另外验证了刷新中断后的回滚。

协调者独立重跑固定 Node 的 16 项测试，全部通过；44 项冻结文件摘要核验通过。独立验收结论和具体证据见 [独立审查](INDEPENDENT-REVIEW-01.md)，实验原始测试、重启及并发证据见 [结果记录](RESULTS.md)。本任务只读参考产品代码，测试使用新建的合成隔离数据库；没有修改正式业务数据库或产品代码。

当前产品启动会重新读取来源，且完整来源内容已有摘要，因此本实验不能证明现有产品出现跨重启旧名称问题。该原型每次仍扫描源数据并计算摘要，不证明性能达到一秒；其运行时代码身份也不是完整依赖闭包。真实产品的版本、更新事务及缓存接线，以及首页和交易库完整首屏，仍需单独验证。财务 P1/F07、Bars 与重复导入继续暂停。
