# 04 — 视觉层级与浏览器验收

**What to build:** 完成交易室首页的视觉收敛和真实浏览器验收，让核心收益、趋势和持仓形成紧凑且可读的主路径，并确认窄屏下没有横向溢出或低对比度内容。

**Blocked by:** 01 — 核心统计范围与收益摘要；02 — 累计收益趋势图；03 — 当前持仓与数据管理职责重组

**Status:** ready-for-agent

- [ ] 核心收益与期间控制在首屏建立清晰的视觉优先级，辅助说明压缩为短文案或详情入口。
- [ ] 主要数字、操作和状态在现有浅色与深色表面上保持可读对比度，交易性质颜色与盈亏正负颜色不混淆。
- [ ] 桌面端浏览器验收确认收益卡片、趋势图、持仓和数据管理入口的完整路径可用。
- [ ] 390px 窄屏验收确认期间 Tab、图表坐标、数据点详情和持仓区域可访问，页面无横向溢出。
- [ ] 涉及写入的浏览器流程使用隔离数据库和独立端口，并验证源数据库记录数量、完整性和交易数据未被修改。
