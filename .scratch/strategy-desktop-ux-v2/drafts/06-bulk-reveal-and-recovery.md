## Scope / What to build

从多组合工作台明确选择展开剩余行情，看到实际逐日进度，可取消或停在完整日；成功进入已有结果页。用合成场景触发数据/执行失败，重试或明确排除失败组合继续，失败组合和其他组合的截止/显示始终准确。

范围外：不接入真实服务/保存后端。保存失败仅设计诚实的模拟提示和恢复展示，不能把其作为真实持久化通过。本票不做多组合结果比较矩阵。

## 输入/输出与最小整理

依赖第 03 票组合身份/会话投影与第 05 票真实可达结果入口；公开可取消展开动作，扩展每组合 Mᵢ 和结构化错误状态。所有数据和失败均为可复现合成场景。

## 验收标准与反例

- [ ] AC01：动作前解释展开全部剩余行情；确认/取消均可用，取消不改变 V/M/任何账本或曝光记录；确认后逐日进度反映真实已完成工作，不能演出虚假进度。
- [ ] AC02：停止展开、离开工作台或故障都停在最后完整日；进度/持仓/成交原子一致，重试不重复成交，只有成功揭示的日期被记录为已看。
- [ ] AC03：同一输入用逐日、播放、快速展开结果一致；完整结束后进入第 05 票结果页，来源和截止可见；取消后可恢复逐日操作。
- [ ] AC04：数据中断/执行失败显示受影响组合、失败日、原因和最后完整日，提供查看原因/重试/返回；不能把部分计算展示为完整日。
- [ ] AC05：明确排除失败组合后其 Mᵢ 保持原日，其余组合可继续；V>Mᵢ 时该组摘要/持仓显示此日不可用，曲线截断并可显式跳最后完整日，不向前填充旧估值。
- [ ] AC06：正常调仓、部分/未成交等场景可在演示工具中复现并正确区分计划/实际；记录原因、费用和原型限制，不冒充真实撮合证据。部分成交属于已完成交易日内的执行结果，必须有一致的成交、持仓与现金；不能与计算中断产生的未提交半日状态混淆。
- [ ] AC07：以确定性演示展示保存失败提示→保留本地内容及最近模拟检查点→显式重试/重载恢复；这是演示工具内的内存检查点，浏览器刷新仍清空。重载不能回退或清除已经看过的最远日期与来源，不能伪装重新盲看。全程标“演示”，无真实数据库写入、无真实保存成功声明，不替代正式产品保存验收。派生新实验另由第04票交付，不作为本票隐藏依赖。
- [ ] AC08：两档桌面比较确认层、展开中、取消、失败、恢复与落后组合状态；错误不遮住主时间控制，键盘可取消/关闭且不意外续播。

核心反例：先把M写到终点再开始工作；停止后残留半日持仓；失败组合旧值延长到新日；重复重试再次买入；展开完无结果出口。

## 视觉与状态约束

- 1440×900、1280×800 CSS 视口，100%缩放；历史基线DPR1，新验收记录实际DPR。保留TradeReview侧栏/背景/蓝色主动作、6–8px圆角；本票元素遵守DD02尺寸、DD13字体和状态色。
- 先装配一屏代表性状态并独立看图，之后扩展其余状态。每票都完成自己的视觉/键盘检查，第08票只验集成，不补做前票门槛。
- 时间遵守DD06，运行V/M/各组Mᵢ、结果R及曝光来源由同一会话边界协调；字段不适用时按本票范围说明，不删除后续契约。
- 原型使用合成数据，返回重开只保留内存；无真实API/schema/数据库写入。窄屏暂不修改，不新增窄屏专项门槛。
