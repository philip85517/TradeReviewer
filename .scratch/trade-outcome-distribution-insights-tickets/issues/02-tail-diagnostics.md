# 02 — 尾部结构诊断与证据跳转

**Parent:** `trade-outcome-distribution-insights` 父规格

**What to build:** 用户可以看到收益是由少数大亏/大赚拉动，还是由较广泛的亏损/小赚组成，并能检查每条诊断使用的证据交易和反例交易。

**Blocked by:** 01 — 收益结构基础：分布、胜率与赔率

**Status:** completed

- [ ] 计算亏损广度、盈利广度、亏损尾部集中度和盈利尾部集中度，并显示样本数与计算口径
- [ ] 在满足最低样本门槛时生成“少数大亏拉动”“亏损较普遍”“少数大赚拉动”“多笔小赚”等中性诊断
- [ ] 样本不足时只显示描述统计和“样本不足”，不生成正式诊断
- [ ] 每条诊断包含支持证据、反例、时间范围、阈值和计算版本
- [ ] 支持点击证据/反例回到现有交易回合，且不修改原始交易
- [ ] 补充诊断规则的边界测试、极端值测试和组件行为测试
