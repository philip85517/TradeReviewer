# 04 — 分市场表现拆解

**Parent:** `trade-outcome-distribution-insights` 父规格

**What to build:** 用户可以按美股、港股、沪市、深市和未知市场切换收益结构，比较各市场的分布、胜率、赔率和样本完整性，同时保持实盘/模拟盘与模拟运行隔离。

**Blocked by:** 01 — 收益结构基础：分布、胜率与赔率

**Status:** completed

- [ ] 按现有标准化市场字段生成总体、市场组和未知市场组
- [ ] 每个市场组复用总体的收益分布、五类结果桶、胜率/赔率和极值口径
- [ ] 市场样本少于 3 个时只显示描述统计，不参与正式诊断或排名
- [ ] 保持交易性质、模拟运行和现有范围筛选隔离，不跨运行合并结果
- [ ] 跨币种时收益率和比例指标继续可用；金额遵循现有原币/FX 可用性规则
- [ ] 显示市场样本数、排除数量和数据完整性说明，并支持打开市场组交易回合
- [ ] 补充多市场、未知市场、小样本、模拟运行隔离和跨币种测试
