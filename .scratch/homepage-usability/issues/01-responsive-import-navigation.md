# 01 — 恢复窄屏下的导入与股票切换入口

**What to build:** 在窄屏下，用户仍能找到导入交易记录、从截图恢复交易和股票切换入口；股票列表以可打开、可关闭的抽屉呈现，选择股票后可顺畅继续复盘。

**Blocked by:** None — can start immediately

**Status:** done

**Priority:** P1

- [x] 在 1024px 和 390px 宽度下，全局导入入口均可见且可用，空首页不再提示用户操作不可见的左侧栏。
- [x] 文件导入和截图恢复均接入现有解析、复核、确认流程；取消或确认前不新增成交。
- [x] 用户可打开股票抽屉、选择股票并返回该股票的复盘区；选中状态明确。
- [x] 抽屉支持键盘打开、Escape 关闭、关闭后焦点返回触发按钮，打开时焦点不会落入被遮挡内容。
- [x] 桌面与窄屏之间切换不丢失当前股票、交易回合、回放位置或未提交的导入草稿。
- [x] 回归验证空数据和有数据两种状态，覆盖窄屏导入与股票切换路径。

**Verification:** 见 [验收记录](../verification.md)。
