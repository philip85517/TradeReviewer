## Implemented

- Replaced the single draft slot with an in-memory collection of experiment sessions, stable per-session IDs, names, configuration, creation/run state, resume stage, progress, source exposure, and a per-instance result-open request counter. The list identifies each experiment's T0, package count, capital, horizon, state, M/V dates, and source when present. Refresh reset remains explicit.
- Each started `RunningPrototype` remains mounted under a stable experiment key and is hidden through its `visible` prop when another stage or experiment is open. Runtime callbacks are created once per run and retained in state; same-value status/progress updates preserve the existing array. `RuntimeProgress.completed` is compared independently of status so a completed run remains completed when V is reviewing an earlier date.
- The list opens a completed run through the explicit `openResultsRequest` signal, which 03 consumes to open or reuse the actual result view. The action stays “查看回测结果” only when `completed` is true; M and V remain visible in the list. Non-completed runs reopen the actual workbench.
- “基于此配置新建实验” receives runtime progress and creates a separate editable draft by copying package settings only. It does not copy the source ledger, candidates, fills, runtime cursors, or partial-coverage confirmation. Its T0 remains the copied configuration's own start date, and the original run stays mounted. Source exposure keeps the latest date across inherited source boundaries, runtime exposure, M/V, and T0; the interface describes this as the source-chain known-data boundary and states that source trades/holdings do not carry into the new run.
- The derived draft can be cancelled from its header, with Escape, or directly from the list. Cancellation removes only the unrun derived draft and reopens the source experiment. Confirming and entering a derived experiment creates its own runtime at T0; returning to the list can reopen either instance independently.
- Desktop list rows group the open action, source information, and a separate cancel control. Added source-boundary presentation and focus-visible styling while preserving the approved TradeReview shell and existing narrow-screen rules.
