# 02 数据管理与主导航交付报告

## 交付范围

- 将顶栏导航整理为「我的交易室 / 交易库 / 模式洞察 / 数据管理」；生产模式默认进入我的交易室，演示模式继续保留既有演示复盘入口。
- 新增 `DataManagement` 页面并保持原有真实导入、取消、行情刷新、失败重试、未完成恢复、保留记录检查和导入历史回调。
- 将 `ImportActions` 与 `GlobalMarketRefresh` 从顶栏移到数据管理页面；顶栏保留状态与导航入口。
- 通过 `instrumentMetadata` 将 `storedInstruments` 中按原始 `instrument.id` 保存的 `market`、`symbol`、`assetType` 传给交易室范围模型。
- 预留 `fxSlot?: ReactNode`，页面只渲染后续模块提供的真实内容，不制造汇率状态；界面文案为「人民币估算使用的最新汇率」。
- 交易室与数据管理 DOM 均保持挂载，切换页面只改变显示状态；新增窄屏数据管理布局，并保留无数据状态。

## 保留的真实路径

- 文件导入仍调用 workspace 原有 `startStatementBatch`，TradingView 仍走 `parseImport`，截图仍走 `startScreenshotImport`；输入取消与导入确认对话框路径未替换。
- 全局行情更新仍使用 `startMarketDataUpdate(undefined, { refreshMetadata: true, batch: true })`；取消、失败重试和未完成恢复分别接回 `cancelMarketDataUpdate`、失败标的集合和 `recoverUnfinishedMarketData`。
- 保留标的检查继续调用 `openDataCheck`；行情详情中的修复、补充导入与刷新回调仍由 workspace 维护。导入历史按钮继续打开 `ImportHistoryDialog`。

## 接口与限制

- `TradeReviewWorkspace` 和 `DataManagement` 接受 `fxSlot?: ReactNode`；当前不提供假汇率数据。
- `ReviewDashboard` 接收 `instrumentMetadata`，workspace 只从已有 `storedInstruments.metadata` 投影出必要字段；缺失 metadata 会由 scope 模型保留为未知资产。
- 未提交、未启动服务、未触碰正式数据库；浏览器导航/数据管理入口由协调者在真实浏览器复核。
