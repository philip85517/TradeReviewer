# 正式版移除演示股票与浏览器导入数据边界设计

日期：2026-08-02

## 目标

正式发布版本不再向用户展示内置的小鹏汽车（XPEV）演示股票；开发和测试仍保留演示数据，保证现有回放与测试夹具不受影响。同时明确截图所示 35 只股票的来源：它们是 `127.0.0.1:4317` 这个浏览器 origin 下的本地导入数据，不属于部署目录的 SQLite 文件。

## 设计

演示数据继续由现有服务端 demo replay provider 提供，但股票复盘侧栏不再把 demo 作为正式交易库条目渲染。正式版侧栏只渲染 `importedInstruments`，股票数量徽标也只统计导入股票。没有导入数据时显示空状态和导入入口，而不是显示 XPEV。

开发/测试专用的 demo replay、demo API 和相关单元测试保持不变；只有面向用户的股票列表入口移除 demo 卡片，避免把测试数据误认为真实导入数据。

## 数据边界

导入成交和导入历史继续通过浏览器 `localStorage` 保存，行情、复盘和建议数据继续使用现有浏览器存储。`make deploy` 只发布应用 release，不迁移、清理或上传这些数据。截图中的 35 只股票应在导入它们的同一浏览器、同一协议/主机/端口下读取；更换浏览器 profile 或 origin 后不会自动出现。

## 验证策略

- 组件测试验证无导入数据时不渲染 XPEV，且导入数据仍正常渲染并准确显示股票数量。
- 现有 demo replay、导入持久化和回放测试保持通过。
- 构建、类型检查、Lint 和渲染回归通过。
- 通过当前部署地址的 UI 复核：导入记录来自浏览器本地存储，部署目录 SQLite 不作为导入交易的读取源。
