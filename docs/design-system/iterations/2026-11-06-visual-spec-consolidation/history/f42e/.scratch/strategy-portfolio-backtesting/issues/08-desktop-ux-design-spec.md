## Scope / What to build

依据[桌面设计方案](../../../docs/specs/2026-09-29-strategy-desktop-ux-design.md)审阅并收敛现有原型的桌面体验：保留 A 四步创建和 TradeReview 风格；组合总览、全局组合切换、统一时间控制、进度安全、调仓解释、结果比较、控件规范和说明分层。

这是设计规格总票，不是直接实施生产功能的授权。当前发布完整设计输入；后续可点击验证继续由既有工作台、结果比较与最终交接决策票承担，避免另建重复实施队列。窄屏暂不修改。

用户已确认以“桌面创建→多组合运行→调仓回看→结果比较→返回重开”为主验收入口，并独立对照 TradeReview 风格；不把这项边界确认扩张为全文设计或生产实施批准。

- [ ] UX01–UX10 均有明确桌面布局、动作、状态及验收反例；用户反馈收敛为可交接设计。反例：用评审意见清单代替设计决定。
- [ ] 新默认净值、盲看替代操作、派生实验和结果入口有明确设计反馈；不将本次“生成方案”视为用户批准全部细节。
- [ ] T01–T12 完整桌面旅程及同状态风格对照通过，并引用既有决策票证据；反例：只做一张静态截图就关闭整票。
- [ ] 窄屏本轮范围排除贯穿规格、任务、覆盖与验收；反例：后续代理又添加 390px 改版要求。
- [ ] 新旧约定的替代关系清楚；原产品数据复用、真实持久化与统计语义未因原型简化被删除。
