# 持仓估值修复实施契约

来源：用户截图、已接受诊断与 repair-options.md。用户确认“展示已知部分并补齐完整估值（推荐）”；“默认异步补充齐（不影响正常流程，同时给到更新的状态动态效果），另外有手工触发按钮”；2026-10-06 “开始修复”授权实施。技术默认值由 coordinator 作可逆实施裁定，不冒充用户逐项决定。

## 财务与展示契约
- 同币种、同指标、同观察时点提供 known amount、covered/expected、covered members、complete/partial/unavailable、reasons。金额存在可展示已知小计；不得据此置全组合完整为 true。
- 完整实线、部分虚线、完全未知断点。币种独立计数。覆盖成员/状态变化处断线且点详情明确变化，不能把不一致小计之差称真实损益。单点可见。收益率只在可信且一致的成本与盈亏覆盖下展示。
- 第一阶段原始隔离 DB 9/14 市值 CNY 194501.40、USD 1551.99；盈亏 CNY -4078.52、USD +188.99；全范围 6/15，完整 false。后续数据修复独立复算新预期并保留此基线。
- 可信来源余额只能从生效时点向后传播。缺数量、缺成本分别保留。算术净零/当前无开放回合不能清除旧仓。不得改原始交易、合成余额证据或删除难估值证券。
- 支持的红股事件复用 position-ledger 语义；未知行动与不明证据继续阻断。

## 行情及更新契约
- 当前/历史用一致市场最近已完成 session 与绝对时点截断，保留正价格/币种/未来/来源和最新成交保护。休市不能按自然 3 天否定最后有效收盘价；缺应有最新 session 仍 unavailable。
- 日期-only asOf 为对应观察日结束时点；timestamp asOf 采用真实 UTC 截点。历史重建允许后来获取的历史日线；不代表当时已知。
- 日线完成采用已收盘且来源可用的保守判断，formal close 与 OHLCV 最终完备性分开，不捏造 provider finality；同日尚未收盘数据不作正式收盘估值。
- 当前产品采用“最近已完成交易日的来源日线参考估值”，并非经交易所独立认证的最终收盘价。提供方未给最终性字段，继续标为非实时参考；已完成 session 只能控制日期可见性，不能证明来源最终发布。当前日内新增持仓不得沿用早于最新成交日的价格；同日收盘后成交也不得用收盘前抓取的滚动价。有 timestamp 时保留绝对成交截点；日期-only 未明顺序仍保守。本次不声称来源最终性已解决。
- 自动范围：可见交易室的当前组合及当前选择的历史区间所需标的日线，复用既有 instrument daily refresh（由最早账本/选择区间需求决定）。同一范围/市场完成 session 一次自动尝试，失败不 effect 无限重试；手动可重试。用户切换范围不阻塞交互。
- 自动/手动共享去重、全局锁、既有 scheduler/批次/并发/限流/取消/持久化。重叠任务共享或明确排队/等待，不重复请求。不引入全市场重构。
- 可见状态：待更新/等待其他行情任务、下载中、历史重算中、完整/部分/失败/取消。基于实际 successful/partial/failed/cancelled 与持久化结果；processed 不能冒称成功。不知道总量不伪造百分比。
- 首次计算期间若后续同范围输入排队，先完成的安全快照即可显示，并明确更新中；前进的 timestamp 可保留旧快照，范围/币种/汇率变化及时间回退不能沿用。用于显示的旧快照不构成刷新完成回执，acceptedInput 仍须是精确的最新输入。
- 无数量/成本证据另列，后台行情更新不宣称能够补齐账本。失败/取消保留有效缓存，reload 可识别中断并手动继续。
