## 请求粒度

|操作（LibraryReadPort 草案）|输入|输出及范围|禁止的旧依赖|
|---|---|---|---|
|`readOptions`|模拟模式、有效日期上下文、AbortSignal|稳定市场/账户选项、默认范围及版本；选项不由一页行数据临时推断|不得借元数据入口返回全部成交/练习/原件|
|`readPracticePage`|日期范围、市场、账户 ID、搜索、稳定排序、页号、pageSize=6、可选 snapshotVersion、AbortSignal|当前页行、完整入选数、可计算/未知数、全范围列表总额状态、snapshotVersion、有效页界限|不得返回全库后由组件切 6 条；总额不能冒用当前页合计|
|`readPracticeDetail`|practiceId、预期 revision/version（直达 URL 可不带）、AbortSignal|单对象身份/标题/来源摘要/三种时间、独立财务字段、内部配对首页及总数、版本、可用动作及原因|不得取全库统计再 find；不得传原始文件或 legacy references 给展示层|
|`readPairPage`|practiceId、相同 revision/version、页号、pageSize=6、AbortSignal|该练习内部配对当前页、总数和版本；少量配对的默认帧仍与参考同态|无界配对数组、跨练习混入、为一页重新下载所有源成交|

页号与 6 条/页来自现有旅程合同。如何用游标/索引实现、是否把合计拆成独立请求、快照保留时长及版本过期策略由 R 决定；不是先把旧 API 改名包装。Mock 先模拟一致快照，旧版本/失效场景显式报错，禁止静默混合两版。统计端口在 F2 按实际展示增补，不先造一个含所有数据的 `getEverything`。

## 字段语义

|数据|前端需要的语义|
|---|---|
|身份|稳定 practiceId、revisionId、practiceVersion、snapshotVersion；instrument 的 id/symbol/name/market；accountId/label；同标的同日序号。显示名不能当 identity|
|时间|有效练习日期及其来源、历史最早/最晚成交、导入时间及显示时区；不互相兜底。正式列表没有未知练习日期分支|
|行计数|原始成交数、内部配对数/是否完整、未平仓数量及其可确认状态；练习仍按文件计一个样本|
|金额|十进制字符串 value + currency + `known/unknown`；unknown 带 reasonCode 和可读原因，不能用 0、NaN 或缺字段冒充。金额与收益率独立可计算|
|财务分解|整份练习已实现毛额、结束估值的未实现毛额、总费用、整份净额/收益率；详情闭合净额/已平仓费用/留存费用分别列出，不能重扣总费；来源已净额与毛额口径显式标识|
|资本/估值|资本值、币种、默认/单设及版本；最后交易所在 bar 的结束估值状态与原因。首批仅展示，不保存；缺价不造卖出或套当前价|
|内部配对|稳定 pairId、完整 practice 身份、开/平时间、数量、净额状态；具体来源映射属于 adapter，不在表格中凭两条 ID 猜金额|
|范围合计|全入选练习数、当前指标可计算数/未知数、总额币种/汇率状态及版本；多币种只适用列表当前汇率 CNY 汇总，未设置兜底的表现仍需产品决定，首批固定 CNY 样本不擅自补默认汇率|
|动作|availability + reason，区分阶段未接入、缺真实周期、对象失效、缺必要输入；不能把所有按钮禁用都写成“缺数据”|

建议统一数据状态为 `loading / ready / error`，其中 `ready` 的单指标仍可 unknown；空集合是成功的 ready，不是失败。网络/权限/合同损坏/对象不存在/版本失效分别保留错误码与可重试性。宿主区分待请求与已生效范围，保留最后成功的范围和结果；新请求成功才原子应用范围/数据/版本，失败说明新范围未应用并重试该目标（V2.0 第七章）。过期标识也由宿主处理；取消不是弹错误。记录耗时和请求数供开发诊断，不放入产品指标卡。

## Mock 场景合同

场景由开发入口 URL 参数选择，正常产品画面不增加调试工具条。固定版本数据通过同一端口异步返回，支持 AbortSignal；组件内无 `if mock` 分叉。现行稿与后续业务有冲突时，以新业务修正文案及数值，差异表记录来源。

|场景|必须可观察的反例|
|---|---|
|reference|六练习 A–F；A 残余 70/结束估值未知，其他五个净额合计 388；练习数/成交数/配对数各自正确；详情为准确 A/B|
|pagination/identity|至少 13 份固定练习用于 3 页；同标的同日不同 practice；筛选后总数/合计属于全范围，不能用 6 行反算|
|empty|条件确实得到零行/零样本，清条件恢复；不是隐藏已有行|
|loading/error/retry|可控慢响应、第一次失败后恢复；请求/反馈/取消可被浏览器观察，结果槽不无故塌陷|
|stale/not-found|A 请求未结束选 B；A 晚回不覆盖 B；版本失效和对象不存在显示准确原因，返回条件保留|
|unknown/zero/longtext|已知 0 与未知分别显示；长名/大金额可查完整值；缺配对、无残余与有残余缺价分别表达|
|explicit-end-price|仅独立场景明确 A 结束价 140、净额 4677；默认 reference 不继承该价格|

Mock 的预期数值是核对展示的固定材料，不证明真实解析、财务计算、来源认证或数据库守卫正确。未来真实 adapter 必须复用端口契约测试，并增加真实来源与集成验证；不允许仅匹配 Mock 截图就接受后端。

## 深入 review 的逐请求表

先由 F1 的实际请求和使用字段完善此表，再对后端作选择，避免先迁服务再寻找理由。

|问题|已知旧实现教训|评审必须提供的结论/证据|
|---|---|---|
|一页/单详情究竟访问多少数据？|25db 全量列表浏览器分页；单详情读全统计|调用图、SQL/索引/查询计划、行数、原件字节、解码/哈希次数、响应字节；无关练习增长时单详情工作量边界|
|摘要和事实如何分层？|原件→解析/配对→财务在多个读入口重复|source/practice/revision、执行事实、配对与人工成果、估值/资本/FX派生关系；字段权威、保留哪些规则和重写哪些组织层|
|校验何时发生且如何发现损坏？|每次全量重验慢，但直接删校验会失去正确性保护|写入认证、读取验证粒度、版本/损坏/修复协议、并发一致性；不能以速度为由跳过来源保障|
|页面组合是否制造额外请求与解析？|旧 workspace bootstrap、新旧双链；重复 serialize/parse|实际 network waterfall、bundle、服务分段、JSON 字节/解析、React 呈现；重复工作根因分开测，不凭源码猜占比|
|如何保持完整范围统计与当前页一致？|只切 6 行不会降低整库计算；页合计不是全选合计|分页、全范围汇总、分布成员查询的边界；快照版本、失效/过期行为与内存上限|
|什么变化需要重算？|只按旧成交表失效会漏 practice/source/revision/date；app_settings 已有注册|导入、改期、资本默认/覆盖、估值、FX、显示名各自的依赖与失效；完整映射及连续两次更新反例|
|同步读取还是持久投影/异步发布？|38a0 发布机制有价值但每读全发布校验约 25.43MB；历史 A1b route 链 median 3078ms，不能当浏览器耗时|对正确数据比较同步有界查询和版本投影的成本、首读/后台构建/新鲜度/故障恢复；不先选缓存框架|
|真实首屏目标如何证明？|合成 LRU 亚毫秒与完整页面不可比；25db 完整分段尚缺|固定数据量/分布、版本/runtime、冷/热/进程重启/变更后、请求与页面可见完成分别计时，报告 median/p95/最大值、响应字节和错误；保留既有桌面首屏 1 秒目标，测量起止另行冻结|

既有数字与限制以 [性能诊断](PERFORMANCE.md)为证据，不新增性能通过结论。R 的产物应是模块裁决更新、接口/模型 ADR、可复现测量方案和待用户讨论的业务选择；未证明的提速和兼容性标 NOT VERIFIED。首次真实接入先做列表/单详情，不把所有后端一次搬入。
