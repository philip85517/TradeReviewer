# 文档阅读器最终集成检查登记

触发：静态设计图/正文结构修改，用户要求独立验收至通过。适用 frontend-control-audit；独立 Agent 检查图稿，协调者检查最终构建的阅读器。此文件是操作前登记，尚不表示执行或通过。

最终版本以最终 review-package.json 的全内容 fingerprint、source fingerprint、文件 SHA256 绑定。服务为本工作树3090静态文档服务；不连接产品数据库。比较视口1440×1000，必要的1280视觉图由独立审查者负责；浏览器缩放与DPR实测记录。

| ID与动态边界 | 真实输入 | 预期与证据 |
|---|---|---|
| TOC/每个最终 nav[data-target] | 鼠标点击 | 精确heading可见且hash对应；记录位置/当前目录态 |
| FRAME/每个分镜的每一帧 | next（首帧reset） | 唯一可见帧、计数、caption及源图与manifest对应 |
| DEMO/每个分镜 prev,next,reset | 鼠标 | 正确前后状态；首帧prev禁用，末帧next/play禁用 |
| DEMO/每个多帧组 play,pause | 鼠标及等待实际计时 | 播放自动进入下一帧，暂停保持；不调用内部setIndex |
| DEMO/每个组 ArrowRight/ArrowLeft；一个多帧组 Escape | 键盘 | 前后切换和停止；与鼠标证据分列 |
| IMAGE/每个最终图 occurrence 原尺寸 | 鼠标打开，关闭 | modal源图/自然尺寸吻合，scroll容器容纳长/宽图；关闭恢复焦点 |
| IMAGE/一个长图的键盘打开/Tab/End/Escape | 键盘 | 原尺寸弹窗焦点受限、能查看末尾、退出焦点返回触发链接 |
| COMMENT/评论入口与6个现有评论详情、定位 | 鼠标 | 原意见/状态可读，2文本映射及4图映射到对应语义位置 |
| ORIGINAL/4条原图链接 | 鼠标 | 打开留存旧图，hash与旧评论记录对应；原图与新版区分 |
| COMMENT/关闭与重新打开/刷新 | 鼠标 | 6条原评论仍可读，原内容状态历史字节不变 |
| FINAL/重新打开最终阅读URL | 浏览器导航 | 最终指纹、主要标题/图片成功、无阻断控制台错误；保留预览服务和交付tab |

明确排除：SVG内的产品示意控件不是运行产品，不能将其绘制当作业务点击通过；评论新建、回复、采纳、解决等写入流程未修改且本次须保留原评论，不执行；评审包导出/身份设置/其他版本对比未修改；真实业务交互、数据库持久化、触摸及手机断点不属静态设计交付。排除项不计PASS。

全部登记项从最终DOM/manifest展开，真实结果分别保存动作日志与截图；覆盖率仅用于该登记范围，不能称整站所有控件100%。任一必需FAIL或NOT VERIFIED阻止交付。
