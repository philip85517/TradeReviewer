数据与适用范围

职责与适用情景

持仓建立后，随已知行情更新移动基准，在满足命名预设的退出条件时提出退出意图。它不负责候选筛选或买入信号；可用于日线与周线回测的趋势跟随、回撤和风险控制场景。

规则摘要 / 输入与输出

输入截至当前揭示时点可知的行情、持仓、入场基准、移动基准和预热数据。
输出退出意图、触发说明、计算时点与执行边界，不直接写入成交。
移动基准每个可知行情更新点重算；方向、起算点和重置规则由 v3 预设声明。
触发 / 成交触发不等于成交；跳空、同日冲突、未成交和重新入场遵循实验执行口径。

命名预设与有效参数

预设移动止盈止损 · 趋势跟随（v3 默认）
移动基准收盘价基准；更新时点：已揭示 K 线收盘；来源：包 v3 规则说明
退出阈值1.5 × ATR（合成示例）；单位：价格；范围：0.5–5.0 × ATR（合成示例）
必要预热至少 20 根同粒度行情（合成示例）；不足时显示“数据不足”，不补零

数据、市场与兼容性

所需数据：日 / 周行情、持仓状态、入场基准。支持市场：股票与 ETF；兼容当前筛选包与买入信号包的单组合执行口径。执行状态：可执行；区间覆盖仍在实验预检中核对。
