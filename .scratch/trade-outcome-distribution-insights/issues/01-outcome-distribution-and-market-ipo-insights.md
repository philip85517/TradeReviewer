# 01 — 收益分布、新股拆分与分市场模式洞察

**What to build:** 在现有“模式洞察”入口增加基于已平仓回合的收益结构分析：收益率分布与小亏/大亏/小赚/大赚分类、胜率—赔率关系、尾部集中度诊断、新股 IPO/非新股/无法判定拆分，以及按市场的同口径比较。

**Blocked by:** 无；复用现有交易室范围、`InsightEpisodeFact`、IPO 证据和模式洞察页面。

**Status:** ready-for-agent

- [ ] 以费用后收益率为主口径，明确展示样本数、持平、排除原因和大小分界值
- [ ] 提供收益率直方图、五类结果桶、极值摘要和胜率—赔率散点图，并支持进入对应回合
- [ ] 实现亏损/盈利广度、尾部集中度和样本门槛明确的中性初步诊断
- [ ] 基于 IPO 配售/获配证据实现新股、非新股、无法判定三态分类，不从上市日期猜测
- [ ] 按现有标准化市场字段生成分市场表现，保持实盘/模拟盘和模拟运行隔离
- [ ] 跨币种时允许收益率分析，金额遵循现有 FX/原币可用性规则，不用零替代未知
- [ ] 补齐报告生成器、事实构建、组件和真实浏览器路径测试
- [ ] 验收前后核对隔离数据库中的原始交易数量与内容摘要不变

**验收口径：** 详见 [../spec.md](../spec.md) 的 User Stories、Implementation Decisions 和 Testing Decisions。实现完成后必须由协调者在真实浏览器中独立检查图表、分组筛选、证据跳转、窄屏可读性和控制台错误，再声明完成。
