# 跨午夜练习的日期归属：用户确认

2026-10-26，用户真实答复已收到。本记录是“练习名称与日期口径”的部分决策；该票其余问题仍保持 open。

## 用户依据

问题：“同一份练习跨过午夜时，是否仍保留为一份练习，并由用户在导入确认页选定一个练习日期，标题、筛选和统计统一归属这一天？不按文件里的历史成交日期拆分练习。”

答复：“采用单个确认日期（推荐）”。

## 已确认规则与验收

跨午夜不拆成两份练习。用户在导入确认页选定一个有效练习日期，标题、模拟日期筛选、排序及统计采用同一个当前确认日期。文件中的历史成交日期只用于原成交与历史交易区间，不将练习按历史日拆分；导入时间也不替代练习日期。

例如用户实际练习跨过 2026-10-25 / 2026-10-26 午夜，选择 2026-10-25 后，整份文件只有一个 practice ID 和一个练习统计样本，标题与归属均为 2026-10-25。保留完整源记录及其原成交时间；并非将不同历史日期裁切或改写为确认日期。未来实际导入、返回列表、筛选、详情、统计及 reload 必须重读同一个持久化确认值。

此后更正仍保留 ID、复盘成果与编号历史，编号冲突遵循[已确认规则](2026-10-26-date-number-conflict-confirmation.md)。本答复未批准候选冲突的具体页面样式、文件名提取语法、内部配对标题或历史区间异常处理。

这是业务决策记录。当前日期纯函数只验证显式候选与本次人工输入；真实导入日期选择、持久化、导航、统计归属及隔离库验收仍为 **NOT VERIFIED**。
