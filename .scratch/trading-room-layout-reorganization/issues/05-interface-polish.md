## What to build

针对真实浏览器巡检发现的问题做最小修正：统一模式洞察与数据管理二级切换的 Tab 语义和键盘行为；修复窄屏统计范围控件及模式分析摘要卡的压缩；统一交易室筛选项对齐；提升收益配置不可用状态的对比度；去除质量页重复标题。

- [x] 模式洞察、数据管理、交易库二级切换使用一致的可访问 Tab 语义，并支持左右键/Home/End。

- [x] 交易室筛选标签和控件按同一基线布局。
- [x] 收益配置的“不可计算/暂无本金”等状态清晰可读；质量页不重复展示同一标题。
- [x] 相关测试、类型检查、构建和真实浏览器桌面/窄屏验收通过。
