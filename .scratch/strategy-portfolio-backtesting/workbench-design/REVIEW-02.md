### UR01 / UR02 的定量复现

| CSS 视口 | 绘图区宽度 | 蜡烛中心间距 | 实体宽 | 实体之间空白 |
| --- | ---: | ---: | ---: | ---: |
| 1440×900 | 1036px | 133.43px | 8px | 125.43px |
| 1280×800 | 876px | 110.57px | 8px | 102.57px |

公式为 `(绘图区宽 − 左边距50 − 右边距52) / (8 − 1)`。中心间距约为实体宽的 14–17 倍，这是稀疏感的直接来源。运行中从 6/18 推进至 6/19，已有三根的 x 不变，只新增第四根；**“每推进一天把已有 K 线横向重新铺满”这一假设不成立**。纵轴会按已见数据重新适配，可能造成纵向移动，不能与横向间隔混为一谈，也未据此认定使用了未来价格极值。

建议下一稿试验每根中心间距 12–16 CSS px、实体约占间距 60%–75%，配合约 60–100 根已知历史 bar 的初始窗口。以上是待对照验证的起点，不是已批准尺寸或行业标准；可用历史不足时保持合理密度并说明，不伪造行情填满画面。T0 可展示起点前已知行情作为上下文，不能展示起点后的未知行情。净值图仍从实验起点表达净值，两种图不共用一个伪造数据对象。

## 建议的用户动线与控件契约

主路径：**确认实验和组合 → 看当前状态 → 推进一日或播放 → 查看调仓及原因 → 查看阶段结果或组合对比 → 返回原观察位置继续。**

固定框架应保留：身份区、摘要带、主图、图下回放与 320px 右侧详情。变化的是可见名称、语义分组和局部内容，而非为每个状态重新排整页。

| 用户目标 | 常驻可理解表达 | 操作结果 / 不变量 |
| --- | --- | --- |
| 看清自己正在研究什么 | 实验名、组合/锁定策略、图表对象；K 线另有标的/周期/单位 | 切组合与切标的是不同动作；图例与当前对象一致 |
| 开始逐日观察 | 待开始；“推进下一交易日”或“播放” | 推进才更新已运行上限；新 bar/交易应实际可见。空态不承诺下一日一定成交，改为“推进后查看策略是否产生交易” |
| 回看过去 | “回看上一日”“查看日期 ▾”；正在查看… / 已运行至… | 只改变查看日 V，不倒退已运行上限 M；回看期间暂停并解释推进条件 |
| 恢复进度 | “回到最新进度” | 回到 M，不展开未知未来；到末尾应显示“已运行完成”，不能提示“现在可以继续推进” |
| 理解策略为何行动 | “组合详情：概览｜调仓记录｜统计指标” | 点调仓后全区进入事件日；“关闭详情”留在事件日，“返回阶段结果 · 截至…”恢复原结果来源，不能混为一个返回动作 |
| 判断表现 | “阶段结果｜组合对比” | 结果截止/共同有效截止表达准确；图表、图例、指标和右侧内容一致；回放固定槽保留并说明如何返回观察 |
| 处理低频操作 | “实验操作”菜单 | 展开剩余行情仍需明确确认，并保留已看后续记录；无事件不是执行这个动作的理由 |

回放带建议在同一固定行内分成“查看日期/回看”与“推进/播放/速度”两组。“推进下一交易日”“回到最新进度”优先保留文字；播放/暂停可用熟悉图标配短词。紧凑程度要在 1280 宽度实际复验，不能用缩小字号或删除含义换取不换行。最终按钮顺序及尺寸待修订稿验证。

## 为什么上一轮检查没有发现这些问题

上一轮 PASS 范围是固定矩形、所列模型路径与特定截图，不能推出首次使用清晰或所有图表组合正确。本轮暴露出三项过程缺口：

1. 将“固定槽位”过度等同于“固定标签”，没有要求标签在每个模式中保持真实含义。
2. 将“紧凑”主要落实为去掉文字，未逐项检查动作是否能在点击前被理解，尤其是导航与推进的区别。
3. 用少量净值样本和假蜡烛代替行情，足够演示外框，却不足以评估 K 线密度、视野和数据对象。

应保留上一轮有限 PASS 和已修正历史，同时重新打开受影响的图表、控件语义与跨视图门槛。本轮未进行新用户测试；不能宣称用户任务成功率或理解时间已通过。

### 独立审阅补充：时间上下文与事件入口

比较场景中查看日、各组合完成日与共同截止可以不同；事件追溯也不会重新运行实验。这些规则应保留，但不应要求用户从四五处日期拼接口径。UR07–08 的修订须提供固定业务上下文，例如“正在回看 06-18｜已运行至 06-25”“共同截止 06-19 · 受组合 B 数据中断限制”“06-18 调仓 · 来自截至 06-25 的阶段结果”；比较页四项摘要还须明确属于哪个组合。仅看摘要和图头仍不能回答“谁、截至哪天”，即不能通过。

图上“调/出”目前是无点击处理的 SVG 标记（L344），列表才可进详情。后续可以把两者接到同一事件入口并验证日期一致，或明确图上标记只读；不应让样式暗示已有可点击能力。此项纳入 UR04 的对象/动作一致性检查。次级说明颜色需在两档桌面直接复验；不通过缩小关键字或降低对比度维持密度。
