# 截图校对上下文栏排版设计

## 背景

截图校对弹窗中的时区选择和交易账户输入目前没有专属样式，控件使用浏览器默认排版，导致标签、输入文字和间距与深色界面其他区域不一致。

## 设计

- `.screenshot-review-context` 作为独立的字段栏，使用横向 Flex 布局、`16px` 字段间距、上下 `12px` 内边距和底部分隔线。
- 每个 `label` 使用上下堆叠布局；标签为 `10px`、控件文字为 `12px`，保持现有 Geist/PingFang 字体继承。
- `select` 和 `input` 统一 `34px` 高、`8px` 圆角、`10px` 水平内边距，并沿用现有深色表面和聚焦边框。
- 时区字段宽度约 `300px`，账户字段宽度约 `240px`，两者均允许收缩但不撑满整行。
- 在窄屏下字段栏允许换行；宽度不足时字段切换为两列或单列，避免文字挤压。

## 范围

只修改截图校对上下文栏的 CSS 和对应组件测试，不改变文案、状态管理或交互行为。

## 验证

- 组件测试确认时区和账户控件仍可通过无障碍标签访问。
- 样式检查确认字段栏、控件高度、字体大小和响应式规则存在。
- 运行截图校对组件测试、类型检查和 lint。
