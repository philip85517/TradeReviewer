# 03 — 当前持仓与数据管理职责重组

**What to build:** 让趋势之后的当前持仓继续作为复盘入口，同时把数据质量明细、收益质量细节和本金配置从首页移到数据管理，使首页只保留不打断阅读路径的状态提示。

**Blocked by:** 01 — 核心统计范围与收益摘要

**Status:** ready-for-agent

- [ ] 当前持仓保留现有记录、排序、状态、估值信息和复盘入口，并明确标注当前状态与截至日期。
- [ ] 当前持仓响应交易性质、模拟运行、资产分类和高级筛选，但不因本月、近三个月或今年至今的业绩期间而错误消失。
- [ ] 首页移除完整数据质量、收益质量和本金录入面板，仅保留紧凑的数据状态提示及进入数据管理的动作。
- [ ] 数据管理集中展示交易可信度、持仓估值、历史行情、汇率状态、受影响记录及可执行处理动作。
- [ ] 本金分类、币种、保存、清空和校验等配置动作迁移到数据管理；首页仅保留有效时的本金参考收益率结果。
- [ ] 数据管理保留原有检查、重试、查看、保存和清空能力，并有集成测试覆盖迁移后的入口与行为。
