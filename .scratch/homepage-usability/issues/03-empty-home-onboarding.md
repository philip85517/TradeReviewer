# 03 — 将空首页改为明确的导入引导

**What to build:** 首次进入且尚无交易时，用户可从首页中央直接开始导入，理解支持的输入，并在确认后自然进入真实交易复盘。

**Blocked by:** None — can start immediately

**Status:** done

**Priority:** P2

- [x] 中央以“导入交易记录”为唯一主要操作，“从截图恢复交易”为次级操作，两者层级明确。
- [x] 就近简要说明实际支持的券商与文件格式，不承诺支持未适配的对账单或截图版式。
- [x] 移除重复的零股票计数、重复空状态及无内容的预留侧栏，空状态充分使用可用区域。
- [x] 中央入口复用现有导入复核和确认流程；取消不新增成交，成功导入后空状态消失并可开始复盘。
- [x] 加载中、读取失败与确实没有交易明确区分；保留失败恢复入口。
- [x] 在桌面、1024px 和 390px 宽度验证入口可见与完整导入路径。

**Verification:** 见 [验收记录](../verification.md)。
