# 非财务事实与展示信息组合读取：实验覆盖

依据：[真实规模读取](../real-data-fact-experiment/RESULTS-RUN-02.md)、[增量更新](../update-publication-experiment/benchmark/reports/run-review-approved-01/COORDINATOR-ACCEPTANCE.md)、[展示信息与重启](../display-cache-restart-experiment/COORDINATOR-ACCEPTANCE.md)、[上轮对照](../source-reuse-experiment/reports/real-sample-01.md)。实验在独立工作树内，禁止产品与共享业务数据库写入；财务、Bars、重复导入暂停。无前端改动，浏览器、视觉本实验不适用。

| ID | 范围与旅程 | 负责人 | 验收证据 |
|---|---|---|---|
| C01 | 一致快照下，已准备事实及展示信息构成摘要和当前页；名称/逐笔标签保持各自语义，不将未知当零 | integrated_worker / 协调者 | 真实行为合成测试、独立审查 |
| C02 | 名称或标签变化不改变成交版本，旧结果必须拒绝或安全刷新，返回新内容；反例包含相同标的不同逐笔标签 | integrated_worker / 协调者 | 测试、版本变更证据 |
| C03 | 历史补录/跨组修订后旧游标拒绝，新增范围完整无重漏；失败与过期写入不得暴露混合版本 | integrated_worker / 协调者 | 完整分页与失败测试；模拟变化非真实导入 |
| C04 | 重启后已准备结果可复用，独立进程实读，且全部校验与实际读取时间计入 | integrated_worker / 协调者 | 进程回执、一次读取与总耗时分开 |
| C05 | 展示新鲜度校验成本不能藏在计时外；按实际可行的隔离样本对照、记录读取次数/处理行数、校验字节和正确性 | measurement owner / 协调者 | 专用只读副本，冻结/独立审查及可复核结果 |
| C06 | 清晰区分假设的原子版本机制与现有产品真实接线；不宣称桌面一秒、全部财务、真实导入或崩溃安全 | 协调者 | 局限与结论、任务记录 |

## 2026-10-30 实验收尾修复覆盖

依据 [实际失败与原因](reviews/measurement-06/REAL-RUN-COORDINATOR-20261029.md)、[独立复核](reviews/measurement-06/real-scale-postrun-independent-review-2026-10-29.md)、[恢复范围 R01–R06](RESUME-MEASUREMENT-2026-10-29.md)；本轮恢复后第 2 轮。用户已确认测试边界为隔离测量入口和实际失败回执及合成文件。只修复测量工具，不执行真实规模数据、产品代码、UI 或共享库操作。

| ID | 可观察要求与反例 | 负责人 | 验收证据 |
|---|---|---|---|
| E01 | 大规模明细不得被组合为超限单个字符串；最终报告完整可复核，保持统计、度量及已完成样本 | 实现 Agent；协调者集成 | 合成反例红/绿、报告读取与内容完整性、独立验收 |
| E02 | 汇总或回执写入失败时记录真实失败状态；源/日志无法复核不伪报通过，保留已完成证据 | 实现 Agent；协调者集成 | 合成错误注入实际回执和错误呈现、独立验收 |
| E03 | 收尾顺序、源与私有副本核验、锁处理和完整计时不因新结构削弱 | 实现 Agent；协调者 | 冻结候选代码逐项审查、既有合成回归和边界测试 |
| E04 | 保留原始失败证据；不输出真实记录；防止产品及被暂停的功能被触碰 | 协调者、独立验收 | 文件范围审查、固定入口与合成数据验证 |

无前端页面、控件或数据接线修改，UI 审核不适用。真实规模重跑不在本次“先解决收尾”范围，仍须满足原有单次真实实验条件及新的门禁。
