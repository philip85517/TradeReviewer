# 09 — 提升现有页面文字与关键指标的可读性

**What to build:** 用户在正常缩放下能阅读股票信息、表单和复盘指标，清楚区分主要操作与辅助状态，不再依赖极小字号容纳内容。

**Blocked by:** None — can start immediately

**Status:** done

**Priority:** P2

- [x] 常用正文、表单输入与标签以不小于 12px 为基准，次要日期和状态不小于 11px；避免继续使用 8–9px 展示必要信息。
- [x] 关键文字与背景对比度至少达到 4.5:1，选中、异常和不可用状态不只靠颜色区分。
- [x] 持仓指标优先显示当前决策需要的信息；次要指标可展开查看，保留原有含义、币种和时间口径。
- [x] 不通过裁切必要标签或缩小字号解决空间不足；长股票名、长金额和状态文案有可读的换行或查看方式。
- [x] 在 1280px、1024px 和 390px 宽度验证主页、交易库及复盘面板，主要操作不被遮挡，关键文字无重叠。
- [x] 验证浏览器放大后的可读性与操作可达性；可独立提交，与其他任务相同区域的改动通过协调合并解决。

**Verification:** 见 [验收记录](../verification.md)。

**验证边界：** 放大采用等效 200% CSS 视口重排检查；内置浏览器原生缩放未实测，未将其作为已完成实测宣称。
