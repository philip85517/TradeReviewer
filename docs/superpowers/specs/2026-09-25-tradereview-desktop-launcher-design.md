# TradeReview 桌面启动器设计

## 目标

在 macOS 桌面提供一个名为 `tradeReview.command` 的可双击启动器。点击后启动统一部署的 TradeReview 生产服务，并在服务健康后打开 `http://127.0.0.1:3022/`。服务继续使用 `/Users/zhoulin/projects/交易空间/TradingReview` 的当前 release 和该部署的正式 runtime 配置；SQLite 正式路径仍由配置解析，不复制数据库、不启动第二个数据库实例。

## 方案

仓库维护一份启动器源文件（位于部署运维目录），桌面上放置该源文件的可执行副本。脚本调用既有 `ops/start-native.command`，不重写 Node 启动参数。双击时若 3022 空闲，启动器在当前 Terminal 会话以前台方式运行服务，同时轮询只读健康端点；就绪后用 macOS `open` 打开首页。关闭该 Terminal 会话会停止服务，符合现有运维约定。

若 3022 已监听，启动器只在能确认监听进程属于正式部署且 TradeReview 健康检查成功时打开现有页面；若端口属于其他进程、健康检查失败或服务未在限定时间内就绪，则显示明确错误并退出，不杀进程、不换端口。重复点击不会启动第二个正式服务。

## 交付范围

- 在仓库增加可维护的桌面启动器脚本及必要的简短使用说明。
- 安装/复制为桌面上的 `tradeReview.command` 并设置可执行权限。
- 不安装常驻 LaunchAgent，不创建浏览器控制服务，不修改业务数据库或行情数据。

## 验收

- Shell 静态语法检查通过。
- 端口空闲时，启动器调用正式启动脚本；服务健康后打开正式 URL。
- 已有本服务时不重复启动；端口被其他进程占用时安全失败且不终止该进程。
- 桌面文件名称准确、可执行；从该文件启动后首页可访问，storage status 返回正式库数据。
