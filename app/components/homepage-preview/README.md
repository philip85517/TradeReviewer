# 首页前端入口

正式路径：`/home`，活动页面为 `full-homepage.tsx`。指标、持仓、历史月/年桶、贡献分段、目录搜索、详情与导出全部消费 `/api/home` 同版 Full HTTP 合同。`complete-mock` 中仅复用现有样式、展示格式/几何函数与页头控件；模拟数据生成器没有正式页面消费者。

`/trades` 接收首页明确账户、实际证券与市场、成交活动期间，初始化现有真实交易库。返回 `/home` 会重读最新完整发布并恢复首页范围、两模式贡献条件、搜索结果、滚动与焦点。

`/preview/homepage` 为保留查询参数的兼容跳转。`archive/` 与完整 Mock 文件保留归档，不是活动生产数据入口。

业务规则见[真实数据口径](../../../docs/specs/homepage-real-data-contract.md)，版本绑定的功能、持久化、视觉及性能结论见[接入交接记录](../../../docs/reports/2026-11-21-homepage-integration-handoff.md)。最终整页浏览器功能、持久化返回链和匹配视口视觉接受由协调者独立记录；实现者测试不替代这些门禁。
