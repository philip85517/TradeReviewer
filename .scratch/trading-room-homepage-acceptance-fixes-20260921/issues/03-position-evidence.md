# 03 — 核实负持仓证据并修正状态判断

**What to build:** 用户可区分有证据的空头与导入流水导致的待核对负差额，并定位到对应账户数据。

**Blocked by:** 无 — 可立即开始

**Status:** completed

- [x] 逐个审计现有负持仓的成交及开空/期初持仓证据，记录可证明的结论及缺失内容。
- [x] 不能仅根据负数量判定合法空头；证据不足时显示待核对并解释原因。
- [x] 不修改原始成交，不自动补数或改正负号；不把证据不足的成本/浮盈亏当作可信值。
- [x] 明确开空、缺失期初/超卖、不完整证据分别覆盖测试；持仓数量展示最多两位小数而计算精度不变。

验收依据：[交付记录](../acceptance-report.md)、[独立审查](../independent-review.md)。
