## 结论

主要产品原则已保留：同一三阶段工作区、图表优先、原判断/原计划可对照、阶段来源及补记、计划/实际区别、当前盈亏配置、不迁移首页 B、不预设复盘比例、完整内容、真实组件与样板保存范围。未发现必须推翻推荐视觉方向的重大矛盾。

未来信息与回 S0 的验收仍不足以直接给 PASS。规范文字表达了正确目标，但下面三项需要在验收计划中具体化；当前均为 **NOT VERIFIED**。可以补充验收契约，不需要扩大到正式业务实现。

## 1. 双截止与已完成 K 的投影必须明确

- 位置：规范 README:108、114–118；coverage DS06/DS09；任务 README:40–45。
- 缺口：仅“市场截止以内”容易被实现为 `candle.time <= cursor`；未明确以 `knowledgeAt` 判断该周期是否已完成可知，也未列切周期、同 K 多笔成交的反例。既有规格 UI:116–118 要求独立成交截止与未完成 K 隐藏。图表、摘要、列表使用“同一已知投影”还需说明不是把两个截止合成一个时间。
- 要求：行情按可知/完成时刻过滤；实际成交按独立 executionCursor 过滤。切周期、开合、resize、缩放不推进任一截止。成交可以先可见而该周期 K 尚未完成；同 K 多笔成交只揭示推进到的稳定顺序。
- 最小验收：固定 fixture 至少一根未完成 K 和同 K 两笔成交；记录两个 cutoff。切长周期后该 K 的完整 OHLC 不出现，但已知成交锚点仍准确；下一决策只增加目标成交；返回 S0 后两条 cutoff 与原已知集合恢复。未完成 K、未来成交、最终盈亏、未来日期详情、未来高低点均作为明确应不可见项。

## 2. Tooltip / list / summary / zoom 需要各自可观察反例

- 位置：规范 README:114、135；coverage DS09 的“逐项检查”尚无操作与反例。
- 要求：检查可见文本、hover/title、accessible name 和上下文弹层。列表包括标的/回合名称、成交选择、统计、快照入口；摘要包括盈亏、累计费用、退出、成交总数和“已完成”状态。未来快照若可主动打开，应作为揭示入口，明确告知并记录暴露，不可既展示未来内容又声称盲态。
- 最小验收：S0/S1 各打开统计及所有相关下拉/列表；在当前最右侧和空白未来区域 hover；缩小/fitAll/拖动时间轴，再调整价格轴。记录实际图与各层读取内容，确认未来成交/结果/完整未来 OHLC、可识别未来日期详情及基于全量未来高低点的自动轴范围未出现。
- 静态风险点：`app/components/recall/recall-workspace.tsx:3117` 的统计显示 `chartExecutions.length / currentExecutions.length`。分母使用全量成交数量，可能泄露未来成交总数。当前属于**待浏览器确认的潜在问题**，不是本审查已证明的运行缺陷；若没有批准的例外，应纳入 summary 反例，不能只验证默认折叠画面。

## 3. 所有未来揭示入口与回 S0 补记要形成一条验收链

- 位置：规范 README:94、108–110、135；任务 README:43–44 仅明确主动 S2；coverage DS07。
- 缺口：完整历史、未来快照/代表图、主动 S2、已看未来后回退等入口未分别列举。已有“永久 hasSeenFuture”目标，但没有验证新建与编辑 Text、原判断原文、两个阶段视野和来源能共同恢复。
- 要求：所有主动揭示入口写入 hasSeenFuture 及来源；返回 S0 不清除未来暴露，新增/改动历史判断显示“已查看后续后补记”。原始判断快照不可被该补记覆盖；补充记录其形成阶段。样板内存清空只是明确的 session reset，不可用作同会话暴露标记的清除入口。
- 最小验收：保存 S0 原判断全文、drawing id/anchor、截图和阶段视野；分别从 S2/完整历史/未来快照揭示（适用入口）。回 S0 后早期行情/成交集合恢复、原文可全文对照、原图形关联仍可见；新建一段并修改一段 Text，检查补记标签/阶段/暴露状态。再次切 S1/S0、会话内保存/恢复后仍一致。当前样板刷新重置明确记录为 session reset，不作为真实重载持久化通过证据。
