## Scope / What to build

把已确认的 Text/绘图规则转成可实现、可重复的端到端任务和控件验收，不重新投票默认盈亏比 `1:1` 或选中反馈方向。覆盖：

- Text：先价格/bar 锚点，连接线和标签随指针预览，第二点/释放固定文字框并编辑；框与锚点分离移动；原文完整、14px/1.5 候选值实测、展开/收起紧凑且命中区≥24/44；关闭、Escape、切工具、编辑失败和长中文。
- 线段类：趋势线、横线、箭头、通道、盈亏比的首点→动态预览→第二点/释放；点击身份清楚，拖动中有反馈，<3px 不提交零长度，通道先基线再宽度，一次动作一条历史。
- 选择/拖动：短确认动效后持久轮廓；8px 可见手柄、24/44 命中；二维 `move/grabbing`、价格单轴 `ns-resize`、时间/宽度 `ew-resize`；释放和取消后的光标与对象状态一致。
- 标签：风险/回撤/价格读数保留精确价格、比例、风险百分比，背景分组避让手柄；已有自定义比例不被改写。

## 验收标准与反例

- [ ] Text 真实鼠标点锚点后，移动指针能看到连线/标签/框的预览；第二点或释放后进入编辑；框移动不改锚点、锚点移动不改框和正文。反例：首击直接生成孤立框、无法关闭、或点击后整个布局被锁住。
- [ ] Text normal/selected/expanded/editing/cancel/longtext 同一套正文布局，选中不重排、不重复渲染、不缩短固定评论；Escape 在编辑、拖动、取点、闲置选择四层逐级退出。
- [ ] 趋势/横线/箭头/通道/盈亏比在第一点、拖动中、第二点/释放、Escape/切工具各有可见反馈；<3px 点击只保留首点，不产生零长度或幽灵历史。反例：点击不灵敏、线无预告突然出现、释放提交两次。
- [ ] 选中确认动效能让用户知道命中对象，随后轮廓/手柄持续可见；邻近对象不会被误选；拖动前、中、后和取消的光标、几何、历史一致。反例：选中无反馈或 cursor 永远是默认箭头。
- [ ] 新盈亏比默认为 1:1，编辑旧对象保持旧比例；密集标签保留重要价格/比例/风险百分比，边界内可读且不盖住操作柄。
- [ ] 选择、hover、preview、动效不持久化；完成创建/移动/编辑才写一条历史和实际保存。回放阶段、截止和可见 bar 不因绘图动作改变。

## 验收证据

- 真实浏览器操作：鼠标 click/drag/release、键盘 Tab/Enter/Escape、编辑输入和返回/刷新；鼠标、键盘、模拟粗指针、物理触控分开记录。
- `before / during / after` 截图/录屏、对象几何、锚点价格和 bar 时间、history 计数、cursor 记录；动效保留正常轨迹，不只保留最终帧。
- 长中文、长价格、密集标签、窄窗口和邻近对象反例截图；独立视觉复核者给出同态结论。
- `PASS / FAIL / NOT VERIFIED` 按功能、状态链/持久化、视觉三门分别记录。

## 派发说明

- 可能受影响的实现边界：`app/components/chart/`、`app/lib/chart/`、Replay/Review workspace 的现有绘图和 Text 入口；实现者必须先确认真实调用链，再提交精确文件清单，不得凭票摘要重构框架。
- 允许复用当前主题与组件；禁止以缩小命中区、隐藏全文、移除价格或改写原始交易数据来解决视觉问题。
- 共享绘图状态和历史只由单一 owner 修改；root 负责跨组件接线和独立接受；若真实调用方缺少切工具/保存回调，必须在报告中列明接口而非 mock 掉。
