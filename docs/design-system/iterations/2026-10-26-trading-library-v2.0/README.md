# 交易库 V2.0：按业务设计规范同步视觉方案

2026-10-26。用户要求将逻辑文档更名为《交易库设计规范》，由多个 Luna 5.6 Max 扫描复核最新视觉规范，并据此发布本地 V2.0 文档版本。

## 本次确认的问题

|问题|根因|修订方向|
|---|---|---|
|模拟练习被拆成多个统计样本|复用了配对级统计|汇总按练习，内部配对在练习详情展示|
|实盘回合随配对份数增加|把技术分配当作人的平仓行为|一次主动平仓一个回合，技术拆单不增加次数|
|练习日期混用保存日|未区分实际练习、历史成交和导入时间|导入前校验有效练习日期，保护人工更正|
|余仓结果与完整练习收益混用|只计算了已实现部分|整体收益含期末浮动及一次费用；缺估值明确未知|
|金额与收益率共用分母|未区分净额可算与本金有效|金额、收益率各自说明有效样本；缺本金不抹去已知金额|
|导入变更可能覆盖人工工作|缺少练习身份与更新交互规则|等价重复不新增；变化先选择；保留历史与复盘成果|
|旧文档、旧原型继续承担业务权威|版本职责未分清|V2.0 引用新规范，旧 E 原型只保留历史参考职责|

最近开仓的配对例子属于已确认内容，继续保留。同一人的成交行为如何自动识别、真实估值与本金来源、多标的与混合方向的具体呈现、冲突界面等仍需后续设计，不在本次静默定型。
