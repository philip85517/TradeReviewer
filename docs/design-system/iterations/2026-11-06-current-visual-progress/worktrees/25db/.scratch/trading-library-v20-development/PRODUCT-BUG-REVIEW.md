# TradingReview 功能问题与现象复核

本次依据现有问题记录、实际操作记录和代码，整理用户会遇到的现象；没有重新操作整个产品或新增修复。核对了历史局部验收清单中 38 个产品代码和测试文件，当前内容与清单一致，但这不能证明整个产品或所有使用场景没有问题。

## 曾经出现、已有修复记录的问题

|用户操作|当时的现象|应该怎样|目前判断|
|---|---|---|---|
|选择一份包含新标的的文件，查看导入预览后取消|即使取消导入，系统仍可能留下该标的的信息。|取消后不应因为这次预览新增标的信息。|已修复；曾通过实际浏览器操作和隔离数据检查复验。|
|在补充文件入口选择 CSV|文件选择窗口可能不允许选中 CSV。|应能选择符合要求的 CSV 文件。|已修复；曾通过真实文件选择复验。|
|只打开数据页或练习页，或刷新页面|旧复盘记录的更新时间被改动，尽管用户没有编辑复盘。|只查看、刷新不应改写旧复盘；真正编辑复盘时仍应能够保存。|已修复；曾通过实际操作和隔离数据检查复验。|
|导入时填写证券信息|确认框中的部分字段在某些屏幕宽度下相互重叠，不便阅读和填写。|字段和提示应清晰、不重叠。|已修复已发现的布局问题；独立检查了多个屏幕宽度。原生下拉菜单弹层和触屏场景仍未验证。|
|预览后数据发生变化，再尝试保存|系统可能保留过期的保存请求，影响重新检查后的保存。|提示重新检查，保留已选择的文件，并按新的检查结果保存。|代码、测试和独立静态检查显示已处理；真实浏览器中的这一特殊情况尚未验证，不能认定完整修复验收通过。|
|导入较大的普通 CSV 文件|文件可能被模拟练习入口的大小限制误拦截。|普通 CSV 应遵循原有导入规则；模拟练习文件按其适用规则检查。|代码、测试和独立静态检查显示已处理；真实文件选择窗口中尚未复验大文件。|

以上“已修复”均只覆盖相应记录中的场景，不代表整个交易库已验收。原始问题和修复轮次见[问题账本](EXECUTION.md)，局部浏览器检查范围见[控件检查记录](evidence/I10-practice-persistence/root/CONTROL-AUDIT.md)。

## 尚未验证：不能直接称为 bug

- 文件选择窗口打开后直接取消、保存过程中关闭窗口、检查失败后重试，以及较早的检查结果晚到时页面如何处理，尚缺完整的真实操作证据。
- 文件的账户和标的无法确认、可能对应多份已有练习，或已有练习日期与文件名冲突时，相关提示与阻止保存的特殊情况尚未逐项在真实浏览器中验证。
- 原生下拉菜单展开后的显示、模拟触屏、真实触屏和手机软键盘尚未验证。桌面窄屏检查不能替代触屏和手机操作。

在已记录的导入、确认、保存及查看范围内，57 个登记项中 44 项曾取得通过结果，13 项未验证，记录中没有当前失败项；这不是整个产品的测试结果。详细列表见[控件检查记录](evidence/I10-practice-persistence/root/CONTROL-AUDIT.md)。

## 功能仍在建设或规则待确定

- **完整练习保存与后续复盘尚未贯通。** 当前已能在有限场景保存和查看完整原始记录，但不能据此说新交易库的内部配对、统计、复盘和返回链都已完成或通过验收。
- **已有练习的文件发生变化时，暂不能直接更新。** 当前会提示需先核对更新规则，本次不保存；如何更新仍需产品规则确定。这是当前能力边界，不应描述为已经确认的数据丢失 bug。
- **旧数据与已有复盘成果如何安全衔接新练习仍需完成和验证。** 目前不能保证完整迁移或自动关联已经实现，也没有据此认定用户现有数据已经丢失。

## 容易误判的正常拦截

按照已确认的规则，导入文件名必须恰好能识别出一个有效练习日期；没有日期、识别出多个日期或日期无效时导入失败，是预期行为。文件里的历史成交时间缺失或无效时，阻止导入并指出问题原行也是预期行为。每份练习仅允许一个账户和一个标的。

本记录只讨论 TradingReview 产品功能；项目资料的备份和管理属于另行讨论的项目工作，不作为这里的产品 bug 或开发阻塞。
