# 复盘页视觉规范 V1.0：全文扫描与改写记录

日期：2026-10-23。范围：导言及RV01–RV10全部正文。依据用户要求，本次修订只改变论述与编排，保留设计提案身份、既有参数、画板和业务契约。

## 全文判断

原文已经包含较完整的规则，但阅读路径更接近实施检查清单：读者常先看到尺寸、枚举或参考资料，随后才知道这些规定要解决什么问题。部分章节的目标隐含在细则里，取舍分散在“不允许”条款中；图稿或表格直接开篇时，也缺少理解它们的任务背景。应先建立每章的论点和内部层次，再让规则、参数、画板和引用承担论据与落实作用。

改写标准是：围绕章标题说明本章解决的问题，先给出整体主张及其目标和取舍，再按内容关系展开规则。参数用于落实主张，例图用于解释状态，引用用于追溯依据。各章采用适合其主题的子标题，不机械重复同一套“目标/规则/引用”标题。导言还应说明全文的阅读顺序及交付边界。

## 改写边界与反例

本次没有修改任何SVG画板、生成器、业务代码或阅读器交互。保留10个章节稳定锚点和10个图片路径，全部规则表只作位置调整，表内内容不变。原始正文和身份、清单快照保存在本目录的before文件中，供追溯本次变化；原视觉验收保留其对应版本，不能用本次文字改写覆盖旧证据。

仅在每章前添加“本章目标”而不调整内部顺序，不符合本次要求；仅将否定句改成正面措辞却改变约束，也不符合要求。因此本次同时重组子标题、段落顺序与规则引导，并对原有约束逐章复核。
