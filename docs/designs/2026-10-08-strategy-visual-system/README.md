字体链应为 `Geist, "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", system-ui, sans-serif`；等宽数字另设 Geist Mono。必须核对 Next 字体变量是否自带 `sans-serif`，不能把中文字体附加在已展开的泛型后。`document.fonts.status=loaded` 与 computed font-family 只证明加载状态/候选链，不能证明每个汉字实际来自哪一个字体。实际 glyph 来源、Windows 字体仍单独记证。

## 颜色与状态

沿用现有 page `#0b1220`、surface `#111a2b`、elevated `#182337`，文字 `#e7edf6` / `#adbbcf` / `#9cacc2`。已有动作/净值蓝 `#2f80ed` 保留；仅实心主要按钮用 normal `#2469c8`、hover `#2b72d3`、active `#205bac` 配白字，计算对比度分别5.344 / 4.719 / 6.659。

焦点使用 `#8cbdff` 的2px外框，offset2px，不能被容器裁切。选中使用淡蓝底、清楚边界和字重600；阶段/开关按钮用 aria-pressed，tab 用 aria-selected 与 tab 角色，普通导航用 aria-current；选中与键盘焦点可以同时存在。Disabled 使用禁用语义和原因，不能只变灰。必要输入边界候选 `#58708f`；结构分隔线继续 `#243145`，后者不独自承担必要边界。错误用现有红加文字，成功用现有收益色加文字，不用金色表示成功。

计划沿用金色 `#f3ba2f`、虚线、计划标签；实际成交用已有买卖标记及完整事实标签。上涨/下跌色由用户设置决定：teal-red、green-red、blue-orange。不可由 CSS 第二次反转。盈亏除颜色外保留正负号、单位与语义。

普通文字目标≥4.5:1，必要控件图形/状态边界≥3:1；disabled有标准例外。对透明色先与真实祖先背景合成后计算。依据：[文字对比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[非文字对比](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。截图像素估色不代替 computed 检查。

## 尺寸、间距、图标

桌面紧凑工具默认36px控件，独立图标按钮候选36×36px；Lucide动作图标18×18px，stroke1.75。原生样板顶栏部分工具/周期仍实测31×36px，周期为Geist Mono/500，阶段为600：这是尚待公共组件推广统一的登记例外，不能称所有控件已36×36。窄屏普通操作44px，价格标签透明命中框仍112×36px（原生inline minHeight），只验证鼠标/键盘，触摸不据此通过。品牌、14px状态符号、图表坐标和手柄登记例外。保持中文 aria-label/title，图标不代替难猜动词。

控件圆角6px，面板8px。以4/8/12/16/24px为间距词汇：图标与文字8、控件组8、区块内12或16、不同任务区24。基线保持既有14px等局部间距时，需写清空间目的，不为凑倍数破坏固定框架。按钮文字基线居中；数字按列右齐；说明左齐。

一般表单沿用现有40px；本轮紧凑复盘样板输入36px是局部候选，推广前按使用场景决定。

公共组件规则：主要按钮只表达当前阶段的主要推进动作；保存、适配视野、查看配置为次要动作。样板输入36px、正文14px、单位靠近值，错误说明靠近输入。菜单选中、hover、focus、disabled分别可辨。弹层保留完整内容、关闭入口、Escape与焦点返回。空、加载、失败、只读状态写清原因和可执行下一步，不能以假数据补齐。

## 复盘工作区

S0入场前、S1持仓中、S2退出后是同一工作区。阶段名称与完整行情/成交可知截止紧邻图表，不只把完整年月日放进title。返回前阶段不洗掉「已看后续 / 复盘补记」来源。

桌面阶段行参与图表真实空间分配：≥1331px chart column用纵向flex，阶段行不收缩，chart-stage占剩余高度，由既有ResizeObserver测量。不可将阶段行加在一个100%高图表之前；overflow:hidden容器也会被焦点操作内部滚动。实际“适应全部→Tab到价格→点击止损定位”后，须检查祖先scrollTop、阶段全文和底轴，window.scrollY=0不算通过。

图表和图上批注是主工作面。原判断不可被新观察替换；图锚、图形、全文和形成阶段保持关联。新观察/结论分别标明形成阶段；事后回填历史分析持续标「复盘补记」。计划56、止损52、目标68、1000股、20万元等完整值保持可读，不为密度省略价格。

推进必须真实揭示目标K线/成交，并让目标在视野内。Tooltip、OHLC、持仓/成交列表、摘要、统计、缩放/适配全部受相同可知截止约束。历史范围与未来可知上限是两条边界，缩放不能推进市场。用户缩放/拖移的视野由既有契约保留。

较窄窗口根据内容拥挤点换行、收起或下移计划/原文面板；图表价格轴、主要动作、完整正文仍可达。不得把首页B栏比例套进复盘。图上文本可以选择并打开同源全文，但不能以全文面板替代图上可见证据。

本轮经真实长文校准的响应式候选：≤1330px下移完整计划，图表480px；≤600px图表720px，页面纵向阅读，完整原判断和S1补充持续可见。此方案按用户最新“不预设栏数/比例、不裁原文”授权探索，与旧规格较窄趋势区200–240px、列表自身滚动有明确差异，不能写成旧规格原样通过。较长页面是为保留文字付出的取舍。≤600px在图表上方正常文档流显示完整“计划入场/初始止损/止盈目标”及当前已知的“实际成本/尚未揭示/已清仓”，防止展开批注盖住轴上角色名；不加入未揭示成本。

重复计划HTML标签移至右轴既有金色标签的透明命中区域，保留完整aria/title和2px焦点框，避免白字穿过原判断。390展开全文仍可能遮住图内买入marker，正常流价格角色解决角色可读性，不代表marker已无遮挡；需后续图层/批注碰撞策略。≤600px回放行按原DOM顺序正常换行，六个控件完整保留；390px实测两行、总高94px、每控件44px，主动作在第二行起始位置。此行不再横滚；顶栏图表工具仍内部横滚。需要滚动到回放区，不能声称六控件都在首屏。图层选中浮层可能覆盖阶段说明尾部与上轴区域，属于本轮登记例外；未完成文字编辑浮层与轴标签的全状态比较。

样板通过SQLite HTTP client读取权威图表设置，不写设置；样板计划、批注和退出评价使用独立浏览器key。开发入口可逆，但静态CSS/样板资产仍可能进入构建包；development渲染条件不等于资源完全排除。正式推广时将当前依赖按钮顺序的样板primary选择器改为显式语义variant。
