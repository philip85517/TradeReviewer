# 组合事实与展示读取实验计划

目标：在同一隔离链路中判断展示信息的新鲜度验证是否会抵消已准备事实的读取收益。

1. 复用既有实验的业务定义与反例，不直接拼接两个各自开启的 SQLite 事务；用私有合成 SQLite 验证事实与展示的一致读取、版本/游标失效、失败回滚与独立进程重启。明确新版本机制仅为实验假设，不能冒充已接产品事件。
2. 先独立审查候选实现、对照范围和源/副本护栏，再冻结全部执行身份与审查记录；任何真实规模访问只走授权的静止隔离样本及新建私有副本。绝不打开共享业务库或带活动 WAL 的源文件。
3. 实际测量将事实读取和包含所有展示验证的读取分开计时；首次准备、更新和新进程总成本分开记，记录过程实际遍历和字节。每项至少三组，保留每组，不以不足样本推断分位/SLA。
4. 按结果和风险写易读报告及状态：仅验证实验设计，不假定完整页面一秒、真实导入、财务/Bars 或断电恢复通过。
