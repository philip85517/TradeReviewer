# 复盘视觉基线：验收标准

本文件定义未来实现的验收，当前状态全部为计划或 NOT VERIFIED。此次文档工作没有执行完整 UI、数据库、触控或视觉回归验收；文档检查与实现验收分开记录。

## 验收入口与固定条件

用户已确认最终入口为真实 `TradeReviewWorkspace → RecallWorkspace → ReplayChart / DrawingCanvas → repository / API → SQLite`。`/design/review` 提供视觉参照与稳定 fixture，不能证明真实标的选择、返回、行情加载或持久化链路。真实页面的完整闭环是必需验收，正式 `/` 内同壳入口及主页兼容按[AC27 / NAV01–04](entry-compatibility.md)验证；不能用样板通过替代。

每个截图/录像/操作日志绑定以下 manifest：commit/工作区未提交差异、URL、数据种子版本、隔离数据库、标的/回合、周期、phase、market cutoff、execution cutoff、已见后续标志、绘图 ID/owner/来源、选中工具和对象、面板开合/滚动、可见 bar 范围/价格范围、CSS 视口、截图像素、DPR、浏览器缩放与系统字体环境。未知项明确写未知。候选比较不得变更这些条件。

比较视口：1440×900 标准桌面、1280×800 紧凑桌面、1280×720 低高度压力、1024×768 窄桌面、390×844 手机；最终断点确定后在每个断点上下各 1 CSS px 检查。DPR 1/2 用于画布/手柄检查；这些是测试条件，不是假设用户参考图的实际 CSS 视口。粗指针模拟、物理触摸、桌面鼠标、键盘、真实中文输入法、手机软件键盘分别记录证据。

纯净比较数据要求：完整原判断、多行中文当前观察、阶段/双截止、计划入场/止损/目标、实际成交、参考资金、一个价格锚定 Text、一个新建 1:1 RR，以及正常/选中/焦点状态。原计划 56/52/68 与新建 RR 56/52/60 可共存。具体交易时间、成交揭示和文案必须先通过状态自洽校验；没有成交揭示时不能固定显示“买入已揭示”。长文另加至少 35 行中文、全角标点和长数字压力样本。新 fixture 不覆盖旧验收数据。

## 分开的放行门槛

| 门槛 | 必需证据 | 不能替代它的证据 |
| --- | --- | --- |
| G1 功能旅程 | 在真实图表逐步观察开始/预览/完成与取消；目标 bar/成交确实可见 | 状态变量变化、mock chart、控件存在 |
| G2 状态与数据 | 隔离库实际保存、返回、重开、刷新；核对双截止、锚点、来源、历史与冲突保护 | 回调调用、内存 fixture 重渲染、单次 API 成功 |
| G3 视觉一致性 | 非实现者直接比较获选纯净基线与当前渲染，同状态同视口；几何测量和截图互证 | DOM 断言、无溢出、总体分数、组件单测 |

三门槛独立通过。用户已确认外观“逐项一致，仅允许环境差异”：对齐、正文换行、价格标签、控件密度和选中反馈偏差均须修正，不能以不影响操作或总体分数高为由放行。字体抗锯齿等环境差异须注明环境与影响；不能把错字体、字号、字重、Canvas 换行差异归入抗锯齿例外。任一适用项失败或必需检查未验证，整体不通过。获选纯净基线截图目前未生成，G3 不得拿未净化归档图冒充新金图。文档规范可先评审，视觉金图由未来 T0 的实际画面确认。

## 阶段、双截止与视野合同

| 动作 | phase / market cutoff / execution cutoff | 可见事实与视野 |
| --- | --- | --- |
| 首次S0 | 入场前 / 第一笔前当前可知bar / 无揭示成交 | 无买入事实、退出或最终盈亏；呈现当时计划与原判断 |
| 下一根 | phase仅随合法成交/决策边界变化 / 推进到目标bar / 若该bar揭示成交才同步推进 | 保留缩放，必要时滚到目标证据；不重置比例或提前展示之后bar |
| 播放/暂停 | 连续应用下一根合同 / 暂停保持当前两截止 | 有连续中间帧，暂停不再推进，不把停止做成跳到结尾 |
| 下一笔决策 | 推进到目标决策阶段 / 对应bar知识截止 / 对应已知成交截止 | 目标bar与实际成交可见，只作必要定位 |
| 切入S1 | 恢复已有S1工作图；无已存图则按首笔决策边界 | 不显示尚未知退出；原判断仍可对照，原计划只读 |
| 切入S2/完整历史 | 明确主动揭示结束时行情和成交 / 保留已见后续标记 | 显示完整历史和来源；未平仓情况区分已实现/浮动，不冒充全部退出 |
| 返回早期阶段 | 恢复对应已存工作图/快照的phase、两截止，保留后来已见来源 | 恢复对应视野；没有已存S0时回第一笔前，无已存S1时按首决策边界；不得清洗补记来源 |
| 切换可用周期 | S0/S1按同一知识时间与执行截止映射，不因聚合bar揭示未来；完整历史模式保持全部合法历史与对应提示一致 | 价格锚点保持市场关联；周期映射后记录实际定位/缩放，不能把完整历史截成最后成交bar却保留完整历史提示 |
| Text/绘图/选择/面板/resize/pan/zoom | 不改变phase、两截止、可见数据及已见后续标记 | 改对应几何/布局/视野；开合不fit-all，锚点市场坐标稳定 |
| 保存/返回/重开/刷新 | 恢复已保存工作图的phase、两截止、owner与来源 | 有保存viewport时在真实数据加载后恢复对应范围；无viewport按现有定位策略并登记，不新建隐式状态源 |
| 保存失败/冲突 | 保留本地当前图与两截止，不覆盖服务端新revision | 留在可重试状态，不因错误重置视野或丢输入 |

这些行为沿用已确认回放合同与现有阶段工作图能力。末尾、无下一根、缺失行情、同一bar多决策及未平仓回合分别设置反例，不能仅验收理想单笔数据。

代码能力不等于满足本表：目前只读复核发现完整历史换周期截断风险，以及decision切换/换周期路径漏存viewport风险，见[来源记录](sources-and-decisions.md)的K01/K02。没有本轮浏览器复现，状态为“源码风险 / 运行NOT VERIFIED”；未来T1必须复现或排除，并取得真实证据，不能用“无viewport按默认定位”掩盖原本有viewport却被漏存的问题。

## 空间、字体与对比度

| ID | 条件与通过要求 | 证据 |
| --- | --- | --- |
| AC01 | 无 DEMO/草稿演示组合、画板说明和开发导航；真实草稿、保存状态与知识边界保留 | 正式入口完整截图 + 文案分类表 |
| AC02 | 顶部没有新增说明空行；按获选预算记录总高度及异常提示例外；主图不被无任务收益的空间压缩 | 每视口 rect、基线并排图、例外记录 |
| AC03 | 左右开关分别位于对应边缘，可逆可达；下方执行组在主图中心，文案与面板开合不推走中心 | open/closed/focus 三态截图、Tab/Enter/Escape 日志 |
| AC04 | 标题/阶段/正文/数值按角色；真实中文字体回退、Canvas 与 DOM 的量字和基线无突变 | computed style、字形环境记录、长中文对照图 |
| AC05 | 右侧标题/标签/正文/价格列与容器对齐，长值完整可访问；多行内容不开无用大框 | 正常/长文/长价格/未知/错误截图和几何 |
| AC06 | 止盈/止损不同色细虚线留在真实价格，图内无计划名称方框；完整名称及价格在右侧图外，与轴文字同字号/行高/基线，数值列右齐。同价来源清楚、近价只图外避让且连接真实价位；长价不碰撞/截断、不遮K线，超视野主动显示无未来泄漏 | 密集标签与超出视野前后图，范围/cutoff 日志 |
| AC07 | 常规桌面/粗指针/Text 例外命中达到规范；各控件有名称、焦点和 Tooltip | hit rect、键盘检查及粗指针检查分别记录 |
| AC08 | 普通正文实际对比度 ≥4.5:1；必要控件边界/状态/图标对邻接背景 ≥3:1；不能四舍五入越过门槛 | 实际状态取色与透明合成过程、原始比值 |
| AC09 | 在各视口和断点两侧可使用；有效绘图区满足约束，正常桌面不沿用 260px 主图/宽计划栏下置造成的拥挤 | 全页截图 + 各区域 rect + 主要操作日志 |

AC08 的正文要求采用 [WCAG 2.2 Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)，必要图形/控件要求采用 [Non-text Contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。禁用控件例外按标准记录，不能把正常次要文字当作禁用。主题 token 的数学比值不是页面所有状态的对比度通过证据。

## 动作与状态验收矩阵

| ID / 旅程 | 起始 → 动作 → 预期结果 | 状态/视口不变量与反例 |
| --- | --- | --- |
| AC10 阶段 | S0 → 推进 S1 → S2；回看原文 | 原图与原判断可追溯；按阶段形成新内容，S1 不提前要求结论；不得重写原文 |
| AC11 下一根/播放 | 暂停 → 下一根；再播放/暂停 | 真实图显露目标 bar，市场截止正确；成交按独立执行截止显示。无未来 Tooltip/列表/摘要，暂停无残留计时器 |
| AC12 下一笔决策 | 决策前 → 下一笔 | 真实成交及相应 bar 可见；记录数量/成本/事实与 cutoff 同步，不能只跳选择项 |
| AC13 历史/补记 | 早期 → 主动看完整历史 → 换可用周期 → 返回早期 → 新增批注 | 全部历史与提示一致；新分析保留“已见后续/补记”，不能因 cursor 回退洗掉来源；不会意外 fit-all；覆盖K01 |
| AC14 锚定 Text | 点 bar/价格 → 移动框 → 预览连接 → 确认 | 保存的是市场坐标；拖框只改布局，锚点独立；pan/zoom 后同 bar 同价，未确认取消无残留 |
| AC15 Text 编辑 | 选中 → 拖框 → 再拖 → 编辑 → 折叠/展开 → 关闭编辑 | 正文可选字；柄移动光标、编辑文本光标；每次拖均可用；关闭不等于删除；长文尾行不被柄遮挡 |
| AC16 线段创建 | 每种工具首点 → 预览 → 最终有效确认 → 自动选择工具cursor且新对象selected → 立即反复拖动 → 空白取消 | 首点/微移不是完成，通道宽度确认才完成；Text正文完成才完成。两步点击/拖放分别过；无需再点箭头，绘图ICON熄灭；下一空白点击不建第二条，phase/两截止不变 |
| AC17 选择反馈 | hover → 新选中 → 同对象再点 → 空白取消 | 首次反馈目标 ≤50ms，以帧级录像/时间采样验证；约200ms一次确认后持续；创建自动选中同样只有一次，工具选中/对象selected/键盘焦点分别可辨；重复不重播，减少动态仍可辨 |
| AC18 选择几何 | 同图表帧，选中前后切换 | Text 换行不变，位置/尺寸漂移 ≤1 CSS px；这是已有选中几何规则的测量容差，不是放行可见错位的许可。手柄真实可操作，焦点与 selected 可区分；不得用总屏差异分数掩盖错位 |
| AC19 取消/锁定 | 编辑/拖动/绘制/选择分别 Escape；锁定后 hover/选中 | 按优先级退出/回滚；未完成几何/空Text取消回cursor并清预览/空框，无新历史；非空Text退出先保留缓冲，完成/继续/明确放弃后才切工具或执行历史，不能静默丢字或误当确认。明确放弃新建无对象/历史，已有对象恢复原值selected；取消取点/拖动不丢正文；非法输入留当前步骤提示，切工具先清旧预览；不误建图形、不丢未提交文字；锁定无假拖动手柄；系统原生光标另有直接证据 |
| AC20 新 RR | 新建多头56/52、新建空头56/60；再试零风险/错误方向/无效价格 | 目标分别60/52，即1:1，价格域计算并统一精度；错误场景提示且不提交、不自动翻转止损。拖动预览可辨，释放一次历史；旧56/52/68及旧自定义比例不改 |
| AC21 更多工具/历史 | 更多菜单全部工具 → 关闭 → undo/redo | 矩形/箭头/通道/Fib/测量/标签各有完整可达项；无图表穿透；一次确认一次历史，preview不填历史，非空Text草稿先按AC19保护再执行历史，undo/redo停留cursor且按有效对象恢复/清选择、不复活旧创建预览、不丢来源 |
| AC22 保存闭环 | 创建/修改 → 换决策/周期并返回 → 保存 → 返回真实列表 → 重开 → 刷新 | 实际隔离 SQLite 文档与 UI一致；核对正文、anchor、layout、width/font、phase、两截止、provenance、revision及阶段工作图viewport恢复；合法无viewport明确定位策略，禁止漏存既有viewport；覆盖K02 |
| AC23 失败/冲突 | 有未保存改动 → 请求失败/版本冲突 → 重试/返回 | 内容保留、反馈可见、离页保护生效；不能提示已保存而库中没有，不能无确认覆盖新revision |
| AC24 生命周期 | 空/加载/只读/数据不可用/完成回合 | 禁用原因、未知值与重试明确；真实周期切换/股票/回合返回正确，不能沿用样板 no-op |
| AC25 导出兼容 | 含三阶段及长文的记录 → 导出 | 三阶段图像16:9；止盈/止损不同色虚线及图外名称/价格与工作图同规则，缩略阶段也无遮图方框、不截价格；不含工具/选中手柄/焦点；包含完整原文、价格、来源、交易表；缺失阶段明确，不能编造内容 |
| AC26 输入方式 | 鼠标/键盘/模拟粗指针/真实IME/软件键盘分别完成关键旅程 | 中文合成输入不被Enter误提交；触屏不依赖hover；每种方式独立PASS/FAIL/NOT VERIFIED，物理触摸不由模拟替代 |
| AC27 正式入口/主页兼容 | 首页持仓“看图·记录”/待复盘“开始复盘”/交易库/分析 → 准确回合 → 保存 → 来源返回 → 重开/刷新 | 同应用壳、准确标的/回合/账户/运行，无新一级菜单或 `/review` 路由；完整壳计入同视口；直接及经库中转来源均保留合法范围/期间/视图/检索/分页；失效有恢复，保存失败/冲突保护；AC27-A～E见入口规范，均NOT VERIFIED |

## 控件登记与证据记录

未来实现影响整个复盘外壳，需完整范围登记：正式应用壳及主页/交易库/分析入口、来源返回与上下文恢复；顶部标的/周期/阶段/真实父级动作/两边开关；导航记录及选中；全部绘图工具与子菜单；每类图形的锚点、手柄、编辑条、折叠、删除、锁定、选中；计划/数量/资金/退出字段；回放五个主动作、保存与更多记录；错误/冲突/离开保护/导出及响应式替代入口。控件按实际生成的 ID 登记，不以本表数量代表 100%。

每条登记写：版本、控件/操作、适用阶段、源规格 CB/E/AC、输入方式、开始/中间/完成证据、状态与数据核对、视觉对照、独立接受人、PASS/FAIL/NOT VERIFIED/NOT APPLICABLE。排除项必须说明范围依据。此次仅文档任务：运行控件、持久化和完整 UI 放行为 NOT APPLICABLE；未来实现任务不得复用此理由。

现有 Vitest 的工作区/样板测试使用 mock chart 或 mock workspace，可复用为编排回归，但不覆盖 G1–G3 的真实证据。新增测试验证外部行为和重要反例，不写仅镜像 CSS 实现的低价值测试。必要外部浏览器检查可用现有可用的浏览器或 Playwright；工具变化不降低标准。
