## Implemented

- Replaced the old preparation screen with the sequential path **设置起点 → 选择策略 → 预览组合 → 确认并进入**. Completed steps show a check, the current step is blue, later steps cannot be skipped, and each stage change returns the creation scroll area to its top.
- Preserved the RunningDraft shape and RunningPrototype props. The blind field stays true; creation edits stop after entering the running workspace. The run configuration is read-only on return, and the single in-memory list entry reopens the draft or original run.
- Added Asia/Shanghai T0 validation, future-time and positive-capital checks, full daily/weekly cutoff explanations, collection source, five horizons, and a fixed daily-reveal explanation.
- Strategy cards use explicit multi-select checkboxes. Names are the selection labels; rules and detail disclosure do not toggle selection. Unselected preset controls are read-only. Missing required data is explained on the affected package. Empty selection blocks progress with a local explanation.
- Preview separates eligible, rule-failed, and data-insufficient sample counts; row disclosure shows rule values and their known-time boundary. Counts identify themselves as synthetic examples and do not claim to have screened the full collection.
- Each selected strategy has its own preview and principal. Target amounts update from the current principal; actual T0 holdings remain 0 and cash 100%. The no-candidate scenario produces a 100% cash target. Partial-coverage confirmation is cleared when the start date, collection, or demonstration scenario changes.
- Strategy and candidate switching use keyboard-operable tab semantics. Development scenarios and prototype/data limitations are collapsed by default. Existing narrow-screen media rules were retained.
