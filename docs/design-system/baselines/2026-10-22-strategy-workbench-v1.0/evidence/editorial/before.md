# 策略台视觉设计方案 V1.0

策略台帮助你把投资想法变成可重复的策略，放到同一段历史里观察，再用成交原因和结果检验它。设计的重心是：**先知道正在看哪个策略、哪一天，再看图表发生了什么，最后追问为什么。**

![完整观察：策略身份、日期、主图与相邻解释区](images/06-observe.svg)

图 ST06｜本次完整观察设计，虚构示例数据。延续已确认的 0.7 观察层级，统一为当前全站 V2.5 控件语言。V1.0 是本模块的新版本编号，不替换历史 2.x 文档；新增视觉方案待评审。

你可以按“策略库 → 创建实验 → 观察与回看 → 结果和比较”的顺序阅读，也可以从侧边目录直接看关心的画面。图中按钮用于说明设计；正文的分镜按钮用于浏览方案。

## 一、这次设计保留什么、改变什么 {#chapter-ST01}

### 一个策略可以反复使用，一次实验只回答一个历史问题

策略库保存“用什么办法选股、何时买入、何时退出”；我的实验保存“用哪个版本、从哪天开始、投入多少资金、运行到哪天”。两个对象分开，修改今天的策略不会改写昨天的实验。创建实验始终从“我的实验”开始；在创建途中缺少合适策略，可以就地组装，保存后回到原来的选择步骤。

进入实验后，回放观察、阶段结果、组合对比共用实验身份和时间说明。查看结果不用重新找策略，打开事件也能返回原来那一页。策略台里的你是观察者：买卖由策略和执行规则决定，页面不会把候选名单画成手动下单面板。

### 三个视觉选择

**保留图表与解释相邻。** 主图回答走势与成交，右侧回答持仓和调仓原因。将解释放在图旁，比每次开弹窗更容易对照；代价是图表变窄，所以低频配置另开覆盖层，右侧不塞完整表单。窄窗口按图表、解释的顺序向下阅读。

**共用控件，不照搬首页布局。** 颜色、字号、按钮、输入、焦点、金额展示沿用 V2.5；策略的身份栏、日期、回放工具保留自己的业务顺序。首页的72px导航、64px页头和八行持仓表不是全站强制尺寸。

**保留完整信息，允许向下滚动。** 0.7 已确认完整观察和页外滚动，本版延续。四项指标合并为一条88px高的摘要带，减少卡片嵌套；它比旧紧凑摘要稍高，换来统一字号与可读金额。图表净绘图区仍至少320px，不靠缩字塞满一屏。

## 二、策略库：先找到方法，再看规则 {#chapter-ST02}

![策略库：完整策略与三类包、查询和管理](images/01-library.svg)

完整策略放在默认视图。三类包作为相邻目录，名称直接说明职责：标的筛选、买入信号、止盈止损。列表优先展示名称、版本、规则摘要与状态；搜索、筛选和排序固定在顶部。“新建策略”是这里唯一主动作，保存成功只进入策略详情。

本版建议将大卡片改成紧凑行，让你同屏比较更多策略。规则全文不塞入每一行，而是在详情里展开。这个密度调整是本次建议，历史“整体模型认可”不代表已经认可这组新尺寸。

包目录复用同一套查询工具，额外显示使用策略数和版本发布时间。“查看详情”不会选中包；回到选择列表后，再点“使用此包”，避免把探索说明变成修改配置。

## 三、组装策略：三个包，一份可追溯的版本 {#chapter-ST03}

![包目录管理：引用计数、个人排序与归档](images/01b-package-management.svg)

![完整策略组装、包说明与版本保存](images/02-compose.svg)

组装页按“筛选 → 买入 → 止盈止损”排列三个区域，表达先找到候选，再产生交易意图的关系。每个区域先给出包名、版本和命名预设，随后显示关键规则与数据要求。排序、仓位分配和再平衡仍在完整策略配置里；第三个包不能把它们替代掉。

右侧包详情覆盖层宽480px，适合阅读说明；运行中的320px检查区只读当日证据，两者不能因为都在右侧就混成一个容器。关闭详情回到原位置，未保存内容不丢失。用户不需要逐条搭建原子条件，也不需要在这里上传脚本。

编辑已有策略时，按钮明确写“保存新版本”；复制历史版本时写“创建副本”。前者属于同一个策略的新版本，后者是独立策略。已有实验始终引用原来的完整策略版本和三个包版本。

## 四、我的实验：每条记录都有下一步 {#chapter-ST04}

![实验列表：草稿、未开始、暂停、完成与失败](images/03-experiments.svg)

实验列表回答“我研究过什么、进行到哪里、现在可以做什么”。状态放在实验名称附近，日期区间和策略组合放在同一行上下文里。草稿提供“继续编辑”，未开始提供“进入实验”，暂停提供“继续观察”，完成提供“查看结果”，失败提供“查看原因”。

这些入口使用相同位置，文字随真实状态变化。打开一个曾运行的实验先保持暂停，避免刚进来就继续暴露未来。搜索、筛选、排序与策略库一致，切换两页不会创建草稿，也不会偷偷选中策略。

<details>
<summary>查看实验状态与列表恢复规则</summary>

EXP01 草稿保留步骤、输入和已选版本；EXP02 确认后有独立运行身份，初态未开始；EXP03 保存的暂停/失败运行重开后仍暂停；EXP04 完成后保留观察、结果、比较和复制入口；EXP05 从详情返回恢复查询、页码、滚动和触发焦点。未保存草稿离开时给出“保存草稿 / 放弃本次修改 / 继续编辑”，不让普通切换隐式保存失败的数据。

</details>

## 五、创建实验：四步把假设说明白 {#chapter-ST05}

:::state-demo
images/04-create.svg|第一步：设置起点|先确定在哪段历史里研究，保留绝对时间、业务时区、名义与实际终点。
images/04b-select-strategies.svg|第二步：选择策略|选择明确版本，各组合本金独立；就地组装新策略后带回原选择。
images/05-confirm.svg|预览组合，再确认创建|目标配置与实际持仓分开；每组资金独立，最终确认锁定版本和执行假设。
:::

第一步确定历史起点与期限。第二步选择一个或多个完整策略；需要新策略时，次动作进入组装，保存后只追加新选项，取消则原样返回。第三步预览历史可知数据形成的候选与目标仓位，并核对各组独立资金。第四步把时间、版本、资金、费用和执行假设集中呈现，确认后进入尚未开始的工作台。

预览刻意同时展示“目标”和“实际”。目标仓位表达策略希望如何配置；尚未运行时，实际持仓仍为0，现金仍为100%。没有候选可以是一种有效结果，页面说明原因，不制造一个默认买入。

<summary>查看四步字段、数据边界及失败规则</summary>

| --- | --- | --- |
| WIZ01 设置起点 | 绝对时间、业务时区、市场/证券池、历史区间；期限沿用1周、1个月、3个月、半年、1年 | 一周为7自然日，其余为1/3/6/12日历月，月末无同日取目标月末；终点取目标之前最后完整交易日，显示名义/实际终点和交易日数；目标超出数据末端时等待补齐，或明确选择部分区间，不静默缩短 |

| WIZ03 就地组装 | 保存成功返回步骤2追加准确新版本；重新预检 | 取消不变；保存失败留表单；已有选择与查询仍在 |

| WIZ06 执行约定 | 信号截止、最早下一可交易开盘执行、停牌/涨跌停/成交不足、退出与再平衡冲突规则 | 触发不等于成交；不从日线假定精确盘中撮合 |

| WIZ08 历史可知 | T0只能用已完整结束的日/周及当时已发布财务信息 | 盘中T0不能用当天收盘；未结束周线不能当完整周；缺必需数据明确阻断 |

## 六、观察工作台：围绕同一天理解一个组合 {#chapter-ST06}

![完整观察：当前组合与当日证据](images/06-observe.svg)

![时间状态与摘要的原尺寸细节](images/06-observe-status-detail.svg)

先读顶部实验名与组合版本，再看摘要和查看日。净值曲线呈现这一组合的变化；切到标的K线后，成交标记解释具体买卖位置。右侧“组合详情”在概览、调仓记录、统计指标之间切换，始终属于当前组合和当前查看日。

主图下方放固定位置的播放/暂停、下一交易日、速度和回看动作，避免日期文字变长时按钮换行跑位。配置放到低频入口，常驻信息只留下理解当下所需的内容。摘要中的净资产、累计收益、最大回撤和仓位共同回答结果与风险，不重复展示一整套账本。

组合很多时，在固定宽度选择区显示当前项和“更多组合”。名称可以换行或在列表完整阅读，不能因为组合增加就向下挤压主图。切换组合只换观察对象，查看日不变；某组执行落后时显示自己的已完成日，不把旧值伪装成今天。

<summary>查看观察元素、长文和空间规则</summary>

OBS01 身份：实验/完整策略/版本同时可追溯。OBS02 摘要：统一到当前查看日与当前组合；未知用“—”。OBS03 日期：显示“正在查看”“行情已展开至”，回看时另保留已看后续提示。OBS04 图表：净值与K线共享舞台；切换恢复对应视野。OBS05 成交：买卖文字/形状与颜色并用；意图、计划和成交分别展示。OBS06 检查区：长原因自然换行；展开详情时主图不换容器、不改变已展开边界。OBS07 回放：播放/暂停同槽；下一日永远表示交易日；不在输入法组合输入时触发快捷键。OBS08 配置：只读锁定值，修改只能“基于此配置新建实验”。

价格保留2位小数，重要价格直接可读。金额按万/亿缩写，完整值可通过聚焦、详情、复制/导出取得；说明正文14/20，长规则候选使用14/22改善阅读，不改变共享按钮行高。

</details>

点一次“下一交易日”，日期、行情和当日证据一起更新。新一天必须出现在主图里；若发生了成交，同时出现成交标记与实际持仓变化。没有成交，就只揭示行情，不能为了让按钮显得有效而制造交易。

回看过去只是换一个观察位置。比如已经看到6月28日，再回到6月14日，主图和当日持仓回到起点，但“已看后续至6月28日”仍然可见。这样你能复查原来的判断，又不会误以为自己从未看过未来。

连续播放按交易日依次揭示；速度只改变观看节奏。展开到指定日期会明确说明将揭示哪段历史。返回最新只回到已经展开的截止，不产生新的进度。错误发生时停在最后完整成功的一天，保留图表与原因。

## 十三、走完一条完整路径，返回后仍找得到原来的位置 {#chapter-ST13}
