# Bundled Geist fonts

These unchanged WOFF2 files are the font assets from the previously accepted production build. All original subsets, weights, unicode ranges and swap behavior are retained in app/fonts.css. They are served from the same origin; clean builds and first page loads do not fetch Google Fonts.

Upstream: https://github.com/vercel/geist-font
License: OFL-1.1, copied from https://raw.githubusercontent.com/google/fonts/main/ofl/geist/OFL.txt (the Geist Mono license is identical). MANIFEST.json records content hashes.
