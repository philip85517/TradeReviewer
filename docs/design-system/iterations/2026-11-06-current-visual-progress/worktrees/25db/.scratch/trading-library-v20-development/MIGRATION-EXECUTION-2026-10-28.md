# 旧库迁移与并行开发执行记录

> 用户要求开始正式迁移并启动多个 Agent 开发；旧业务库保留，目标使用新数据库。任务与原 V2.0 设计、[迁移票](issues/33-legacy-database-migration.md)和[用户决定](USER-DECISIONS-2026-10-27.md)一致。

## 责任与顺序

1. `source_assessment`：只读评估真实源库并对唯一新建隔离快照进行预检；不得迁移、切换配置或输出交易/复盘正文。
2. `migration_implementation`：独占新迁移脚本与其测试，先在合成隔离库验证复制、异常、中断和重复执行；未知练习身份、日期和复盘关联不得猜测。正式迁移须等待独立审查和协调者核验。
3. `initial_capital`：调查并推进全局默认 100,000 元和练习覆盖值的独立后端切片；不碰迁移代码、业务库或 UI。缺失的估值、既有练习受全局配置变更的影响以及跨币种转换不能自行定案。
4. 协调者：核对任务边界、实际数据迁移方案和风险，安排未参与实现的独立审查；将真实迁移产物、完整性和引用、原库保护与应用重读分别验收；任何失败保留证据，同一问题修复最多五轮。

## 状态与限制

- 执行迁移和启用新库必须分别核对：一致性快照不等于完整业务映射；不得以旧文件名、时间或净值猜测无法证明的练习与复盘关系。
- 以合成数据库检查失败、中断、重试及数据不变；真实业务库只读，任何输出库使用新的路径且不得覆盖现有文件。真实结果与原始证据在生成后记录，未检查项为 NOT VERIFIED。
- 用户已确认正式迁移测试入口：从旧库生成新库，检查交易和复盘完整与关联，错误或中断时保留旧库并能安全重试。预检脚本的 95% 例外不延伸到其他范围。
- UI、触屏及窄屏不属于本轮已分派的两个后端切片；完整 V2.0 的桌面视觉和交互验收仍按项目规范执行。
- 三个代理请求模型 `gpt-5.6-luna`；此环境未提供能验证代理实际模型身份的元数据，不冒称实测模型。
- 初始资金已完成范围调查：[报告](evidence/initial-capital/report.md)。2026-10-28 用户确认全局默认变更后，未单独设置本金的既有练习按新全局值重新计算，单独设置的仍用其设置；持久化及接入仍待开发和验收。
- [源数据独立复核](evidence/I33/source-independent-review.md)发现 Recall 草稿中存在成交 ID 候选线索，不能断言没有任何关联；具体语义和完整性继续核实。另有批次记录数差异和 review 标的为空，不能直接推定原因。
- [资金独立审查](evidence/initial-capital/independent-review.md)：纯解析通过局部验证，但统计入口尚未接入，币种一致性须在接线时验证，先失败测试证据未找到。要求实施者补齐公开入口的红绿测试并处理币种边界。
- 协调者复跑：迁移及预检测试 25 项通过；资金和练习统计测试 86 项通过；上述四个实现/测试文件的 ESLint 通过。以上是局部测试，不代表业务迁移、配置持久化或整体产品验收完成。
- 迁移副本程序的[独立第一轮审查](evidence/I33/migration-independent-review.md)为 FAIL：目标路径的 SQLite 附属文件可污染读取结果；新副本及暂存权限过宽；成功发布后的清理失败可能误报；暂存文件存在创建竞态。已交实施者按反例补红绿测试修复，正式迁移和启用仍不得以当前版本执行。本轮为上述各问题首次独立发现，修复轮次由实施者记录，单问题最多五轮。
- 第一轮修复后[第二轮独立审查](evidence/I33/migration-independent-review-round2.md)仍为 FAIL：目标附属文件可在检查与发布之间出现，读回数据被污染。已安排该问题第二轮修复；目录隔离和可重试的恢复语义仍须独立验证，不能用于实际迁移。
- 协调者检查第二次修复时发现，其仍把文件发布到共享目标目录，且将不覆盖的 hard-link 改为可能覆盖目标的 `renameSync`；旧并发复现只挂钩 `linkSync`，因此该复现读回源值不能证明竞态已解决。已暂停该实现并安排第三轮独立核验；该问题修复仍未接受。
- [第三轮独立复现](evidence/I33/migration-independent-review-round3.md)确认三个阻断项：目标被并发覆盖、最终侧车检查后出现 WAL 导致读取错误数据、异常清理删除并发替换的目标。原有 28 项测试全部通过却没有覆盖这些情况，现已要求实施者按实际发布步骤先补反例，并约束专属目录及清理边界；每个问题最多五轮修复。
- 独立[第四轮审查](evidence/I33/migration-independent-review-round4.md)对专属目录方案重新触发上述三个反例，结果仍 FAIL；该测试前提是同用户或已获目录写权限的并发操作，并非跨用户权限绕过。上一实施者报告已记为第 4 轮修复，因此按较保守的计数启动第 5 轮，也是最后一轮；若独立复验仍未解决，则停止该问题并保留记录，不进行第 6 轮。正式迁移继续禁止使用当前程序。
- 本金持久化[独立验收](evidence/initial-capital/persistence-independent-review.md)：隔离库的保存、重开、全局变更、练习覆盖和删除覆盖回退通过；统计与页面接线仍未完成。练习存在性检查和写入的并发边界、设置的生命周期需进一步处理；GET 目前仅返回带币种的设置，未自行判断统计币种，先前报告的相反表述需更正。
- 存在性与写入已改在同一 SQLite 写事务内；[独立双连接复验](evidence/initial-capital/transaction-independent-review.md)验证交错删除受锁保护、缺失练习返回 404。若未来增加删除练习或复用 ID，仍需处理设置生命周期；尚未发现现有删除入口。实际统计页面接线仍 NOT VERIFIED。
- 数据复核进一步通过当前应用算法在隔离快照重建 764 个旧 episode，138 个 reviews 表记录中 131 个 ID 命中、7 个未命中；这 7 条仅有 cursor 状态，未发现复盘正文、绘图或 Recall，仍有待进一步核实的成交候选。5 份 Recall 的决策成交引用均可在对应重建 episode 中找到，其中一条是有源成交的反向拆分派生 ID。该结果仍不证明新练习的身份、日期、所有附件或实际应用迁移完成；详见[独立复核记录](evidence/I33/source-independent-review.md)。
- [独立旧应用读回复核](evidence/I33/app-readback-independent-review.md)在新建隔离副本重跑真实存储和路由：45 个旧业务表原有列行摘要保持一致，交易来源、138 项复盘状态和 5 份 Recall 的原始数据与应用读取相符。快照共有 46 个非系统表，其中另一个是 schema_migrations；worker 首报的“45 个非系统表”为计数表述错误。该检查不等于 V2 映射、浏览器操作或实际迁移验收。
- 协调者对本金计算与设置的四个单测文件重跑：21 项通过；覆盖两个本金计算文件及两个存储文件的分支为 84.21%（48/57），未达到 95%，已安排补充有意义的行为测试；该数字不代表整个项目的覆盖率。
- 本金测试补充后，协调者在 Node 26 重跑 [五个测试文件和指定六个生产文件](evidence/initial-capital/unit-coverage-2026-10-28.md)：41 项通过，V8 分支 65/65。此数仅限所列文件，不代表全项目或完整统计用户旅程；独立复审进行中。
- [旧模拟练习映射可行性](evidence/I33/v2-mapping-feasibility.md)：82 条明确模拟成交形成 4 组候选，各组账户/标的/文件名和有效日期有线索，但尚无原始 CSV 字节、完整原行或已证实的复盘关联，不能冒充满足 V2 完整来源合同；有限范围内未找到原始文件，已询问用户文件位置。其他旧交易和复盘仍必须原样保留。
- [第五轮独立验收](evidence/I33/migration-independent-review-round5.md)：并发创建目标不覆盖、异常清理保留替换物的两个复现场景通过；同用户并发下，最终检查之后出现 SQLite WAL 时，脚本仍可能报告成功但读回错误内容。该问题 **STOPPED / UNRESOLVED 5/5**，不得进行第六轮；冻结脚本不得用于正式迁移。此停止仅针对该迁移问题，不阻止其他产品任务。
- 协调者独立运行第 5 轮复现脚本，三个合成场景分别读回 `OTHER CREATOR DATA`、`REPLACEMENT BY OTHER` 和错误的 `SIDECAR`（应为 `SOURCE`），与独立验收一致。复现仅使用临时库，不表明真实业务库受影响。
- [本金测试独立复验](evidence/initial-capital/unit-coverage-independent-review.md)：真实 handler 与隔离文件库验证同一无覆盖练习随全局值改变、关闭重开保留，以及单次覆盖优先和删除覆盖后回退；五个测试文件 41 项通过，限定六个生产文件分支 65/65。统计页面、浏览器和全项目覆盖仍未验收。
- [本金生产接入评估](evidence/initial-capital/production-integration-assessment.md)：当前用户可见统计仍走旧版汇总，没有调用练习本金计算。新练习投影尚未提供完整可信盈亏与费用；旧模拟成交保留部分净损益/手续费线索，但不能证明原文件及全部费用完整，不得作为已迁移完整练习收益。真实消费者接入、已知/未知区分、估值来源与 UI 验收仍待完成。
