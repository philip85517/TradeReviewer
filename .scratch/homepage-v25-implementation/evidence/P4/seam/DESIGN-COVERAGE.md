Read-only fee semantics: incurred expenses remain the existing FeeFacts, with original incurredAt/businessDate/knowledge/evidence. Allocation facts are observations of existing F pools and per-movement equations, not a new fee ledger. Before-context includes exact source hash, cursor, selected execution prefix/order, preceding movement prefix where attached, and original/cash-knowledge evidence policy. Full precision values are derived from the same unrounded Decimal state. Unknown fee status/conflicting duplicate/currency/quantity/direction gates remain unavailable in exposed allocations and totals. Group totals do not promote compatibility zero to known money. A source with only events can expose an incurred expense without certifying any realization allocation.

Complexity bounds (explicit reads only): let N be executions, M timeline entries including attached evidence, Q queries, K the sum of explicit selected-ID input sizes, and R total emitted facts/selected IDs. Ordinary canonical read builds its source digest once, runs one original evaluator sweep, and uses existing Map probes or Q binary searches: selection O(K + Q log N), materialization O(R), added auxiliary/output O(N + R). The reused evaluator still includes its original timeline construction/sort and existing evidence predicates; no new per-query scan of all ordered executions occurs. Source digest serializes source once. 256 executions/128 empty prefix queries assert one observed evaluation,256 transitions,1152 probes and zero emitted facts.

Ordinary F read performs one selected-prefix existing fee sweep and builds transient execution/movement and fee/evidence Maps. Allocation join lookups are O(1) plus the lineage actually emitted; no per-allocation scan/find/filter of all canonical facts or fee facts remains. The200-fill test asserts200 transitions/probes/fee steps, one observed canonical sweep, unchanged retained counters, gross100, fees .000000002 and native99.999999998. Diagnostics `evaluations/transitions` count the canonical observation call, and `feeSteps` counts F observations; they do **not** claim to count all internal replay work.

Attached/non-prefix requests preserve exact fallback. Each context invokes the original evaluator, and attached F may invoke it at each movement under original cash-knowledge/preceding-movement selection. Its cost is the sum of those original evaluations plus context hashing/output, including original event matching/cost helpers; it is **not linear**. Source classification also checks original execution-backed suppression authority across applicable allocation/execution pairs. No performance shortcut relaxes future knowledge, ties, selection or source authority. All added indexes/hashes are local to the explicit read; none survive in A's prepared handle or memo. No new unmetered retained Map is hidden from64MiB accounting.
