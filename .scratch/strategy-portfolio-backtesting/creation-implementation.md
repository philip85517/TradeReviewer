# 历史创建原型第二轮实现记录

日期：2026-09-29

本轮仅实现 dev-only `?prototype=strategy-create&variant=A`，保留首轮 `?prototype=strategy&variant=A/B`。页面使用内存状态与合成数据，不读取业务数据库、不调用 API、不产生真实回测。

## 已实现

- 沿用 TradeReview 深色页面框架、左侧导航、顶部上下文栏和现有 CSS 变量；导航断点沿用 760px，1059/1060 由页面自然收窄。
- 历史设置：Asia/Shanghai 日期时间按日历和真实 instant 分开校验，覆盖周末、盘中、未来、无效状态；动态显示最后完整日线与完整周五；标的集合、初始资金、五档期限、盲看和调仓预设均为内存字段。
- 策略包：两个完整策略包，多选生成独立组合；缺历史市值禁用依赖包并清理已选状态；部分覆盖需要独立显式确认；无候选保留现金组合。
- 组合预览：组合 tab 可切换，各自显示目标权重与金额；候选/排除原因、数据可知截止、当前实际持仓 0 与尚无成交；名义终点按周/日历月计算并做月末夹取。
- 准备运行与列表：显示锁定的起点、期限、调仓预设和零成交状态；返回列表可重新打开当前内存快照，新建会回到干净草稿；修改历史设置会离开旧预览。
