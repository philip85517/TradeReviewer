## 状态与接受门槛

|必须可视化的状态|最低承载材料|下一步操作或恢复要求|
|---|---|---|
|default / hover / active / selected|S03/S07，P01/P06|焦点单独展示；按下、播放中与选中不是同一语义|
|disabled / expanded|S03/S07，P04/P06|禁用原因可读，开合入口可达，工具列表顺序完整|
|loading / empty / error|P10、S06|仅相关区域反馈；可重试/取消/返回，主图保留|
|saving / conflict|P08、S06|本地草稿保留，版本对比及取消入口可见|
|end / longtext / missing|P06/P09/P10、S02/S04/S05|不自动下一交易；全文可读可编辑；未知不置零|

后续每张验收截图需登记：源版本、视口、样本、阶段、可见数据截止、左右开合、工具/焦点状态、参考版本、偏差、审阅者和结果。整页和局部都要比较，不能拿局部控件通过替代整页接受。

原型与设计阶段的门槛是可操作场景、状态安全示意、视觉对照和用户选择。真正产品功能的门槛仍包括真实图表推进、工具完整生命周期、隔离库持久化/返回/重载；本轮规划和后续模拟原型均不能替代。
