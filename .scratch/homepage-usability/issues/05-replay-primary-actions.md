# 05 — 突出当前回合与开始继续复盘操作

**What to build:** 用户打开复盘区即可辨认正在复盘的交易回合，理解当前回放位置，并找到开始或继续回放、暂停和下一成交等主要操作。

**Blocked by:** None — can start immediately

**Status:** done

**Priority:** P2

- [x] 回合选择项显示可区分的日期、账户和复盘状态；回放中不新增未来成交、最终盈亏或事后结论的泄露。
- [x] 开始、继续和暂停回放具有清晰文字或同等可发现提示，状态与实际回放一致。
- [x] 下一成交、逐根推进和回放速度在主要控制区可访问，禁用状态能让用户理解原因。
- [x] 当前时间位置、回放中或暂停、到达可用终点等状态清楚可辨，不用最终交易结果充当进度提示。
- [x] 低频绘图和行情维护操作降为次级入口，现有能力仍可发现、可访问。
- [x] 验证首次开始、继续已有进度、暂停、下一成交和终点场景，以及未来数据遮蔽回归。

**Verification:** 见 [验收记录](../verification.md)。
