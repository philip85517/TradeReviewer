## 发现：1280 持续回合身份提示较弱

可复现：打开 1280 原型 → 展开左栏并选第 2 次交易。选中瞬间显示“已切换回合：第2次交易”，但左栏随右栏展开自动收起；继续下一根后该提示被“已揭示…持仓中”替代。此时顶部标题仅“示例股份 / 600000”，画面没有持续显示“第2次交易”及买入日期；需重新展开左栏才可确认。见[选择后的提示](1280-trade2-selection-auto-right.png)、[持仓画面](1280-29-holding.png)、[重新展开列表](1280-trade2-list-reopened.png)、[补充观察](identity-sample2.json)。

这**不是**已观察到的回合串数据：上面的 `57.25` / `58.25` 内存样本是分离的。R01 要求展示股票身份、交易次数和日期，但未明确侧栏折叠时身份是否必须持续可见；因此将其记为 **视觉/交互风险，待协调者按合同判断**，不擅自宣称严格违约，也未修改 UI。1440 左栏展开时当前回合和日期可直接看到。列表标题实际为“交易列表”，股票身份在顶部及各行；是否必须合并为单个标题同样待判断。
